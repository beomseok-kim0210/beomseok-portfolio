# 04 Personal Gallery — 개인 프로젝트 미술관

2026-10-17 세션에서 어두운 연구실(Lab) 뼈대를 "퀄리티가 낮고 어둡다"는 이유로 반려하고 정한 방향입니다.
2026-10-19 Human 확정: 이 구상대로 진행하되, 품질은 최소 Wedding Dress 장면보다 높게.

## 컨셉
- 팀 프로젝트(병실·재활실·살롱)를 지난 뒤, 마지막 방은 직접 만든 작품을 전시한 갤러리.
- 밝음은 웨딩과 다르게 갑니다: 흰 벽, 회색 콘크리트 바닥, 천장 트랙 조명의 차갑고 깨끗한 밝음.
- 캡처·도식은 벽 액자, 설명 문구는 작품 옆 명판(캡션).

## 전시
| 전시 | 작품 (3D) | 벽 |
|---|---|---|
| Digital Docent | 도슨트 얼굴 3D 모델을 흰 대리석 흉상으로. 마지막에 "이 작품에게 물어보기"로 실제 도슨트와 연결 | 질문 → PageContext → Hybrid 검색 → LLM → 음성·입모양 / Hit@1·3·5 0.647·0.912·0.980 |
| BCOS | 투명 아크릴 판 5장: Task Contract → Worker → Host verification → Independent review → Event audit. 빛이 판을 통과하며 진행 | 자기 승인 문제와 분리 / T-015 APPROVED, AC 50/50, tests 272/272 |
| Crime Scene | 유리 비트린: 증거물·사건 파일, 금고처럼 잠긴 '진실' 칸 (서버만 아는 truth) | 심문 경계 { answer, concededTopicIds } ∩ whitelist / 전체 플레이 2/2, 비밀 문자열 감사 335 |

## 흐름
갤러리 입장 → 전시 3개 소개 → 전시마다 3장면. 스크롤 한 번에 한 장면.
움직임이 화면 밖에서 일어나지 않도록 전시마다 순서를 다르게 잡았습니다.
- Digital Docent: 작품 → 벽(Hit@k 도식) → 근접 초상(대리석 입이 말함, "이 작품에게 물어보기")
- BCOS: 작품(빛이 다섯 장을 통과) → 근접(리뷰 판이 Worker 줄에서 빠져나와 차가운 색으로) → 벽(50/50 · 272/272)
- Crime Scene: 작품(금고 잠금등, whitelist 태그 점등) → 벽(심문 경계 도식) → 전시 전체

## 품질 기준 (웨딩 대비)
- 반사 바닥(블러 반사), 스포트라이트 그림자, AO, 환경광 반사 — 웨딩과 같은 렌더 스택 이상.
- 재질: 대리석(셰이더 결), 아크릴(투과·굴절), 유리 진열장, 알루미늄 액자.
- 숫자·문구는 src/data/projectDetails.ts 기록에서만 사용.
