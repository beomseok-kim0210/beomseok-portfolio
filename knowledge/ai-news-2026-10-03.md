## 에이전트 곁에 '감시하는 에이전트'가 붙고, 에이전트가 손댈 수 있는 범위는 화면 밖까지 넓어진다

큰 모델 발표가 없던 하루였다. 대신 에이전트가 무엇을 볼 수 있고 어디까지 손댈 수 있는지를 넓히는 소식이 이어졌다. Claude Code는 작업하는 에이전트 옆에 지켜보는 에이전트를 하나 더 붙였다. 메타는 자사 에이전트를 실제 하드웨어와 집 안 기기로 연결했다. 딥시크와 구글은 데스크톱에서 파일과 앱을 직접 다루는 에이전트 앱을 내놓거나 준비 중이다. 3D 생성 쪽에서는 이미지 모델처럼 부분만 고치는 편집 기능이 나왔다.

### Claude Code 'You should know' — 옆에서 지켜보던 보조 에이전트가 놓친 것을 짚어주는 내장 Mod

[어제 다룬 Mods 정식 출시](ai-news-2026-10-02.md)와 같은 Claude Code 2.1.287 릴리스(10월 1일)에 들어간 기능이다. 공식 릴리스 노트는 이를 "보조 에이전트가 뒤를 지켜보다가 사용자나 Claude가 놓칠 수 있는 것을 짚어주는 내장 Mod"라고 설명한다. 기본으로 꺼져 있고, 아래 명령으로 켠다.

```
/plugin enable cc-plugin-you-should-know@builtin
```

조건이 하나 있다. 앤트로픽 계정으로 직접 쓰는 세션(first-party)이면서 텔레메트리가 켜져 있어야 한다. Bedrock·Vertex 경유 세션이나 텔레메트리를 끈 환경에서는 쓸 수 없다.

choi.openai는 이 기능을 "Claude가 일하고, 다른 Claude가 그 Claude를 감시하는 구조"라고 정리했다. 긴 코딩 작업에서는 Claude가 많은 파일을 고치고 여러 결정을 내린다. 사용자가 그 과정을 다 따라가기는 어렵다. 그래서 메인 에이전트는 작업을 하고, 보조 에이전트는 그중 사람이 알아야 할 내용만 따로 알려주는 역할을 나눈 것이다. 같은 릴리스에는 이 밖에도 다음 변경이 들어갔다.

- 에이전트 목록 화면에 세션 이름·작업으로 거르는 `n:<텍스트>` 필터
- MCP 서버가 URL을 열어 달라고 요청하는 2025-11-25 프로토콜 지원
- Windows에서 Bash 도구를 막으면 PowerShell도 같이 꺼진다는 시작 경고

> 🔧 **적용 포인트** — 도슨트 음성 파이프라인이나 R3F 씬처럼 여러 파일을 한 번에 건드리는 긴 작업에서 켜 둘 만하다. 확인할 점은 두 가지다. 첫째, 보조 에이전트가 짚은 내용 가운데 실제로 놓쳤던 것(예: 환경 변수 누락, 테스트를 건너뛴 변경)이 얼마나 되는지. 둘째, 그 대가로 사용량이 얼마나 늘어나는지. 일주일 정도 써 보고 판단하자. 텔레메트리를 켜야 한다는 조건도 미리 확인해 두자.

### 메타 Muse Gadgets — ESP32·Raspberry Pi용 SDK를 오픈소스로 풀었지만, 연결은 메타 토큰이 쥔다

메타가 10월 2일(현지) 자사 AI 에이전트 Muse를 실제 하드웨어에 연결하는 **Muse Gadgets**를 공개했다. 구성은 두 가지다.

- **ESP32 Device SDK와 펌웨어**: 화면·오디오 입출력·센서를 붙일 수 있다.
- **Linux Device SDK**: Raspberry Pi 같은 리눅스 기기용이다. 직접 만든 명령을 실행하거나 Home Assistant와 연결할 수 있다.

코드는 Apache 2.0 라이선스로 공개됐다. gadgets.muse.ai에서 API 토큰을 받은 뒤 코딩 에이전트에게 GitHub 저장소를 넘겨 주변기기를 만들게 하는 방식이 권장된다. 공개 몇 시간 만에 전자책 단말기를 Muse 전용 상시 디스플레이로 바꾼 사례도 나왔다.

함께 나온 **Muse Home Link**는 ESP32-C5 칩을 쓴 USB-C 동글이다. 집 Wi-Fi에 붙어 Philips Hue·Sonos·Apple TV·Google Nest·삼성 TV 등 로컬 HTTP API를 가진 기기를 Muse가 다루게 해 준다. "TV 켜 줘", "이 문서 출력해 줘" 같은 요청을 실제 기기에서 실행하는 식이다. 5,000대 한정으로, 미국의 Muse 구독자에게 1인 1대씩 무료로 10월 중 발송한다. 펌웨어는 새로 덮어쓸 수 없다.

choi.openai는 "새 폼팩터는 결국 기업이 직접 만들 것"이라는 예상과 달리, 메타가 SDK를 풀어 누구나 Muse용 기기를 만들게 한 점을 높게 평가했다. 오픈AI가 Codex를 오픈소스로 풀어 개발자 생태계를 넓힌 것처럼, 하드웨어에서도 "누구나 연결해 만들 수 있는 생태계"가 경쟁력이 된다는 해석이다. 다만 Runtime Wire는 코드가 오픈소스여도 **연결 자체는 메타가 발급하는 토큰에 묶여 있다**고 짚었다. 이용 약관상 이 토큰은 "지원되는 제품이나 개발자 플랫폼이 아니며" 언제든 회수될 수 있다. 토큰 하나당 기기는 50대까지이고, 서면 허가 없이 판매·배포할 수 없다. 원문 댓글에서는 "IoT 표준화부터 해 줬으면 좋겠다"는 반응이 나왔다.

### 데스크톱 에이전트 앱 경쟁 — DeepSeek Harness v0.2 설치형 배포, Gemini Desktop은 'Full Access' 권한 준비

데스크톱에서 파일과 앱을 직접 다루는 에이전트 앱 소식이 같은 날 두 건 나왔다.

- **DeepSeek Harness v0.2**: 딥시크 모델로 업무·코딩 작업을 실행하는 데스크톱 앱이 macOS(Apple Silicon·Intel)와 Windows 설치 파일로 나왔다. 리눅스는 npm 패키지 `@deepseek-ai/dsh`와 deb·rpm 패키지로 쓸 수 있다. 그동안은 Node를 직접 설치하고 CLI로 돌려야 했다. 이번 버전은 Node 24 런타임을 앱에 묶어 터미널 없이 바로 실행된다. 플러그인과 작업 공간(Workspaces)을 기본 지원하고, 앱 안에서 플러그인을 관리하며, 정해진 시간에 작업을 돌리는 예약 실행과 파일·코드 미리보기가 추가됐다.
- **Gemini Desktop "Full Access" (유출)**: testingcatalog에 따르면 최근 Gemini Desktop 앱에 아직 숨겨진 "추가 샌드박스 옵션" 설정이 들어갔다. 켜면 Gemini가 Mac의 모든 파일에 접근하고 어떤 앱이든 실행할 수 있다. 설정 문구에는 "설정에 따라 Gemini가 먼저 허락을 구하지 않고 행동할 수 있다"고 적혀 있다. 컴퓨터 사용 기능은 [9/30 공개된 Gemini 4 Argon](ai-news-2026-10-01.md) 계열이 맡을 것으로 보인다. 설정 문구는 Mac 기준으로 쓰여 있다.

원문 댓글에서는 "애플이 전체 디스크 접근 권한을 조이는 같은 주에 구글은 클릭 한 번으로 전체 접근을 여는 스위치를 시험한다. 이 스위치로 파일을 처음 유출하는 에이전트가 나오면 두 회사 모두 기준이 다시 정해질 것"이라는 지적이 나왔다. 편의와 노출 범위를 맞바꾸는 결정을 사용자 스위치 하나에 맡긴다는 점이 핵심 쟁점이다.

> 🔧 **적용 포인트** — 이 포트폴리오 저장소에는 `.env`의 API 키, RunPod 엔드포인트, 예약 작업 설정이 함께 들어 있다. 데스크톱 에이전트에 "전체 접근"을 주기 전에 작업 폴더를 저장소 하나로 좁히자. 비밀값은 저장소 밖(OS 키체인 등)으로 옮겨 두는 게 먼저다. Claude Code도 권한 설정에서 쓰기 허용 경로를 프로젝트로 한정해 두는 편이 안전하다.

### Meshy Edit — 3D 모델 전체가 아니라 고를 부분만 프롬프트로 고친다

3D 생성 서비스 Meshy가 모델 전체를 다시 만들지 않고 고칠 부분만 골라 수정하는 **Meshy Edit**를 공개했다. 수정할 영역을 고르고 원하는 내용을 입력하면 된다. 공개 데모에서는 조각상의 발만 골라 부츠를 신기거나, 캐릭터의 안경과 머리 장식만 바꿨다. 기존 Texture Edit(8월 Meshy 7)는 표면 텍스처만 다시 칠하는 기능이었다. 데모로 보면 이번에는 형태까지 부분 수정하는 쪽으로 넓어졌다. choi.openai는 이를 "3D 모델링계의 나노 바나나"라고 부르며, 3D 생성도 이미지처럼 "만들기"에서 "대화하며 고치기"로 넘어가고 있다고 평가했다.

다만 한계도 보인다. 데모에서도 고치지 않은 얼굴 일부까지 바뀌는 문제가 있었다. 10월 3일 현재 Meshy API 변경 기록에는 이 기능이 아직 올라오지 않았다. API로 쓸 수 있는지는 확인되지 않았다는 뜻이다.

> 🔧 **적용 포인트** — 프로젝트 쇼케이스에 쓰는 GLB 소품이나 캐릭터를 처음부터 다시 생성하지 않고 일부만 고칠 수 있다면 반복 비용이 크게 준다. 다만 고치지 않은 영역도 바뀔 수 있으니 결과 GLB를 그대로 덮어쓰지 말자. 기존 파일과 나란히 R3F 씬에 올려 비교한 뒤 교체하고, 폴리곤 수·텍스처 크기가 늘지 않았는지도 확인하자.
