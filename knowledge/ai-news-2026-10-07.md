## 판단 전용 API는 가격표를 달았고, 미공개 모델은 수학 원고 722편을 내놨다

DevDay에서 제한 프리뷰로 나온 오픈AI Decisions API가 일주일 만에 모든 개발자에게 열렸고, 처음으로 가격도 공개됐다. 같은 날 오픈AI는 아직 이름도 없는 내부 모델이 만든 수학 원고 722편을 깃허브에 올렸다. 앤트로픽은 Claude를 구글 문서 도구 안으로 넣었고, Codex의 '28일 연속 개선'은 2일차에 승인 검토 비용을 없앴다.

### 오픈AI Decisions API 퍼블릭 베타 — 입력 100만 토큰당 0.10달러·출력 무료, 판단 3종(predicate·choice·score)을 한 요청에 묶는다

[9/30 제한 프리뷰로 소개한 Decisions API](ai-news-2026-09-30.md)가 10월 6일(미국 시간) 퍼블릭 베타로 전환됐다. 문서·Playground와 함께 첫 가격이 나왔고, 정식 출시(GA)는 몇 주 안으로 예고됐다.

- **무엇을 돌려주나**: 답을 문장으로 생성하지 않고 세 형태 중 하나로 돌려준다. 조건이 참일 확률(**predicate**, 0~1), 미리 정한 선택지 중 하나와 신뢰도(**choice**), 순서가 있는 단계 기준에 따른 확률 가중 점수(**score**)다. 공식 예시는 "사진 속 캔이 찌그러졌나 → 1.00", "도로 그림에서 2번 차선 → 0.94" 같은 식이다.
- **입력·모델**: 텍스트, 또는 텍스트+이미지 메시지(이미지는 호스팅 링크가 아니라 base64 data URL만)를 받는다. 모델은 GPT-6 Luna 하나이고, 같은 Luna를 Responses API로 부를 때보다 약 10배 빠르다고 밝혔다. 데모 앱 화면에는 "API 처리 69ms, 결정 4개"가 찍혔다.
- **가격**: 입력 100만 토큰당 0.10달러이고, **출력·캐시 읽기/쓰기는 과금하지 않는다**. 답이 짧은 판단 작업 특성상 사실상 입력 토큰만 내는 구조다.
- **한 요청에 여러 질문**: 서로 독립적인 질문은 `questions` 배열 하나에 넣고 질문마다 다른 타입을 쓸 수 있다. 영업 메일 한 통에서 회사 유형·팀 규모·구매 단계·요구사항·일정·다음 단계를 한 번에 판정하는 식이다. 다만 앞 답에 따라 다음 질문이 달라지는 **의존 관계 판단은 호출을 나눠야 한다**.
- **주의할 점**: 오픈AI는 높은 확률은 자동 처리하고 애매한 건만 사람에게 넘기도록 "실제 데이터로 기준 확률을 정해 쓰라"고 안내한다. 앞서 나온 리뷰들도 이 신뢰도는 모델이 스스로 내놓는 값이라 실제 결과에 맞춰 보정된 것은 아니라는 점을 짚었다. 임계값은 직접 정답 셋으로 재봐야 한다.

> 🔧 **적용 포인트** — [10/1에 정리한 판단 모델 흐름](ai-news-2026-10-01.md)이 가격표까지 붙어 실사용 단계로 왔다. 도슨트 챗봇의 "이 질문은 어느 프로젝트/섹션에 관한 것인가(choice) · RAG 검색이 필요한가(predicate)"를 한 요청의 `questions` 배열로 묶어 보자. 질문 30~50개짜리 정답 셋을 만들어 Playground에서 먼저 정확도와 신뢰도 분포를 보고, 신뢰도 임계값 아래는 기존 LLM 경로로 넘기는 구조면 실패해도 손해가 없다.

### 오픈AI, 미공개 내부 모델의 수학 원고 722편 공개 — 문제 약 4,000개, 결과당 Pro 추론 평균 3시간, Lean 검증은 일부만

오픈AI가 공개하지 않은 내부 프런티어 모델이 만든 수학 결과를 `openai/math` 저장소에 올렸다. 원고는 722편이고, 핵심 결과·보조 정리·후속 결과·다른 증명을 묶어 372개 묶음으로 정리했다. 8월에 [Astra 이름으로 낸 10개 결과](https://dev.to/alifar/openai-publishes-lean-certified-proofs-for-ten-advances-in-math-and-computer-science-gn7)와 비교하면 규모가 수십 배 커졌다.

- **어떻게 만들었나**: 기존 수학 평가가 포화되자 미해결 연구 문제로 평가를 넓혔고, 약 4,000개 문제를 냈다. 결과 하나에 평균 ChatGPT Pro 추론 3시간 분량의 연산이 들었다. 출력물 중 일정 수준 이상 의미 있는 것만 골라 목록을 만들었다.
- **목록에 오른 이름들**: 모든 디리클레 L-함수가 실수부 7/8보다 큰 영역에서 영점이 없다는 준리만 가설형 결과, 힐베르트 10번 문제의 유리수판(변수 개수까지 입력에 포함할 때 유리수 해 존재를 판정하는 알고리즘이 없다), 카탈랑 상수의 무리성, 원주율의 무리성 지수가 정확히 2라는 결과, CM 아벨 다양체에 대한 호지 추측, 에르되시 추측 여러 개 등이다.
- **검증 상태**: 저장소는 "검증 단계가 서로 다른 결과가 섞여 있다"고 직접 적었다. Lean 형식화 표시가 붙은 묶음은 372개 중 235개이고, 형식화하지 않은 결과에는 오류가 있을 수 있다고 밝혔다. 리만 제타 함수 영점 영역과 호지 추측 결과는 정해진 절차 밖에서 얻은 예외였고, 11/12 영역 증명은 사람이 읽기 쉽게 다시 편집했다.
- **냉정하게 볼 점**: 모델 이름·가격·API는 없다. 수학계의 독립 검토도 이제 시작이다. 다만 결과마다 Lean 증명과 추론 요약(10개)을 함께 공개했다는 점에서 "AI가 풀었다"는 주장을 기계로 확인 가능한 형태로 내놓는 관행이 자리 잡는 중이다.

### Claude for Google Workspace 베타 — Docs·Sheets·Slides 사이드바에서 열린 파일을 직접 고친다

Claude가 Google Docs·Sheets·Slides 안 사이드바로 들어갔다. 반대로 Claude 웹·데스크톱에서 구글 파일 링크를 붙이거나 새 문서·시트·슬라이드를 만들어 달라고 하면 채팅 옆 패널에 파일이 열려 같이 편집할 수 있다. Pro·Max·Team·Enterprise 플랜에 베타로 제공된다.

- **설치·조건**: Google Workspace Marketplace에서 설치하는 확장이다(기존 Google Drive 커넥터와 별개). Chrome·Edge·Safari만 지원하고 Firefox는 안 된다. 회사 계정은 Workspace 관리자가 허용해야 한다.
- **편집 승인**: 기본값은 "편집 전 확인(Ask before edits)"이고 "모두 수락"으로 바꿀 수 있다. 모든 변경은 내 이름으로 버전 기록에 남는다. 웹 이미지 삽입·링크 추가·접근 권한 제거는 모드와 상관없이 항상 승인을 받는다.
- **한계**: 지금 열려 있는 파일 하나만 다룬다. 작업 한 번은 최대 6분이고, 다른 Drive 파일·Gmail·캘린더는 커넥터를 켜지 않으면 못 본다. 대화 기록은 브라우저·파일별로 로컬에만 남는다.
- **의미**: 구글이 Gemini를 넣어 둔 자리에 Claude가 정면으로 들어간 셈이다. 개발자에게는 시트 수식 작성·데이터 정리, 긴 문서 재구성 같은 주변 업무를 Claude 하나로 처리할 수 있게 된 정도의 변화다.

### Codex 28일 개선 2일차 — ChatGPT 로그인 사용자의 Auto-review 검토가 무료, 플랜 사용량에서 빠진다

[10/6에 다룬 '28일 연속 개선'](ai-news-2026-10-06.md)의 2일차 결과다. Codex가 "이 명령 실행해도 될까요?"라고 묻는 승인 요청 일부를 다른 모델이 대신 검토하는 **Auto-review**가, ChatGPT 계정으로 로그인한 사용자에게 무료가 됐다. 검토 자체는 플랜 사용량에서 차감되지 않는다.

- **켜는 곳**: Settings → Permissions → Auto-review. 검토에서 승인되면 작업을 이어가고, 거절되면 더 안전한 방법을 찾거나 사용자에게 다시 묻는다.
- **그대로인 것**: 본 작업은 계속 사용량을 쓴다. 파일·네트워크 접근 제한도 그대로이고, 사용자가 직접 승인해야 하는 경우도 남아 있다.
- **배경**: 몇 주 전 개발자 커뮤니티에는 auto-review가 백그라운드에서 사용량을 생각보다 많이 먹는다는 불만이 올라왔다. 오픈AI는 중복 생성·재시도 동작을 고치고 auto-review를 별도 항목으로 분리해 보여주는 조치를 했는데, 이번에 아예 과금 대상에서 뺐다.
- 티보의 28일 약속을 날짜별로 기록하는 비공식 사이트(Codex Resets)도 생겼다. 1일차는 Astra·Sol 기본 속도 약 50% 향상, 2일차가 이번 Auto-review 무료화다.

> 🔧 **적용 포인트** — Codex를 보조 워커로 돌릴 때 승인 요청 때문에 화면을 계속 지켜봐야 했다면 Auto-review를 켜 두자. 이제 비용 부담이 없다. 다만 네트워크·파일 접근 범위는 그대로 좁게 두고, 배포·git push처럼 되돌리기 어려운 명령은 직접 승인하는 기존 원칙을 유지하는 게 맞다.
