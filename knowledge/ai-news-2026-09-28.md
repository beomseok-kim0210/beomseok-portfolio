### 브라우저에서 도는 1.4억 파라미터 판단 모델 Julia-1 공개 — WebGPU로 결정 1건 약 75ms, Apache 2.0

Threads(choi.openai)에 따르면 슈퍼소닉 랩스가 여러 기기에서 로컬 실행에 초점을 맞춘 분류 모델 Julia-1을 공개했다. WebGPU를 지원해 브라우저에서도 돌아가며, 한 개발자는 M1 Pro에서 한 프로세스로 요청 10개를 약 0.93~0.96초에 처리했다고 공유했다. 웹서치로 확인한 MarkTechPost와 허깅페이스 모델 카드에 따르면, Julia-1은 브라질의 소규모 연구소가 9월 26일 공개한 1억 4,430만 파라미터 오픈웨이트 "판단(decision)" 모델이다. 문장을 생성하지 않고, 맥락·질문·후보 답변 목록을 받아 그중 하나를 고른다. 분류, 라우팅, 순위 점수, 예/아니오 판단에 쓰도록 만들어졌다. CPU나 BF16 GPU에서 파이썬으로 돌릴 수 있고, 별도 Julia-1-ONNX 저장소에는 전체 ONNX 변환본과 자바스크립트 WebGPU 어댑터가 들어 있다. 제작사는 리눅스 Brave 브라우저에서 워밍업 후 WebGPU로 판단 1건당 중앙값 75.47ms, 100건 모두 원본 모델과 같은 결과를 냈다고 밝혔다. 라이선스는 상업적 이용이 가능한 Apache 2.0이다.

> 🔧 **적용 포인트** — 도슨트 질문을 서버 LLM에 보내기 전에 브라우저에서 "어느 프로젝트/섹션 질문인가", "RAG가 필요한가, 인사말인가"를 Julia-1-ONNX로 먼저 고르면(후보 목록을 넘겨주는 구조라 딱 맞다), 간단한 질문은 서버 호출 없이 즉시 응답하거나 `pageContext`와 연결해 이동을 유도할 수 있다. 다만 모델 파일 다운로드 크기와 R3F 씬과의 GPU 공유 부담은 먼저 측정해야 한다.

### 텐센트 오픈웨이트 비디오 월드 모델 WorldCrafter — 3D 복원 없이 카메라 위치로 기억을 꺼내 공간 일관성 유지

같은 날 choi.openai는 텐센트가 공개한 비디오 월드 모델 WorldCrafter를 소개했다. 별도의 3D 공간을 직접 만들지 않고, 카메라 위치에 따라 메모리에서 필요한 정보를 꺼내 영상을 만드는 방식이라, 다른 곳을 봤다가 다시 돌아와도 이전 공간과 물체가 비교적 일관되게 유지된다. 이미지 한 장이나 텍스트만으로 몇 분간 공간을 돌아다닐 수 있고, 현재 해상도는 384×640이다. 웹서치로 확인한 GitHub(TencentARC/WorldCrafter)·허깅페이스 논문 페이지에 따르면 카메라 포즈나 행동 문자열로 조종하는 자기회귀 비디오 모델로, 33프레임 단위로 새 시점을 이어서 만든다. 표준 모델 WorldCrafter-Base와 적은 단계로 증류한 WorldCrafter-Fast 가중치, 추론 코드가 모두 공개됐다. 논문은 9월 21일 arXiv에 올라온 뒤 허깅페이스 Daily Papers 2위에 올랐다.

### 미니맥스 코딩 모델 M3.1-Flash-Preview 공개 — 100만 토큰·5단계 추론, 벤치마크·가격은 미공개

choi.openai에 따르면 미니맥스가 코딩용 새 모델 M3.1-Flash-Preview를 자사 에이전트 도구 MiniMax Code에서 먼저 공개했다. 빠른 버그 수정부터 전체 기능 개발까지 일상 개발 작업을 겨냥한 텍스트 모델이다. 웹서치로 확인한 Pandaily·APIMaster 보도에 따르면 컨텍스트는 최대 100만 토큰이고, low부터 새 max 단계까지 5단계 추론 슬라이더로 지연과 깊이를 조절한다. 현재는 Token Plan과 MiniMax Code에서만 쓸 수 있고 모델 카드·벤치마크·공개 가격은 없다. 최근 OpenRouter에 등장한 정체불명 모델 "Space Bunny Alpha"가 미니맥스 모델이라는 분석도 있었지만 이 모델과 같은지는 확인되지 않았다. 정식 공개 전 프리뷰라 성능 판단은 이르다.
