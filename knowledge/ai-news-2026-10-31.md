## Claude 상위 요금제가 이름을 바꿨고, 사이트 주인은 robots.txt 한 줄로 AI 학습을 거부할 수 있게 됐다

10월 30~31일 소식 네 가지를 골랐다. 두 가지는 Claude를 쓰는 개발자에게 바로 닿는 변화(요금제 개편, API 요청 크기 확대)이고, 하나는 웹사이트를 운영하는 사람이라면 확인해 둘 robots.txt 표준, 하나는 에이전트가 데스크톱 앱을 다루는 오픈소스 도구다.

### 앤트로픽, Max 5x는 Max·Max 20x는 Ultra로 — 가격은 100·200달러 그대로, 인증된 Ultra는 5시간 제한이 사라지지만 주간 한도는 Pro의 10배로 유지

testingcatalog가 10월 30일 처음 전했고, choi.openai가 다음 날 정리했다. Claude 공식 요금 페이지로 교차 확인했다.

- **무엇이 바뀌었나**: 기존 Max 5x(월 100달러)는 이름이 **Max**로, Max 20x(월 200달러)는 **Ultra**로 바뀌었다. 가격은 그대로이고 기존 구독자는 따로 할 일이 없다.
- **Ultra의 핵심**: 인증을 마친 Ultra 계정에는 5시간 단위 세션 제한이 없다. 신규 Ultra 계정은 인증 전까지 임시로 세션 제한이 걸릴 수 있다.
- **주간 한도는 그대로**: 요금 페이지 기준으로 Max는 5시간·주간 모두 "Pro의 5배", Ultra는 주간 "Pro의 10배"다. testingcatalog는 "10배"라는 숫자를 보고 한도가 줄었다고 오해하는 사람이 많다며 정리했다. 옛 Max 20x도 5시간 세션은 Pro의 20배였지만 주간 한도는 원래 Pro의 10배였다. 즉 Ultra는 **주간 총량은 같고, 5시간 단위 끊김만 없앤** 요금제다.
- **함께 알아둘 것**: Claude와 Claude Code는 같은 사용량을 나눠 쓴다. Fable은 Max·Ultra에서 주간 한도의 절반까지 포함되고, Pro에서는 사용량 크레딧으로 결제한다.
- **경쟁사 쪽 흐름**: btibor91은 10월 29일 ChatGPT 웹 결제 화면에 "12월부터 요금제 사용량은 ChatGPT와 Codex 전체에서 공유 한도로 묶인다"는 숨은 안내 문구가 생겼다고 전했다. 오픈AI의 공식 발표는 아직 찾지 못했다. 사실이라면 양쪽 모두 "채팅과 코딩 에이전트가 한 주머니를 나눠 쓰는" 구조로 가는 셈이다. 독자 댓글에도 이름보다 "긴 빌드 세션 도중에 끊기지 않느냐"가 궁금하다는 반응이 많았다.

> 🔧 **적용 포인트** — Claude Code로 포트폴리오 작업을 길게 돌리다 5시간 제한에 막히는 게 문제였다면 Ultra(옛 Max 20x)에서 계정 인증을 마쳐 두면 된다. 다만 주간 총량은 늘지 않았으니, 한 주에 큰 리팩터링을 몰아 돌리는 방식이라면 체감 차이가 없을 수 있다. Fable은 주간 한도의 절반까지만 포함된다는 점도 함께 계산해 둔다.

### 오픈AI·구글·마이크로소프트·앤트로픽, robots.txt 한 줄짜리 공통 AI 학습 거부 토큰 __usage_ai-training 지지 — 앤트로픽은 시작, 나머지는 몇 달~2027년

testingcatalog의 10월 31일 데일리 브리프에 실렸다. Data Studios·DEV Community 등 여러 보도로 교차 확인했다. 10월 30일 발표다.

- **무엇인가**: 지금까지는 GPTBot·ClaudeBot·Google-Extended처럼 회사마다 다른 이름을 각각 막아야 했다. 이번에는 네 회사가 **`__usage_ai-training`** 이라는 공통 토큰을 robots.txt의 `User-Agent` 줄에 쓰면 학습 거부 의사로 존중하겠다고 했다. 새 지시어는 없고, 평소처럼 `Disallow`·`Allow`를 쓴다.

```
User-Agent: __usage_ai-training
Disallow: /
Allow: /press-kit/
```

- **적용 시점**: 앤트로픽은 이미 적용을 시작했다. 오픈AI는 "앞으로 몇 달 안", 마이크로소프트는 2027년, 구글은 2027년 초다.
- **구글 쪽 주의점**: 구글 문서에 따르면 이 토큰으로 거부하면서 Google-Extended를 따로 적지 않으면, Google-Extended를 막은 것으로 본다. 그러면 Gemini가 그 사이트를 인용하는 데에도 영향이 있을 수 있다.
- **한계**: `User-Agent: *` 묶음은 학습 거부로 치지 않는다. 크롤링 자체를 막지도 않는다. robots.txt를 무시하는 스크레이퍼에는 소용이 없고, 이미 수집된 데이터에 소급되는지도 아무도 밝히지 않았다. 문서는 앤트로픽의 Kevin Kelley가 낸 IETF 개인 드래프트("Machine-Readable Training Preference Signal")로, 공식 표준 지위는 없다.

> 🔧 **적용 포인트** — 이 포트폴리오의 `src/app/robots.ts`는 지금 `userAgent: "*"`, `allow: "/"` 하나뿐이라 학습 선호를 표시하지 않은 상태다. 채용 담당자가 AI 검색으로 이 사이트를 찾게 하려면 지금처럼 두는 편이 낫다. 학습만 막고 싶다면 `rules`를 배열로 바꿔 `{ userAgent: "__usage_ai-training", disallow: "/" }`를 추가한다. 다만 구글은 이를 Google-Extended 차단으로 해석해 Gemini 인용까지 줄어들 수 있으니, 노출과 학습 거부 중 무엇이 중요한지 먼저 정한다.

### Claude API Messages 요청 최대 크기 32MB → 128MB — 배치 256MB·Files 500MB는 그대로, 클라우드 파트너는 여전히 20~32MB

testingcatalog의 10월 31일 데일리 브리프에 실렸다. Claude API 공식 문서로 교차 확인했다.

- **바뀐 값**: Messages와 Token Counting 엔드포인트의 요청 최대 크기가 32MB에서 128MB로 네 배가 됐다. 넘으면 전과 같이 413 `request_too_large` 에러가 난다.
- **그대로인 값**: Message Batches API 256MB, Files API 500MB, Managed Agents의 Sessions·Agents·Environments는 32MB다.
- **클라우드 경유 시**: Bedrock은 20MB, 구글이 운영하는 Google Cloud 버전은 30MB다. 앤트로픽이 운영하는 Claude Platform on AWS·Anthropic 관리형 Google Cloud·Microsoft Foundry도 Messages는 아직 32MB다. 128MB는 **앤트로픽 직접 API에서만** 쓸 수 있다.
- **의미**: 큰 PDF나 이미지를 base64로 한 번에 넣을 때 Files API를 거치지 않아도 되는 경우가 늘었다. 그래도 같은 파일을 여러 번 쓴다면 업로드 후 ID로 참조하는 편이 요청이 가볍다.

### Vercel Labs agent-desktop — 운영체제 접근성 트리로 데스크톱 앱을 읽고 조작, 기본은 포인터와 포커스를 빼앗지 않는 백그라운드 모드

choi.openai가 10월 31일 소개했고, 주간 정리에서도 "agent-desktop 1.0"으로 다시 다뤘다. GitHub 저장소로 교차 확인했다.

- **무엇인가**: 같은 팀의 agent-browser가 웹 브라우저를 다뤘다면, agent-desktop은 운영체제의 **접근성 트리**로 데스크톱 앱의 버튼·입력창을 읽어 에이전트가 조작하게 한다. Rust로 만들었고 Apache-2.0이다.
- **동작 방식**: 스냅샷을 찍으면 조작할 수 있는 요소마다 ref가 붙은 JSON이 나온다. 에이전트가 ref로 클릭·입력한 뒤 다시 스냅샷을 찍어 결과를 확인한다. 화면 픽셀을 맞추지 않는다. UI가 바뀌면 `STALE_REF` 에러가 나서 새 스냅샷을 찍게 한다.
- **백그라운드 기본값**: 기본 모드에서는 접근성 API로만 조작하므로 마우스 포인터를 움직이거나 창 포커스를 가져가지 않는다. 사람이 다른 일을 하는 동안 돌릴 수 있다. 실제 입력이 필요하면 `--headed` 옵션을 쓴다. choi.openai는 여러 에이전트가 각자 독립된 커서로 동시에 작업할 수 있다고 소개했는데, 저장소에는 `cursor-overlay` 명령만 보이고 자세한 설명은 없다.
- **지원 환경**: macOS(접근성 권한 필요)·Windows·Linux(그래픽 세션과 `at-spi2-core` 필요), x64·ARM64. npm으로 설치하는 CLI와, 프로세스 안에서 부르는 C 라이브러리를 함께 준다.
- **버전 표기**: choi.openai는 1.0이라고 했지만 저장소 첫 화면에서 정확한 릴리스 번호는 확인하지 못했다.
