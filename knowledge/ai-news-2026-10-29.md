## 새 지수 1위가 이틀 만에 바뀌었고, GitHub는 모델을 하나 고르는 대신 여러 개를 엮기 시작했다

오늘은 세 가지를 골랐다. 구글이 Gemini 4 Argon을 내놓은 지 2주 만에 Gemini 4 Carbon을 발표했다. 이틀 전 개편된 Artificial Analysis v5에서 바로 1위에 올랐지만, 지금은 사이버 방어 기관만 쓸 수 있다. GitHub는 Universe 2026에서 여러 모델과 작업 흐름을 묶는 Copilot Fusion을 정식으로 내놨다. 오픈AI는 ChatGPT Pro·Business 구독자에게 매달 API 크레딧을 주기 시작했다.

### 구글 Gemini 4 Carbon 공개 — Argon 2주 만에 Artificial Analysis v5 59점으로 1위, Terminal-Bench 4.0 65.2%·ExploitGym 54.8%, 지금은 Fairwind 사이버 방어 기관만 쓸 수 있다

choi.openai가 10개 연속분 스레드로 정리했고, testingcatalog가 Arena 순위를 따로 전했다. 구글 공식 블로그와 VentureBeat·Wccftech 보도, Vals AI 모델 페이지로 교차 확인했다. 10월 28일(미국 기준) 발표다.

- **출시 속도**: 구글은 9월 2일 Gemini 3.8 Flash, 9월 30일 Argon 발표, 10월 13일 Argon 정식 공개에 이어 Carbon까지 두 달 사이 모델을 네 번 냈다. 순다르 피차이 CEO가 직접 발표했고, 구글은 Carbon을 자사에서 가장 강한 모델이라고 소개했다.
- **종합 순위**: [어제 정리한 Artificial Analysis Intelligence Index v5](ai-news-2026-10-28.md)에서 Carbon은 59점이다. Opus 5.5(58), GPT-6 Astra(57), GPT-6.1 Sol(55)을 넘었고, Argon(50)보다 9점 높다. testingcatalog에 따르면 Arena에서는 Text Arena 1위(1528점), Agent Arena 2위(Opus 5.5 다음), WebDev Arena 4위(Opus 5.5·Astra·Sonnet 5.5 다음)다.
- **긴 작업과 코딩**: 구글 내부 팀에서는 Carbon이 며칠 동안 막다른 길을 돌아가며 큰 코드베이스의 숨은 버그를 끝까지 고쳤다고 한다. Terminal-Bench 4.0은 65.2%로 Opus 5.5(59.6%)와 Astra(59.1%)보다 5점 넘게 높다. 25만~100만 토큰 자료에서 연결 관계를 찾는 GraphWalks는 96.2%(Argon 84.2%)다. 다만 실제 개발 과제 FrontierSWE 2는 Astra(65.5%)가, 컴퓨터 사용 OSWorld-2.1은 Opus 5.5(87.2%)가 더 높다.
- **사이버 보안**: 취약점 찾기 SEC-bench Pro 88.2%(Astra 85.4%), 공격 가능성 검증 ExploitGym 54.8%(Astra 42.4%, Opus 5.5 34.5%), 근본 원인 수정 CWE-bench 71.0%로 모두 1위다. 크롬 팀은 고품질 패치를 만드는 데 다른 회사 대형 모델보다 10배 넘게 나았다고 했다. 구글은 이 점수를 안전장치 없이 쟀다고 밝혔다.
- **정렬**: Terminal-Bench 4.0에서 채점을 속이는 부정행위 성공률 0.0%, 시도율 0.4%였다. 구글 내부 코딩 환경의 심각한 정렬 이탈 경보는 80% 가까이 줄었다. 웹페이지·문서에 숨긴 지시로 모델을 조종하는 간접 프롬프트 인젝션 시험 Gray Swan에서는 공격 성공률 0%였다(Argon 0.7%, Opus 5.5 1.0%, Astra 8.5%, Sol 8.6%, Kimi K3 52.7%).
- **실무 평가**: Vals AI 지수는 70.36%로 2위다. 1위 Sonnet 5.5(70.85%)와 0.5점 차이고 Opus 5.5(70.18%)보다 높다. 테스트당 비용은 10.51달러로 Sonnet 5.5(18.70달러)·Opus 5.5(28.12달러)보다 싸다. 대신 Argon보다 출력 토큰을 64% 더 썼고, 늘어난 양은 대부분 금융·법률·세무 평가에서 나왔다. Argon 때 '벤치마크용 모델'이라는 내부 평가 보도가 있었는데, 이번에는 외부 평가기관 두 곳의 측정이 발표 당일 나왔다.
- **가격과 접근**: 구글 블로그 기준 출시 기념가는 Argon과 같은 100만 토큰당 입력 2달러·출력 10달러이고, 캐시된 입력은 95% 할인이다. 기념가가 언제 끝나는지는 공개되지 않았다. Wccftech와 Vals AI는 4달러·20달러를 표기하고 있어, 기념가 이후 가격과 섞인 것으로 보인다. 컨텍스트는 100만 토큰이다. 지금은 Fairwind 프로그램의 사이버 방어 기관만 쓸 수 있고, 개발자·기업·일반 공개 날짜는 정해지지 않았다.
- **독자 반응**: 댓글에서는 "Argon도 좋은데 사용량 한도가 너무 빨리 찬다"는 불만이 여럿이었다. "구글은 벤치마크의 왕"이라는 회의적인 반응도 있었다.

> 🔧 **적용 포인트** — 당장 API로 쓸 수 있는 모델이 아니니 지금 바꿀 것은 없다. 다만 일반 공개 때 확인할 숫자는 두 가지다. ① Gray Swan 간접 프롬프트 인젝션 0%는 도슨트처럼 외부 문서를 RAG로 읽어 오는 챗봇에 의미가 크다. ② WebDev Arena는 4위라서, Three.js·R3F 장면 작업은 지금 쓰는 Claude 쪽이 여전히 앞선다. 공개되면 같은 장면 수정 요청을 두 모델에 한 번씩 돌려 보는 정도로 비교하면 충분하다.

### GitHub Universe 2026 — 여러 모델을 엮는 Copilot Fusion 정식 출시, 저장소를 넘나드는 Copilot Projects와 이벤트로 돌리는 Copilot Automations

testingcatalog가 10월 28일 샌프란시스코에서 열린 GitHub Universe 2026 발표를 정리했다. Crypto Briefing·DEV Community·The Register 보도로 확인했다. GitHub 공식 블로그 원문은 직접 열어 보지 못해서 수치는 보도 기준이다.

- **Copilot Fusion**: 모델 하나로 부족할 때 여러 모델과 작업 흐름을 조율하는 모델 라우팅 서비스다. 미리보기 때 이름은 HydraFusion이었다. 같은 날 사티아 나델라 마이크로소프트 CEO도 인터뷰에서 "다중 서브에이전트와 로컬 모델을 묶는 에이전트 스웜"의 예로 이 기능을 들었다. 보도에 따르면 Fusion Max는 Artificial Analysis 코딩 에이전트 지수에서 Opus 5.5 Max와 2점 안쪽 차이였고, 작업당 비용은 약 절반, 시간은 40% 적게 들었다. 이 수치는 GitHub 자체 주장이고, 구독자 청구액이 아니라 작업당 평균 API 비용 기준이다.
- **Copilot Projects**: 작업이 어디까지 진행됐는지 한곳에서 보고, Copilot이 다음에 맡을 일을 지정한다. 여러 저장소에 걸쳐 에이전트 세션을 동시에 돌리며, 공개 미리보기로 나왔다는 보도가 있다.
- **Copilot Automations**: 작업을 한 번 정의해 두면 직접 실행하거나, 일정에 맞춰 돌리거나, GitHub·연결된 서비스의 활동에 반응해 실행한다.
- **Copilot dreaming**: 개인 메모리, 저장소 지침, 에이전트 스킬, 사용자 지정 지침을 어떻게 고치면 좋을지 Copilot이 제안한다.
- **보안 확장**: 사람과 에이전트가 방금 쓴 코드를 저장소의 코드 스캐닝 경고와 함께 하나의 Security 캔버스에서 검토한다.
- **요금과 인프라**: GitHub Enterprise 고객은 별도 Copilot 구독 없이 모든 기능을 쓰고 사용한 AI 크레딧만 낸다. 지금은 영업팀을 통해서만 되고 셀프서브는 나중이다. 장애를 줄이려고 CPU 코어 400만 개를 더 붙이고, Azure 다중 리전 이전을 내년 초까지 끝낸다고 했다.

> 🔧 **적용 포인트** — 이 포트폴리오는 Claude Code로 개발하니 Copilot으로 갈아탈 이유는 아니다. 눈여겨볼 건 'dreaming'의 발상이다. 지침 파일과 스킬을 에이전트가 주기적으로 점검해 고칠 곳을 제안하게 하는 것인데, Claude Code에서도 `CLAUDE.md`와 메모리 파일을 한 번씩 다시 읽고 낡은 내용·중복을 고르는 정리 작업을 일정에 넣어 두면 같은 효과를 얻는다.

### 오픈AI, ChatGPT Pro·Business 구독자에게 매달 API 크레딧 — Pro는 요금만큼 100·200·500달러, Business는 좌석당 20·100달러를 워크스페이스당 최대 500달러까지

choi.openai와 testingcatalog가 같은 날 전했다. 오픈AI 도움말 문서와 OpenAI Developers 공식 X 계정, 개발자 문서로 확인했다. [10월 9일 정리한 Claude Max·Team 월간 API 크레딧](ai-news-2026-10-09.md)과 같은 방향의 혜택이다.

- **금액**: Pro는 등급에 따라 매달 100·200·500달러로, 구독료와 같은 금액이다. Business는 유료 Standard 좌석당 20달러, Premium 좌석당 100달러를 합쳐 워크스페이스당 최대 500달러까지 준다.
- **받는 방법**: ChatGPT 결제 설정에서 직접 신청하고, API 조직 하나에 연결해야 한다. 오픈AI는 다음 단계로 ChatGPT나 Codex의 OpenAI Developers 플러그인으로 API 키를 만들라고 안내했다.
- **조건**: 남은 크레딧은 결제 주기가 끝나면 사라지고 이월되지 않는다. 주기 중간에 신청하면 첫 지급은 날짜만큼 줄 수 있다. 보도에 따르면 Enterprise·Edu·무료 체험·기존 Codex 좌석은 대상이 아니고, 구독을 7일 넘게 유지해야 한다. 크레딧이 ChatGPT나 Codex 사용 한도를 늘려 주지는 않으며, API 약관과 속도 제한은 그대로 적용된다.
- **맥락**: testingcatalog는 "테스트에 딱 필요한 것"이라고 평했다. 구독과 API 결제를 따로 내던 개인 개발자에게는 사실상 API 비용 일부를 구독료로 덮을 수 있게 된 셈이다.

> 🔧 **적용 포인트** — 도슨트 채팅 라우트가 오픈AI API를 쓰므로, ChatGPT Pro를 쓰고 있다면 이 크레딧을 도슨트용 API 조직에 연결해 운영비를 덮을 수 있다. 크레딧이 매달 사라지니, 코퍼스 재요약이나 질문 세트 평가처럼 미뤄 둔 배치 작업을 결제 주기 끝나기 전에 몰아서 돌리는 식으로 쓰면 낭비가 없다.
