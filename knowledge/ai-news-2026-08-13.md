## 프론티어 랩 내부 모델의 격차가 수학으로 증명되고, 오픈웨이트·가격 경쟁은 더 치열해진 하루

### 앤트로픽, 21년째 안 풀리던 하다마드 행렬 668차를 내부 클로드 모델로 해결 — 공개된 GPT-5.6 Sol Max·Claude Fable은 실패한 문제

Threads에 따르면 앤트로픽 연구원 레벤트 알푀게가 내부 전용 클로드 모델로 하다마드 행렬 668차를 찾아냈다. 하다마드 행렬은 모든 행과 열이 서로 직교하는 +1과 -1로만 이루어진 정사각 행렬로, 신호처리·오류정정부호·양자컴퓨팅의 기반이 되는 구조다. 4의 배수 차수에는 항상 존재할 것이라는 추측이 150년 넘게 이어져 왔는데, 668차는 2005년 이후 가장 작은 미해결 사례로 남아 있었다. 증명 자체는 +와 -로만 이루어진 문자열 하나로 압축되며, 668차가 풀리면서 2,000 미만의 모든 미해결 차수가 전부 해결됐다. 정작 일반에 공개된 GPT-5.6 Sol Max와 Claude Fable은 이 문제를 풀지 못했다는 점이 함께 알려지면서, 사람들이 실제로 쓰는 공개 모델과 프론티어 랩이 내부에만 쥐고 있는 모델 사이의 격차가 이번에 수학적으로 드러났다는 평가가 나왔다.

웹서치로 교차 확인한 Epoch AI의 FrontierMath 미해결 문제 목록(epoch.ai/frontiermath/open-problems/hadamard)에 따르면 이 문제는 "AI가 해결한 것으로 잠정 표시됨" 상태로 갱신됐으며, 앤트로픽 소속 3명의 인간 연구자와 클로드가 공동 크레딧으로 올라 있다. 제출된 해법은 기존에 알려진 Goethals-Seidel 구성법에 넣을 "시드" 문자열만 별도로 찾아내는 방식으로, 2,000 미만의 모든 처리되지 않은 차수에 대해 한 번에 하다마드 행렬을 만들어내는 형태였다. 다만 이 판정은 "사람이 핵심 수학적 아이디어에 상당히 기여했다"는 후속 보고가 나오면 다시 조정될 수 있다는 단서가 붙어 있다.

### 알리바바, 2.4조 파라미터 오픈웨이트 모델 Qwen3.8-Max 허깅페이스 공개 — 과금 전환 발표 이후에도 약속한 오픈웨이트는 지키다

Threads에 따르면 알리바바가 Qwen3.8-Max의 가중치를 허깅페이스에 공개했다. 총 2.4조 파라미터에 실제 추론 시 활성화되는 파라미터는 950억 개인 MoE 모델이다. 바로 지난주 대형 기업 대상 유료 전환 소식이 나왔던 터라 오픈웨이트 공개 자체가 불투명해 보였지만, 알리바바는 약속대로 가중치를 풀었다. 라이선스는 상업적 이용과 파인튜닝을 허용하되 초대형 AI 기업에만 별도 라이선스를 요구하는 방식이다. Gated DeltaNet과 Gated Attention을 결합한 새 아키텍처를 쓰고, 100만 토큰 컨텍스트와 FP8 버전도 함께 제공되며, 더 가벼운 27B 모델은 이틀 뒤인 금요일 공개 예정이라고 밝혔다.

웹서치로 교차 확인한 결과(huggingface.co/Qwen/Qwen3.8-2.4T-A95B, Latent Space AINews 등) 정확한 구조는 총 512개 전문가 중 라우팅되는 10개 + 항상 켜지는 공유 전문가 1개를 토큰마다 활성화하는 파인그레인 MoE이며, 풀 어텐션과 선형 어텐션을 섞은 하이브리드 구조를 쓴다. 출력 길이는 최대 12만 8천 토큰까지 지원한다. NVIDIA 기술 블로그는 이 모델을 GB300 NVL72급 인프라에서 구성 가능한 추론 강도로 서빙하는 방법을 별도로 다뤘고, 다른 분석 블로그들은 총 파라미터 기준으로 VRAM을 산정해야 한다는 점(활성 파라미터가 작다고 전체가 가벼운 게 아니라는 점)을 공통으로 지적했다.

### 딥시크, V4-Pro 정식판 공개 — 코딩 에이전트 성능 5배 뛰고 출력 가격은 Fable 5의 60분의 1

Threads의 11부작 스레드에 따르면 딥시크가 8월 13일 V4-Pro 정식판(모델명 `0813`)을 API와 딥시크 챗에 먼저 공개했다. 지난 4월 프리뷰를 대체하는 버전으로, 총 파라미터 1.6조 개 중 실제 활성화되는 파라미터는 490억 개, 컨텍스트 100만 토큰에 최대 출력 38만 4천 토큰이며 딥리즈닝·즉답 모드를 모두 지원한다. 앤트로픽 호환 API와 Codex 연동까지 열어 에이전트 환경에 바로 붙일 수 있게 했다. 프리뷰 대비 상승 폭이 가장 큰 항목은 실행형 과제였다 — 코딩 에이전트 평가 DeepSWE가 12.8→62.7로 거의 다섯 배, 보안 취약점 탐지 CyberGym이 52.7→83.3, 저장소 단위 코딩 NL2Repo가 38.5→61.5, 터미널 작업이 72.1→87.9로 뛰었다. 반면 지식 문답·수학 단답형에서는 이 정도 도약이 없었는데, 이는 파라미터를 늘린 효과라기보다 딥시크가 구축한 수십만 개 규모의 에이전트용 강화학습 샌드박스 환경이 확대된 결과로 해석됐다. 가격은 100만 토큰당 입력 0.435달러·출력 0.87달러(캐시 히트 시 입력 0.003625달러)로, Fable 5(입력 10달러·출력 50달러) 대비 출력 단가가 약 60분의 1이다. 다만 비교 기준이 최신 Opus 5가 아닌 직전 세대 Opus 4.8이었다는 지적, 독립 평가에서는 Kimi K3에 절반가량 항목에서 여전히 뒤졌다는 점, "벤치마크에만 최적화돼 정작 마인크래프트 클론 하나 제대로 못 만든다"는 혹평과 추론 강도를 최대로 두면 긴 작업을 끝까지 못하고 중간에 멈춘다는 문제 제기도 함께 소개됐다. 가중치는 아직 공개되지 않아 외부 재검증은 불가능한 상태다.

웹서치로 교차 확인한 Unite.AI·gmicloud·digitaltoday·wccftech 등에 따르면 실제 공개 시점은 8월 13일 오후 11시(베이징 시각)경이었고, 기존 API 사용자는 모델 ID를 바꿀 필요 없이 `deepseek-v4-pro` 요청이 자동으로 0813 빌드로 라우팅된다. 다만 wccftech는 딥시크가 근시일 내 API 가격을 상당폭 인상할 계획이라고 밝혔다고 전해, 지금의 파격가가 계속 유지되지는 않을 수 있다는 점도 짚었다. 같은 날 xAI의 Grok 4.6, 알리바바의 Qwen3.8-Max까지 겹쳐 나오면서, 최고 성능 경쟁보다 "비슷한 지능을 누가 더 싸게 제공하느냐"가 새로운 경쟁축으로 떠올랐다는 평가가 스레드 안에서도 나왔다.

> 🔧 **적용 포인트** — 이 포트폴리오의 `/docent` 챗은 `src/app/api/docent/chat/route.ts`에서 `new Anthropic()`을 인자 없이 생성하고 `DOCENT_MODEL` env로 모델명만 바꾸는 구조다. Anthropic 공식 SDK는 `baseURL`을 명시하지 않으면 `ANTHROPIC_BASE_URL` 환경 변수를 그대로 읽으므로, DeepSeek가 이번에 공개한 앤트로픽 호환 엔드포인트(`https://api.deepseek.com/anthropic`)를 `ANTHROPIC_BASE_URL`에, DeepSeek API 키를 `ANTHROPIC_API_KEY`에, `DOCENT_MODEL=deepseek-v4-pro`를 넣으면 코드 변경 없이 도슨트 라이브 챗을 훨씬 싼 비용으로 돌려볼 여지가 있다. 다만 딥시크가 곧 가격을 올릴 수 있다고 밝힌 만큼, 실제 전환 전에 그 시점의 가격을 다시 확인하는 게 안전하다.
