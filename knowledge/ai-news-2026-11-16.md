## 중국 두 회사가 같은 날 100만 토큰 모델을 냈다 — 알리바바는 값을 내린 플래그십, 텐센트는 출력 2위안짜리 실행용 모델, 둘 다 코딩 점수에선 한발 물러섰다

### 알리바바 Qwen4-Max — 2.4조 파라미터 MoE(활성 710억)·100만 토큰 컨텍스트에 입력 1.5달러·출력 4.5달러로 값을 내렸고, 법률 에이전트 벤치에선 1위지만 코딩·터미널 과제는 Opus 5.5·Kimi K3.1에 크게 밀린다

알리바바 Qwen 팀이 Qwen4 세대의 첫 모델 **Qwen4-Max**를 내놨다. 총 2.4조 파라미터의 희소 MoE로 토큰마다 약 710억 개만 쓰고(전작 Qwen3.8-Max는 약 950억으로 추정), 텍스트·이미지·영상을 입력받으며 컨텍스트는 100만 토큰, 최대 출력은 39만 3천 토큰이다. **가중치는 공개하지 않는다** — QwenCloud API와 구독형 Token Plan, Qwen Studio·Qoder 등으로만 쓸 수 있다.

- **구조 변화**: Gated DeltaNet 3층마다 'Qwen Sparse Attention' 1층을 끼워 긴 문맥을 고정 크기 상태로 압축하고 필요한 부분만 골라 보는 방식, 4갈래로 나뉜 게이트형 잔차 연결, 지역 토큰 패턴을 조회하는 3,280억 파라미터짜리 N-gram 임베딩을 더했다. 알리바바는 같은 데이터에서 Qwen3.8-Max-Base보다 bits-per-byte가 5~13% 낮다고 밝혔다.
- **가격**: 100만 토큰당 입력 1.5달러(전작 2달러), 출력 4.5달러(6달러), 캐시 읽기 0.075달러(0.25달러, 70% 인하). 여기에 토큰 사용량 자체도 줄어 자사 Work360 기준 과제당 평균 비용이 4.43달러→1.67달러로 약 62% 내려갔다고 한다.
- **벤치마크(알리바바 자체 차트, 독립 재현 없음)**: 16개 중 4개에서 1위 — 법률 에이전트 HLAB-Vals 1.1 21.3점(Kimi K3.1 11.7, Opus 5.5 9.2), DeepSWE v1.1 75.7점(Kimi 75.5, Opus 74.2) 등. 반면 **ProgramBench 31.5점(Opus 5.5 65.0)**, **Terminal-Bench 4.0 48.5점(Kimi 67.2)**, 차트 이해·HLE에서는 뚜렷하게 뒤진다. 16개 중 7개는 Opus 5.5가 1위였다.
- **제3자 지표**: TestingCatalog에 따르면 Artificial Analysis 지수에서 xhigh 추론 기준 43점으로 Muse Wonder보다 1점, Kimi K3.1 Pro(max, 46점)보다 3점 낮고 Qwen3.8-Max보다는 9점 높다. 실제 사용자 에이전트 세션 1만 4,700건을 집계하는 Agent Arena에는 종합 14위로 들어왔다.
- **API**: 모델 ID `qwen4-max`. OpenAI 호환·Anthropic 호환 클라이언트를 모두 지원하고, 함수 호출·구조화 출력·컨텍스트 캐시·배치·웹 검색·파인튜닝을 쓸 수 있다. 사고 모드는 `enable_thinking`으로 켠다.

TNW 등은 성능 수치가 알리바바 자체 발표라 검증되지 않았다는 점과, Qwen3.8 때와 달리 오픈 가중치가 없다는 점을 짚었다. 정리하면 "프런티어급 에이전트 모델을 절반 이하 값에"라는 주장이지만, 코딩 에이전트 용도로는 아직 Opus 5.5·Kimi K3.1과 거리가 있다.

> 🔧 **적용 포인트** — Anthropic 호환 API를 지원하므로 도슨트(/docent)처럼 Claude Messages 형식으로 짠 호출부는 base URL과 모델 ID만 바꿔 같은 질문 세트로 비교해볼 수 있다. 100만 토큰 문맥에 캐시 읽기 0.075달러라 큐레이션 코퍼스 전체를 앞에 고정해 두는 실험엔 단가가 유리하다. 다만 ProgramBench·Terminal-Bench 격차가 커서 Claude Code를 대신할 코딩 모델로 갈아탈 근거는 못 된다.

### 텐센트 Hy4 Flash — 활성 120억 파라미터·100만 토큰 컨텍스트에 출력 100만 토큰당 2위안, 내부 업무 벤치에선 상위 모델 Hy4 프리뷰와 비슷하다지만 터미널 과제 점수는 Hy4의 절반 이하

텐센트 훈위안(Hunyuan) 팀이 같은 날 Hy 계열 첫 Flash 모델 **Hy4 Flash**를 공개했다. 총 2,240억 파라미터(이 중 640억은 조회형 'Engram' 메모리) 가운데 토큰당 120억 개만 쓰고, 멀티모달 입력과 100만 토큰 컨텍스트를 지원한다.

- **가격**: 100만 토큰당 입력 0.5위안·출력 2위안·캐시 적중 0.02위안(Hy4는 6·18·0.3위안). TestingCatalog는 달러로 입력 0.07달러·출력 0.281달러로 전했다. 11월 30일까지 Tencent Cloud TokenHub API는 반값, WorkBuddy에서는 무료다.
- **어떻게 싸졌나**: 사전학습에 하이브리드 어텐션·LatentMoE·Engram을 넣어 KV 캐시를 Hy4의 6분의 1(Hy3의 24분의 1)로 줄였고, Hy4에서 증류한 뒤 강화학습으로 과제당 출력 길이를 절반으로 줄였다. 추론은 메가커널·4비트 양자화로 초당 150토큰 이상을 낸다고 한다.
- **성능 — 근거의 성격에 주의**: 대표 수치는 비공개 내부 벤치마크 **WorkIndex**(슬라이드·문서·스프레드시트 편집, 음성·영상 처리 등 WorkBuddy 업무)에서 나왔다. 여기서 7,700억 파라미터 Hy4 프리뷰를 약간 앞서고 과제당 비용은 Hy4의 20분의 1이라는 주장이다. 사내 사용자 85명의 블라인드 테스트에선 만족도가 Claude Haiku 5.5에 근접했다고 한다. 반면 공개 벤치인 **Terminal-Bench 4.0은 19.2점으로 Hy4(44.4점)의 절반에도 못 미치고**, 텐센트 스스로도 긴 코딩 과제는 Hy4를 쓰라고 권한다.
- **제공처**: TokenHub(모델 ID `hy4-flash`), WorkBuddy·위안바오·WeCom 등에 적용됐고 OpenRouter 등록 예정. 오픈소스 공개 계획은 밝혔지만 발표일 기준 가중치·라이선스는 나오지 않았다.

문서·슬라이드·딥서치·간단한 프런트엔드 같은 '업무 실행' 쪽은 싸게 맡기고, 긴 소프트웨어 작업은 큰 모델에 남기는 분업형 포지션이다. 메타 Muse Ember·구글 Gemini 4 Hydrogen에 이어 실행용 저가 모델 경쟁이 중국 쪽으로도 번진 셈이다.
