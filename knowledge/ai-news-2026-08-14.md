## 모델 업데이트 주기가 짧아지고, 추론 속도가 새 경쟁축이 되고, 클로드 코드 세션끼리 말을 거는 하루

### 구글, 사전학습 없이 3주 만에 제미나이 3.7 플래시 출시 — 코딩 벤치마크 대폭 상승에 가격은 반값

Threads의 14부작 스레드에 따르면 구글이 8월 13일 Gemini 3.7 Flash를 공개했다. 직전 모델인 3.6 Flash가 나온 지 불과 3주 만이다. 실제 개발 과제를 평가하는 FrontierCode 1.1에서 34.4%→43.6%, 긴 호흡의 소프트웨어 작업을 평가하는 DeepSWE v1.1에서 49.0%→65.3%로 올랐고, 웹 개발 블라인드 평가 WebDev Arena에서는 순위가 19위에서 8위로 뛰었다. 구글이 밝힌 핵심은 사전학습을 다시 돌리지 않았다는 점이다. 아키텍처·학습 데이터·하드웨어는 3.6과 동일하고, 문제를 풀고 행동하는 추론 알고리즘만 손봐 이 정도 상승폭을 만들었다. 가격은 100만 토큰당 입력 0.75달러·출력 3.75달러로 3.6 Flash 대비 반값이지만, 이 가격은 2026년 12월 31일까지만 적용되고 2027년 1월 1일부터는 입력 1.5달러·출력 7.5달러로 원래대로 돌아가는 한시적 할인이다. 같은 스레드는 구글 딥마인드의 리더십 변화도 함께 짚었다 — 데미스 하사비스가 CEO에서 의장으로 물러나고 27년차 수석과학자 제프 딘이 회사를 떠났으며, 5월 I/O에서 예고한 최상위 모델 Gemini 3.5 Pro는 여섯 달째 출시되지 못한 채 Flash 라인만 석 달 사이 세 번 업데이트됐다는 지적이다.

웹서치로 교차 확인한 VentureBeat·officechai·buildfastwithai·techtimes 등에 따르면 벤치마크 수치와 가격 구조는 Threads 스레드와 일치했으며, 이 가격이 GPT-5.6 Terra(입력 2달러·출력 12달러)와 Claude Sonnet 5(입력 2달러·출력 10달러)를 크게 밑도는 수준이라는 점도 공통으로 다뤄졌다. VentureBeat는 이를 "50% 도입 할인"으로 표현하며 한시적 성격을 강조했다.

### 오픈AI, GPT-5.6 Sol 초고속 모드 'Ultrafast' 프리뷰 공개 — Cerebras 힘 빌려 초당 750토큰, 표준 대비 최대 14배

Threads에 따르면 오픈AI가 GPT-5.6 Sol의 초고속 모드 'Ultrafast'가 실제로 작동하는 영상을 공개했다. 같은 프롬프트로 3D 창고 시뮬레이터를 만드는 과정을 표준 모드와 나란히 보여줬는데, 응답이 눈에 띄게 빠르게 나온다. 아직 일부 고객 대상 API 프리뷰지만, 음성 상담·코딩·금융 리서치처럼 답변 대기 시간이 곧 비용인 업무에서 속도 자체가 제품 경쟁력이 되는 흐름을 보여준다는 평가다.

웹서치로 교차 확인한 오픈AI 공식 발표(openai.com/index/previewing-ultrafast)·TechCrunch·9to5Mac·Cerebras 공식 블로그에 따르면 Ultrafast는 Cerebras 하드웨어로 구동되며 표준 모드의 초당 약 53토큰 대비 최대 14배 빠른 초당 750토큰을 낸다. 오픈AI는 속도를 높이면서도 지능 수준은 표준 GPT-5.6 Sol과 동일하게 유지했다고 밝혔다. 현재는 API를 통한 제한적 프리뷰 단계이며, 금융 리서치·인시던트 대응·고객 지원·음성 애플리케이션·커머스·실시간 실험 등 응답 지연이 치명적인 용도를 우선 타깃으로 삼는다고 설명했다.

### 앤트로픽, 클로드 코드에 세션 간 메시징 기능 반영 — v2.1.224부터 로컬 세션끼리 요약 메시지 주고받아

Instagram(@ai.trend.kr)에 따르면 클로드 코드가 업데이트되면서 세션(터미널 창)끼리 직접 메시지를 주고받을 수 있게 됐다. 한쪽 세션에서 알아낸 내용을 다른 세션에 전달해달라고 말만 하면 클로드가 알아서 요약해 보내주고, 시키지 않아도 필요한 순간엔 클로드가 먼저 옆 세션에 알려주기도 한다. 같은 컴퓨터 안에서 오간 메시지는 앤트로픽 서버를 거치지 않고 소켓으로 바로 전달된다.

웹서치로 교차 확인한 앤트로픽 공식 문서(code.claude.com/docs/en/cross-session-messaging)·9to5Mac에 따르면 이 기능은 8월 7일 Claude Code v2.1.224부터 macOS와 Linux(WSL 2 포함)에서 제공되며, 네이티브 Windows는 지원하지 않는다. 클로드는 `ListAgents`로 메시지를 보낼 수 있는 세션 목록을 확인하고 `SendMessage`로 이름을 지정해 전달하는데, 넘어가는 건 대화 기록이나 파일이 아니라 클로드가 직접 작성한 요약 텍스트뿐이다. 같은 기기의 다른 세션은 소켓을 통해 즉시 전달되고, 다른 기기의 세션이나 웹의 클라우드 세션은 Remote Control 연결을 거쳐 앤트로픽 서버를 통해 전달된다. 수신 세션의 권한 설정은 그대로 유지되어, 메시지가 다른 세션의 승인되지 않은 작업을 대신 승인하거나 설정을 바꿀 수는 없다. 병렬 워크트리에서 작업할 때 한쪽에서 반영된 변경 사항을 다른 쪽에 알리거나, 오래 걸리는 마이그레이션·테스트 작업이 끝났을 때 지켜보던 세션에 상태를 보고하는 용도로 안내되고 있다.

> 🔧 **적용 포인트** — 이 포트폴리오 저장소를 여러 터미널 세션으로 동시에 작업할 때(예: 한쪽에서 `npm run dev`를 띄워두고 다른 쪽에서 컴포넌트를 고치는 식, 혹은 두 개의 git worktree로 기능을 나눠 작업하는 식) 바로 써볼 수 있는 기능이다. `/list-agents`(`/peers`)로 현재 열린 다른 세션을 확인한 뒤, "다른 세션에 지금 라우트 구조 바꾼 내용 알려줘" 같은 프롬프트로 컨텍스트를 복사-붙여넣기 하지 않고 세션 간에 넘길 수 있다. Claude Code v2.1.224 이상, macOS/Linux(WSL 2 포함)에서만 동작하며 별도 설정 없이 기본 켜져 있다.
