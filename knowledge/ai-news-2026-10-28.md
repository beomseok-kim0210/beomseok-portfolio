### 앤트로픽, 에이전트가 전문가의 판단을 얼마나 끌고 가는지 무작위 실험으로 측정 — 분석가 50명이 Claude Code가 동전 던지기로 정한 쪽을 86% 따라갔고, 77%는 에이전트의 논리를 자기 말처럼 되풀이했다

choi.openai가 스레드로 정리했고, 앤트로픽 연구 페이지와 논문("Who's Aligned to Whom?", Amaç Herdağdelen·Hailey Joren·Alex Tamkin)으로 내용을 확인했다. 10월 27일 공개된 연구다.

- **실험 설계**: 인과추론 경험이 있는 분석가 61명을 모았고, 에이전트를 쓰지 않기로 한 11명을 빼고 50명을 분석했다. 50명 중 65%는 석·박사이거나 경력 6년 이상이었다. 이들은 웹 VS Code에서 Claude Code(Claude Opus 4.8, High effort)로 가상의 농업협동조합 유료 컨설팅이 효과가 있는지 평가했다. 이사회가 정한 확대 기준은 생산성 3~4% 향상이었다. 작업 시간 중앙값은 65분이었다.
- **정답이 없는 판단 4개**: 생산성 지표(헥타르당 수확량 대 운영비 대비 수확량), 비교 방식(이중차분 대 통계 보정 수준 비교), 분석 범위(가입 농가 대 조합 전체), 가중치(농가 동등 대 대형 농가 가중)다. 판단 하나가 효과 추정치를 몇 %포인트씩 움직였다. 연구진은 동전 던지기로 에이전트가 어느 쪽을 밀지 몰래 정했다. 에이전트에게는 가장 설득력 있게 주장하되 증거가 반대면 생각을 바꾸고, 결과를 왜곡하지 말라고 지시했다.
- **결과**: 분석가는 판단 4개에서 에이전트가 민 쪽을 86% 골랐다. 영향이 없었다면 50% 근처여야 한다. 판단별로는 생산성 지표 92%, 비교 방식 82%, 분석 범위 81%, 가중치 90%였다. 에이전트가 어느 쪽으로 기우느냐에 따라 같은 선택을 한 비율이 62~82%포인트씩 벌어졌다.
- **최종 권고**: 영향이 줄었지만 사라지지는 않았다. 에이전트가 확대 쪽이면 54%, 반대면 36%가 확대를 권했다. 동전 던지기 4번의 결과만으로 최종 권고의 82%를 맞힐 수 있었다. 가장 흔한 답만 찍으면 61%다.
- **알아챘나**: 대부분 몰랐다. 52%는 최종 권고가 에이전트보다 자기 판단에 가깝다고 답했다. 77%는 사후 설문에서 에이전트의 논리를 되풀이했고, 일부는 문장까지 같았다. 에이전트 덕이라고 밝힌 사람은 15%였다. 연구의 목적이 AI 영향이라고 짐작한 사람은 48명 중 6명이었고, 에이전트의 선호가 조작됐다고 의심한 사람은 없었다.
- **미리 의견이 있었을 때**: 분석가가 먼저 의견을 밝힌 38건에서, 에이전트가 반대하면 60%가 의견을 바꿨다. 에이전트가 동의하면 6%만 바꿨다. 다만 표본이 작아 신뢰구간이 넓다(24~82%포인트). 논문에는 43분 동안 자료를 공부하고 직접 분석 계획까지 세운 분석가가 나온다. 에이전트가 두 판단에서 다른 방식을 권하자 "Okay, let use you recomendation"이라고 답하고 그대로 따랐다.
- **누가 먼저 말했나**: 대화 기록을 보면 판단의 77%에서 에이전트가 먼저 의견을 냈다. 사람이 먼저 묻기 전에 에이전트가 방향을 정해 버리는 흐름이 대부분이었다.
- **실력으로도 못 막았다**: 경력, 스스로 평가한 전문성, 학력, 인과추론 퀴즈 점수, AI 신뢰도, AI 사용 빈도, 성향, 성별, 나이까지 10가지 특성을 봤다. 에이전트를 더 따른 사람을 가려 주는 특성은 사실상 없었다. 나이만 의미 있게 나왔지만 여러 특성을 한꺼번에 검정한 점을 보정하자 사라졌다.
- **에이전트 없이 한 사람들**: 11명 중 6명(55%)이 심각한 방법론 오류를 냈다. 에이전트 사용자는 50명 중 3명(6%)이었다. 하지만 이 그룹은 스스로 선택했고 경험도 적어서, 연구진은 인과관계로 읽지 말라고 했다.
- **한계**: 에이전트의 성향을 일부러 강하게 만들었으므로 실제 영향은 더 작을 수 있다. 과제 하나, 분야 하나, 모델 하나였다. 성향을 주지 않은 Claude는 123번 중 112번 같은 선택을 했다. 즉 평소에는 모델의 기본 선호가 일관되게 한쪽으로 작용한다는 뜻이기도 하다. 다만 성향을 주지 않은 에이전트는 선호가 더 약했고, 때로는 사용자에게 반박하기도 했다고 연구진은 덧붙였다.

앤트로픽은 "AI를 덜 쓰자는 주장이 아니다"라고 선을 그었다. 대신 몇 가지 방향을 제시했다. 에이전트가 갈림길마다 양쪽의 가장 강한 근거를 내놓거나, 먼저 사람의 의견을 묻게 하는 설계가 있다. 조직은 어떤 판단을 사람이 직접 내려야 하는지 정하고, 그럴 시간을 줘야 한다. 연구진은 같은 모델에 판단을 맡긴 여러 팀의 결과가 서로 독립적이지 않고 같은 방향으로 치우칠 수 있다고도 지적했다. 사람이 승인하는 '휴먼 인 더 루프'도, 그 사람의 판단이 정말 자기 것일 때만 의미가 있다.

독자 댓글에서는 "질문하는 사람이 처음부터 가닥을 잡고 묻기 때문에 생기는 순환 아니냐"는 반론이 나왔다. 하지만 이번 실험은 에이전트의 성향을 사람이 아니라 동전 던지기로 정했기 때문에, 질문자의 성향으로는 설명되지 않는다.

개발자에게도 바로 해당되는 이야기다. 코딩 에이전트는 상태 관리 방식, 라이브러리 선택, 테스트 범위처럼 정답이 없는 결정을 하루에도 수십 번 제안한다. 이번 실험은 경험 많은 전문가도 그 제안을 자기 결론처럼 받아들인다는 점을 숫자로 보여 줬다.

### Artificial Analysis Intelligence Index v5 — 60%를 비공개 시험으로 바꾸자 Opus 5.5 58·GPT-6 Astra 57·GPT-6.1 Sol 55, 과학 영역은 GPT가 가져가고 오픈웨이트와의 격차는 3점에서 12점으로 벌어졌다

choi.openai가 정리했고, Artificial Analysis의 공식 발표문으로 수치를 확인했다. 1월 v4 이후 가장 큰 개편이다.

- **구성**: 지식 노동·코딩·과학·일반 지식 네 영역이 25%씩이다. 시험 9개 가운데 6개는 모델이 코드 실행 같은 도구를 써서 직접 일을 끝내야 한다. 처음으로 전체의 약 60%가 문제나 정답이 공개되지 않은 시험이다. 공개 시험을 학습 데이터로 외우는 문제를 줄이려는 것이다.
- **바뀐 시험**: 새로 들어간 것은 비공개 코딩 시험 FrontierCode 2.0(15%)과 Terminal-Bench-Science(15%)다. Terminal-Bench-Science는 생명과학·물리·수학 등 5개 분야의 실제 연구 과정 70개를 터미널에서 수행하고, 과제의 모든 검사를 통과해야 점수를 준다. CritPt v2는 출시 당시 최신 모델들이 이미 다 푼 30문제를 빼고 어려운 40문제만 비공개로 남겼다. Humanity's Last Exam은 HLE-Diamond로 바뀌었다. GDPval-AA, SciCode, AA-LCR은 빠졌다.
- **순위**: Claude Opus 5.5가 58점으로 1위를 지켰다. GPT-6 Astra가 57점, GPT-6.1 Sol이 55점으로 뒤를 이었다. 이어서 Sonnet 5.5가 54점, GPT-6.1 Terra가 51점이다. 상위 5개를 앤트로픽과 오픈AI가 모두 차지했다. 9월 말 v4.3.2에서 Astra와 Sol은 53·52점으로 Opus·Sonnet·Fable 아래였다. 반면 Gemini 4 Argon과 Muse Wonder Full은 50점, Fable 5.1은 49점으로 밀려났다.
- **과학 영역이 순위를 바꿨다**: Terminal-Bench-Science에서 Astra 63%, Opus 5.5 59%, Sol 58%였다. CritPt v2 어려운 문제에서는 Astra 72%, Sol 69%, Opus 5.5 61%였다. 과학 시험 두 개의 1위를 모두 GPT가 가져갔다.
- **코딩만 보면**: FrontierCode 2.0은 Cognition이 만든 비공개 코딩 시험이다. 실제 오픈소스 저장소 132곳에서 에이전트가 고친 코드를 관리자가 병합해 줄지를 기준으로 채점하고, 필수 기준을 하나라도 어기면 0점이다. 여기서 Opus 5.5가 46%로 1위였고 Astra·Terra·Sonnet 5.5가 42%로 뒤를 이었다. Terminal-Bench 4.0에서는 Kimi K3.1 Pro가 67%로 가장 높았다. HLE-Diamond는 Opus 5.5 68%, Astra 64%였다. 9개 시험을 모두 1위 한 모델은 없었다.
- **에이전트형 시험이 중심이 됐다**: Terminal-Bench-Science, Terminal-Bench 4.0, AA-Briefcase, FrontierCode 2.0 네 개가 지수 비중의 55%지만, 모델이 쓰는 출력 토큰으로는 88%를 차지한다. 과제당 출력 토큰 중간값도 3만 5천 개에서 5만 9천 개로 늘었다.
- **과제 하나에 드는 비용**: Opus 5.5는 10.04달러, Astra 6.24달러, Sol 1.27달러였다. Sol은 Opus 5.5보다 3점 낮은 점수를 약 8분의 1 비용으로 냈다. 상위 10개 중 가장 싼 건 GPT-6.1 Terra(0.96달러), 가장 비싼 건 Fable 5.1(13.04달러)이다.
- **추론 강도가 훨씬 중요해졌다**: Opus 5.5는 가장 낮은 강도에서 35점, 최고 강도에서 58점으로 23점 차이가 났고, 비용은 0.98달러에서 10.04달러로 10배 뛰었다. 강도별 점수 차는 Sonnet 5.5가 20점에서 29점으로, Sol은 10점에서 20점으로 벌어졌다. 오래 붙잡고 일해야 하는 시험이 늘면서, 같은 모델이라도 설정에 따라 순위표 위치가 크게 달라진다.
- **오픈웨이트와의 격차**: 오픈웨이트 쪽 1위는 아직 가중치를 공개하지 않은 Kimi K3.1 Pro로 46점, 선두와 12점 차다. v4.3에서는 3점 차였다. [10/24 Kimi K3.1 Pro 공개](ai-news-2026-10-24.md) 때 "Opus 5.5와 3점 차"로 소개했던 거리가 새 지수에서는 네 배로 늘어난 셈이다. 가중치가 이미 공개된 모델 중에서는 DeepSeek V4.1 Flash 1017과 GLM-5.3이 32점으로 가장 높다. Claude Haiku 5.5(36점)보다도 낮다.
- **Progress Index v1**: 2022년 11월 이후 나온 언어 모델들을 하나의 능력 척도에 놓아 시간에 따른 변화를 비교하는 지표도 함께 나왔다. 현재 모델 비교는 여전히 Intelligence Index가 기준이다.
- **이 지수로 알 수 없는 것**: v5는 텍스트·영어 중심이다. 이미지·음성·다국어(한국어 포함)는 따로 잰다. 긴 문서 추론 시험 AA-LCR이 빠져서 긴 문맥 능력도 지수에 들어가지 않는다. 일부 시험은 LLM이 채점하고, Artificial Analysis 자체 실행 환경(Stirrup)에서 돌린 결과라는 점도 감안해야 한다.

종합 점수는 가중치를 어떻게 주느냐에 크게 좌우된다. 이번 개편에서 과학이 4분의 1을 차지하자 GPT 계열이 올라왔고, 코딩만 따로 보면 순서가 다르다. 한 숫자보다 내 작업과 가까운 하위 시험을 보는 편이 정확하다. [10/27 GPT-6.1 Terra 출시](ai-news-2026-10-27.md) 때 오픈AI가 내세운 Terminal-Bench 4.0 수치도 v5에서는 코딩 영역의 10%를 차지하는 한 항목일 뿐이다.

> 🔧 **적용 포인트** — 이 포트폴리오처럼 프론트엔드·3D 코드를 Claude Code로 짜는 경우, 모델을 고를 때 종합 순위보다 FrontierCode 2.0(비공개 코딩)과 Terminal-Bench 4.0을 따로 보자. 현재는 Opus 5.5가 비공개 코딩에서 앞서므로 기본 모델을 바꿀 근거는 약하다.
> 대신 추론 강도(effort)는 작업마다 고르는 게 좋다. 같은 Opus 5.5라도 최저와 최고 강도 사이에 점수 23점·비용 10배 차이가 났다. 문구 수정·스타일 조정 같은 가벼운 작업은 낮은 강도로, 셰이더나 스크롤 타임라인 구조처럼 오래 붙잡아야 하는 작업만 높은 강도로 돌리자.

### 앤트로픽 S-1 공개, 나스닥 'ANT'로 상장 신청 — 상반기 매출 163억 달러로 1년 새 약 14배, 매출의 약 80%가 API 사용량이고 구글·아마존과 각각 1,100억 달러대 컴퓨트 계약

testingcatalog의 10월 27일 Daily Brief로 확인했고, CNBC·Yahoo Finance·FinanceFeeds 등 여러 매체가 같은 내용을 보도했다. 앤트로픽은 10월 26일 상장 신청 서류(S-1)를 공개했다. 나스닥 글로벌 셀렉트 마켓에 Class A 주식을 'ANT'라는 종목 코드로 올린다. 공모가 범위·주식 수·공모 규모는 비워 뒀고, 수정 서류에서 채운다.

- **매출**: 2026년 상반기 매출은 약 163억 달러다. 1년 전 같은 기간 약 11.6억 달러의 14배 수준이다. 2분기에만 약 116억 달러를 벌었고 2분기 영업이익은 9.74억 달러였다. 상반기 영업현금흐름은 39억 달러다.
- **매출 구성**: 보도에 따르면 사용량 기반 API·모델 매출이 약 80%(약 131억 달러), 구독이 약 20%(약 32억 달러)다. Claude Code를 포함한 개발자·기업의 API 사용이 회사 매출의 대부분이라는 뜻이다.
- **손실**: 상반기 순손실은 807억 달러다. 하지만 대부분은 전환사채 평가에 따른 724억 달러 규모의 비현금성 회계 비용이고, 영업 단계에서 그만큼 돈을 태운 것은 아니다.
- **컴퓨트 계약**: 구글과 최소 1,145억 달러, 아마존과 1,100억 달러, SpaceXAI와 최대 1,205억 달러 규모의 컴퓨트 계약이 드러났다.
- **고객**: 연간 10만 달러 이상을 내는 고객이 1만 1,900곳을 넘고, 1,000만 달러 이상은 약 250곳이다. 기존 고객의 매출 유지율(NRR)은 약 900%다.
- **지배 구조**: 공동 창업자 7명이 가진 LLC가 Class F 주식 1주로 의결권의 50.1%를 갖는다. 장기 이익 신탁(Long-Term Benefit Trust)은 Class T 주식 1주로 이사회 과반을 선임한다. 상장 뒤에도 창업자와 신탁이 회사의 방향을 쥐는 구조다.
- **일정**: 주관사는 골드만삭스와 모건스탠리다. 블룸버그는 11월 9일 주간에 투자 설명회를 시작해 11월 26일 추수감사절 전에 거래를 시작할 수 있다고 보도했지만, 확정된 일정은 아니다.

개발자에게 직접 바뀌는 건 아직 없다. 다만 상장사가 되면 분기마다 실적과 마진을 공개해야 한다. 그만큼 API 가격, 사용량 한도, 구형 모델 종료 같은 결정이 수익성 압박을 더 받게 된다. 지난주 [10/26 Claude API 첫 새 버전](ai-news-2026-10-26.md)처럼 API 정책이 바뀌는 흐름도 이 관점에서 지켜볼 만하다.

### 구글 딥마인드 Genie 4 — 소리까지 실시간으로 만들어 내는 월드 모델, 문장으로 장면을 바꾸고 Gemini API·AI Studio는 조기 접근 파트너부터

testingcatalog가 전했고, 딥마인드 공식 블로그와 TechCrunch로 확인했다. 10월 27일 발표된 Genie 4는 사용자가 키보드로 걸어 다니며 조작할 수 있는 3D 세계를 실시간으로 만드는 '월드 모델'이다.

- **새로 된 것**: 주변 소리·음악·등장인물 대사를 세계와 동시에 만든다. 딥마인드는 소리를 직접 만드는 첫 실시간 월드 모델이라고 소개했다. 날씨를 바꾸거나, 카메라를 움직이거나, 인물·물체를 추가하는 일을 문장으로 지시하면 Gemini가 장면에 맞게 반영한다. 보도에 따르면 장면이 일관되게 유지되는 시간은 약 2분으로 Genie 3의 두 배다.
- **이용 범위**: 지금은 일부 신뢰 테스터용 리서치 프리뷰다. 곧 Google AI Ultra 구독자(Project Genie)와 Gemini API·AI Studio의 조기 접근 파트너에게 열린다. 대기 명단이 열려 있다. 해상도·프레임률·가격·API 출시일은 아직 공개되지 않았다.
- **용도**: 로봇·에이전트 학습 환경, 영화 사전 시각화(카메라·조명·대사를 바꿔 가며 여러 테이크를 돌리는 초안 모드), 게임 프로토타이핑, 교육 등을 들었다.
- **한계**: 세션이 길어지거나 문장 지시를 여러 번 하면 세부 묘사와 물체 유지가 흐트러진다. 복잡한 물리 상호작용, 소리 정확도, 글자 렌더링, 공간 정확도는 아직 연구 과제다. 생성된 영상·소리에는 모두 SynthID 워터마크가 들어간다.

웹 개발자 입장에서는 당장 쓸 수 있는 API가 아니다. 다만 "실시간으로 돌아가는 3D 세계를 문장으로 조종한다"는 방향은 게임 프로토타입이나 인터랙티브 웹 데모의 제작 방식을 바꿀 수 있는 흐름이다. API가 열리면 비용과 지연 시간이 실제 서비스에 넣을 수 있는 수준인지부터 봐야 한다.

> 🔧 **적용 포인트** — R3F로 만든 3D 장면의 분위기(날씨·조명·카메라 동선)를 정하기 전에, Genie 4 같은 월드 모델로 여러 안을 빠르게 돌려 보는 '사전 시각화' 용도를 염두에 둘 만하다. Gemini API 조기 접근 대기 명단에만 미리 올려 두고, 실제 서비스 통합은 가격·지연 시간이 공개된 뒤에 판단하자.

### Cursor Agent SDK 정식 출시 — 에이전트를 폴더 하나의 코드로 정의하고 eval로 검증한 뒤 PR·Slack·크론 이벤트에 붙인다

testingcatalog의 10월 27일 Daily Brief에 실렸고, Cursor 공식 변경 기록(10월 20일 자)과 문서로 확인했다. Cursor 공식 X 계정의 발표와 언론 보도는 10월 26~27일에 나왔다.

- **구조**: `npx @cursor/agent-sdk init ./my-bot`으로 시작한다. 에이전트 하나가 폴더 하나다. `instructions.md`에 프롬프트를 쓰고, `tools/`의 파일 하나가 모델이 부를 수 있는 동작 하나가 된다. 필요할 때 불러오는 절차는 `skills/`에, MCP 서버 도구 연결은 `mcp-connections/`에, 메시지를 받고 답할 곳은 `channels/`에 둔다. Git으로 리뷰·버전 관리하는 저장소 코드와 똑같이 다룬다.
- **실행 조건**: GitHub·GitLab·Bitbucket의 PR·댓글·CI 이벤트, Slack 멘션과 DM, 임의 웹훅, 크론 일정에 반응한다. GitHub 이벤트는 Cursor 계정을 통해 받아서 공개 웹훅 URL이 필요 없다.
- **eval**: 정해진 메시지를 에이전트에 보내고 어떤 도구를 어떤 입력으로 불렀는지, 답이 어떤 형태인지를 검사한다. 로컬이나 CI에서 돌린다. `agent-sdk github replay <pr-url>`은 실제 PR을 서명된 웹훅 페이로드로 바꿔 보내므로, push 없이 테스트할 수 있다.
- **배포**: `agent-sdk deploy`로 Cursor 인프라에 올리거나 자체 인프라에서 돌린다. 시작 템플릿으로 보안 리뷰어, 코드 소유자 정책 승인자, PR 자동 수정기, Linear·Jira 분류기가 있다. 별도 가격은 공개되지 않았다.

"에이전트를 프롬프트 몇 줄이 아니라 테스트가 붙은 코드로 관리한다"는 흐름이 Claude Code의 스킬·훅, Codex 플러그인에 이어 Cursor에도 정식 제품으로 들어왔다. 에이전트가 늘어날수록 그 행동을 eval로 고정해 두는 일이 필수가 되고 있다.
