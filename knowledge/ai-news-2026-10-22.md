## AI가 찾은 취약점이 웹 전체의 패치 일정을 움직이고, 에이전트는 메신저·게임 엔진·로컬 서버로 퍼진다

오늘의 큰 사건은 PHP다. 웹사이트 대다수를 떠받치는 언어 엔진에서 AI 모델이 원격 코드 실행 결함을 찾았고, 공개 당일 공격이 따라붙었다. 나머지 세 소식은 에이전트가 들어가는 자리를 넓힌다. 앤트로픽은 먼저 말을 거는 개인 에이전트를, Epic Games는 게임 에디터용 공식 플러그인을, 크래프톤은 직접 돌릴 수 있는 한국어 강세 오픈 모델을 냈다.

### PHP2Shell — GPT-5.6 Sol·Gemini 4 Argon이 찾아낸 PHP 엔진 원격 코드 실행 결함 2건, 10월 21일 8.5.12·8.4.27·8.3.36·8.2.35로 패치, 공개 직후 공격 시도가 시작됐다

choi.openai가 전날 긴급 경고에 이어, 결함을 찾은 게 오픈AI 모델이었다는 후속 스레드를 올렸다.

- **결함 두 개**: PHP 보안 공지 기준 CVE-2026-109618과 CVE-2026-109619이며 둘 다 CVSS v4.0 9.2다. 첫째는 메모리 한도(OOM)에 걸리는 순간 요청 내부 데이터가 반쯤 초기화된 채 남고, 정리 과정이 이를 정상 데이터로 다루는 문제다. 둘째는 요청이 쓰던 내부 상태가 메모리 해제 뒤에도 남아, 같은 워커의 다음 요청이 그 상태를 쓰는 문제다. Apache + mod_php 조합에서는 로그인 없는 요청 하나로 애플리케이션 코드가 돌기도 전에 공격이 가능하다고 공지에 적혔다. 그래서 앱 코드를 아무리 안전하게 짜도 PHP 버전이 낡았으면 뚫린다.
- **누가 찾았나**: Fortune 보도 타임라인으로는 8월 1일 AI 레드팀 기업 Calif가 GPT-5.6 Sol로 첫 결함을 찾아 오픈AI에 알렸다. Calif는 오픈AI의 오픈소스 보안 지원 프로그램 Patch the Planet에 합류했다. 8월 19일에는 Wiz가 Gemini 4 Argon·GPT-5.6 Sol·자사 Wiz Atlas로 같은 결함을 따로 찾았다. Wiz는 특히 Gemini 4 Argon이 탐지·익스플로잇·패치 검증에 유용했다고 밝혔다. choi.openai는 "오픈AI 모델이 찾았다"는 쪽에 무게를 뒀지만, 실제로는 두 회사의 모델이 각각 독립적으로 찾은 사건이다.
- **왜 두 달이 걸렸나**: choi.openai 스레드 3/에 따르면 첫 징후는 2024년 외부 감사에서 이미 나왔다. 하지만 공격 경로를 확인하지 못했고, 수정안마다 하위 호환성이나 확장 기능 문제가 걸려 작은 보안팀이 몇 달씩 결정을 미뤘다. PHP 재단은 의사결정 구조와 자원 부족 탓이라고 인정했다. 최종 수정은 한도를 넘는 순간 처리를 끊는 대신 작업을 정리한 뒤 멈추게 바꾼 것이고, 파일 390개를 건드렸다.
- **공개 직후 상황**: Cloudflare CTO는 패치가 나오기 전날 밤부터 초기 공격을 감지해 방어 규칙을 넣었다고 했다. Palo Alto Networks는 잠재적 취약 인스턴스를 약 2,260만 개로 추정했다. 네덜란드·핀란드 일부 정부 기관은 예방 차원에서 사이트를 내렸다. Wiz는 LLM이 PHP 버전·설정·메모리 배치에 맞춰 익스플로잇을 자동으로 고쳐주기 때문에 공격 문턱이 낮아졌다고 경고했다.
- **운영자 조치**: 업데이트 외에 완전한 완화책은 없다고 공지는 못박았다. PHP 8.1 이하는 공식 지원이 끝났고, 7.4·8.0·8.1용 최소 백포트 브랜치만 제공된다. 임시로 `memory_limit=-1`(앱이 덮어쓰지 못하게 `php_admin_value`로)과 컨테이너·cgroup 메모리 제한 조합, `session.upload_progress.enabled=0` 등을 제시하지만 "설치를 안전하게 만들지는 않는다"고 적었다. 오픈AI는 영향 여부를 확인하는 `openai/php2shell-checker`를 GitHub에 공개했다.

### 앤트로픽 Claude Duet 리서치 프리뷰 — 먼저 말을 거는 개인 에이전트, 미국 Pro·Max 대기 명단, 결제·전송·삭제 전에는 반드시 묻는다

choi.openai와 testingcatalog가 10월 21일 공개된 Claude Duet을 전했다. Claude 공식 계정은 Duet을 "주의가 필요한 일을 먼저 가져오고, 맡긴 일을 끝내고, 자리를 비운 동안에도 일하고, 대신 행동하기 전에 확인하는" 앱으로 소개했다.

- **구조**: Opus 5.5 기반이다. Claude 계정의 메모리·스킬·연결된 앱을 그대로 가져온다. 보도에 따르면 아침마다 연결된 앱에서 중요한 일을 추린 브리핑을 보내고, 주기적으로 확인해 알림을 띄운다. iOS·Android 단독 앱과 웹으로 제공된다.
- **행동 전 확인**: MacRumors는 메시지 전송, 결제, 문서 서명, 파일 삭제 전에 사용자 승인을 받는다고 전했다. 결제는 Stripe의 디지털 지갑 Link와 Shopify의 Shop Pay를 쓴다. 1Password에 저장된 로그인으로 사이트에 들어가는 기능은 "곧" 추가된다. 앤트로픽은 Duet이 비밀번호를 직접 보지 않는다고 밝혔다.
- **접근과 한계**: 미국 Pro·Max 대기 명단으로만 열렸고 Team·Enterprise는 아직 빠졌다. 별도 요금은 없고, 백그라운드 작업도 플랜 사용 한도에서 차감된다는 보도가 있다. 앤트로픽 스스로도 무엇이 급한지 잘못 판단할 수 있다고 적었다. testingcatalog는 내부 코드명이 'aibo'이고, 에이전트 아래 해시태그로 보아 Slack식 스레드 UI일 수 있다고 추정했다(추정이다).
- **맥락**: 오픈AI Dots, 메타 Muse에 이어 세 번째 대형 개인 에이전트다. 개발자에게는 연결된 앱 생태계(커넥터·스킬)가 이제 채팅창이 아니라 상시 실행 에이전트의 입력이 된다는 점이 핵심이다.

### Epic Games 공식 Unreal Engine Claude Code 플러그인 — MCP로 실행 중인 에디터를 30개 이상 도구 묶음으로 조작한다, 로컬호스트는 신뢰 경계가 아니다

choi.openai가 Epic Games가 직접 내놓은 Claude Code 플러그인을 소개했다. 저장소는 `EpicGames/unreal-engine-skills-for-claude-code-plugin`(MIT)이고, 앤트로픽 공식 마켓플레이스에 올라 있다.

- **할 수 있는 것**: 실행 중인 Unreal Editor에 MCP로 붙어, 30개 이상 도구 묶음의 수백 개 도구를 쓴다. 액터·씬 배치, Blueprint, 머티리얼, 메시·텍스처, Control Rig·State Tree·Behavior Tree 같은 애니메이션, Sequencer, Niagara VFX, UMG UI, GAS·물리 에셋, C++ 자동화 테스트, 배치 Python 실행까지 들어 있다.
- **설치**: Claude Code에서 `/plugin install unreal-engine-skills-for-claude-code@claude-plugins-official`. 에디터에서는 ModelContextProtocol·AllToolsets 플러그인을 켜고 콘솔에서 `ModelContextProtocol.StartServer`를 실행한다. AllToolsets가 없으면 도구가 하나도 노출되지 않는다.
- **구성**: `unreal-mcp` 스킬 하나와, 저장소가 Unreal 프로젝트임을 알려주는 SessionStart 훅으로 이뤄진다. 훅은 bash 스크립트라서 Git Bash·WSL 없는 순수 PowerShell에서는 돌지 않는다. 이 경우에도 MCP 도구는 쓸 수 있다.
- **보안 경고**: README는 로컬호스트가 신뢰 경계가 아니라고 명시한다. 같은 사용자로 도는 어떤 로컬 프로세스든 이 서버에 붙을 수 있다. `execute_tool_script`는 에디터 전체 권한으로 임의 Python을 실행한다. 이 플러그인을 켠 상태로 `--dangerously-skip-permissions`를 쓰지 말고, 긴 세션 전에는 작업을 커밋해두라고 권한다.

> 🔧 **적용 포인트** — 엔진 회사가 공식 배포하는 플러그인의 모양이 "MCP 서버 + 도메인 스킬 1개 + 프로젝트 맥락을 알리는 SessionStart 훅"이라는 점이 참고할 만하다. 포트폴리오의 R3F 씬 작업용 반복 절차를 스킬로 묶을 때 같은 구조를 쓰면 된다. Windows에서 훅을 쓴다면 bash 의존 여부를 먼저 확인한다. 로컬 MCP 서버를 띄울 때는 "로컬이니 안전하다"는 가정을 버린다.

### 크래프톤 Raon-1 mini 프리뷰 — 전체 288억·활성 43억 MoE를 Apache 2.0으로 공개, 수학·도구 호출은 앞서고 터미널·긴 문맥은 뒤진다

choi.openai가 크래프톤이 자체 학습한 언어 모델 Raon-1 mini 공개를 전하며 "코딩·에이전트 작업에서 Muse Glimmer 수준"이라고 소개했다. 허깅페이스 모델 카드로 확인한 내용은 조금 더 복잡하다.

- **구조**: 전체 288억, 토큰당 활성 43억 매개변수의 하이브리드 희소 MoE다(이름의 30B-A4B는 반올림). 25층 중 18층은 고정 크기 상태를 쓰는 Raon Delta Attention, 7층은 KV 캐시를 쓰는 MLA다. 전문가 128개 중 6개(+공유 1개)가 활성화된다. 기본 문맥은 262,144토큰이다.
- **벤치마크(자체 발표, Muse Glimmer 30B 대비)**: GPQA Diamond 84.3 대 82.6, LiveCodeBench v6 81.6 대 77.4, BFCL v4(도구 호출) 59.8 대 51.8로 앞선다. 반면 Terminal-Bench Lite 47.0 대 70.7, 긴 문맥 AA-LCR 67.3 대 81.3, MMLU Pro 76.5 대 84.0으로 뒤진다. 모델 카드 스스로 Qwen3.8-27B가 여러 항목에서 더 높다고 적었다. 채점에 judge 모델(gpt-5.6-luna)을 쓴 항목이 있고, 한국어 채팅 점수는 공개되지 않은 내부 벤치마크다. "에이전트 작업에서 비슷하다"는 소개는 터미널 작업 기준으로는 맞지 않는다.
- **라이선스와 실행**: 가중치는 Apache 2.0이다. 호스팅 API·플레이그라운드는 별도 약관이다. 허깅페이스 접근은 신청제지만 자동 승인된다. vLLM과 llama.cpp는 아직 크래프톤 포크·브랜치가 필요하다. MLX(애플 실리콘), GGUF Q4_K_M, NVFP4(설정을 맞추면 32GB RTX 5090 한 장) 양자화가 함께 나왔다. 투기적 디코딩용 0.7B 드래프트 모델 DFlash2로 B300 한 장에서 출력 처리량이 최대 2.18배 오른다고 한다.
- **주의**: 모델 카드가 "최종 모델이 아닌 프리뷰"라고 명시했고, 사양·결과가 바뀔 수 있다. thinking 모드 전제로 설계돼 끄지 말라고 권한다.
