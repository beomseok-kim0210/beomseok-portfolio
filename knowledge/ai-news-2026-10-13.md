## 메타가 프런티어 경쟁에 들어왔고, 구독 한도의 실제 값이 처음으로 측정됐다

코딩 에이전트용 모델의 공급자가 하나 늘었다. 메타가 처음으로 오픈AI·앤트로픽 최상위 모델과 같은 급이라고 내세운 모델을 내놨는데, 가장 강한 버전은 API로 팔지 않는다. 한편 10월 5일 공개된 뒤 국내에도 소개되기 시작한 세미애널리시스 보고서는 구독 요금제 한도를 직접 재서 API 가격으로 환산했다. 그 결과 같은 돈을 내도 Claude 구독 쪽이 약 5배 많이 쓸 수 있는 것으로 나왔다.

### 메타 첫 프런티어 모델 Muse Wonder — API는 입력 4달러·출력 20달러, 최상위 Wonder Full은 API 없이 Muse Code 구독 전용

메타가 10월 12일 **Muse Wonder**와 **Muse Wonder Full**을 공개했다. testingcatalog는 두 모델의 역할을 이렇게 나눠 전했다.

- **Muse Wonder**: 실전 코딩과 오래 걸리는 작업용 모델이다. 계획을 세우고, 도구를 병렬로 부르고, 일부 작업을 서브에이전트에 넘기고, 오류가 나면 복구해 복잡한 작업을 끝까지 마친다. Meta Model API와 Muse Code에서 바로 쓸 수 있다.
- **Muse Wonder Full**: 추론을 최대로 돌리는 최상위 모델이다. **Muse Code 구독자만** 쓸 수 있고 API로는 제공하지 않는다.

TechCrunch는 이 모델을 메타의 **첫 프런티어 모델**로 소개했다. 2025년 8월 알렉산드르 왕이 메타 AI 조직을 개편한 뒤 처음 나온 최상위급 모델이다. 그동안 메타는 저지연 경량 모델 Muse Spark와 Muse 에이전트만 내놓았다. 학습은 올해 가동한 오하이오 Prometheus 데이터센터에서 했다. API 가격은 **입력 100만 토큰당 4달러, 출력 20달러**로, TechCrunch는 GPT-6 Sol·Opus 5.5와 비슷한 수준이라고 평가했다. Wonder Full이 포함된 Muse Code 요금제는 월 50달러(Power Usage)와 200달러(Maximum Usage)다. 메타 뉴스룸 발표문은 'Active Memory'를 강조했다. 대화를 넘어 중요한 내용을 기억했다가 지금 작업에 필요한 세부 정보를 다시 꺼내 쓰는 기능이다. 'Active Focus'도 함께 내세웠다. 어려운 작업에서 다른 방법을 시도하고, 필요하면 되묻고, 중요한 행동 전에 확인하는 기능이다.

성능 수치는 걸러 읽어야 한다.

- **메타 자체 수치**: Wonder Full이 DeepSWE 1.1에서 79.0점이다. Opus 5.5와 GPT-6 Astra는 약 74점이다. SWE-Marathon에서는 57.5점으로 Opus 5.5(46.3)를 앞섰다. 장기 기억 벤치마크 MemoryBench에서도 Fable·Opus·Astra를 이겼다고 했다. 모두 메타가 낸 모델 카드 수치이고 독립 검증은 아직 없다.
- **Artificial Analysis 지수**: testingcatalog는 "Wonder Full이 Opus 5.5에 2점 뒤진 2위"라고 썼다. 반면 다른 보도는 Wonder를 52점, Opus 5.5를 58점으로 적었다. 어느 변형을 어떤 설정으로 쟀는지에 따라 차이가 나는 것으로 보이며, 이번 교차 확인에서 공식 리더보드 수치는 찾지 못했다. 종합 지수 1위는 여전히 Opus 5.5(v4.3 기준 58점)다.
- **API 세부 정보**: 서드파티 개발자 가이드는 모델 ID를 `muse-wonder-1.0`, 컨텍스트를 약 100만 토큰으로 적었다. OpenAI 호환 API라서 base URL과 모델명만 바꾸면 된다고도 했다. 다만 메타 공식 발표문에는 컨텍스트 크기와 API 호환성이 나오지 않는다.

dev.to의 한 글은 제목에서부터 "저커버그의 최고 모델은 API에 없다"고 꼬집었다. 개발자가 자기 앱이나 에이전트에 넣을 수 있는 건 Wonder까지이고, 벤치마크 1위로 내세운 Full은 메타 자체 코딩 도구 안에서만 쓸 수 있다. testingcatalog는 메타가 'Watermelon'이라는 차기 모델도 예고했다고 덧붙였다.

> 🔧 **적용 포인트** — 포트폴리오 도슨트처럼 LLM을 호출하는 기능이 OpenAI 호환 클라이언트로 짜여 있다면, base URL과 모델명만 바꿔 Muse Wonder(입력 4달러·출력 20달러)를 같은 질문 세트로 비교해볼 수 있다. 다만 컨텍스트 크기와 호환성은 공식 문서에서 먼저 확인한다. 벤치마크 1위로 홍보된 Wonder Full은 API로 쓸 수 없으니, 비교 대상은 Wonder로 잡아야 한다.

### 세미애널리시스 구독 한도 실측 — 같은 20달러로 Claude Pro는 API 환산 약 1,178달러, ChatGPT Plus는 약 211달러

ai_freaks.kr은 반도체·AI 분석 기관 세미애널리시스(SemiAnalysis)가 AI 구독 9곳의 한도를 직접 측정했다고 전했다. 결론은 **Claude 구독이 ChatGPT보다 5배 넘는 가치를 준다**는 것이다. 한때 한도가 넉넉하기로 유명했던 쪽은 오픈AI였다. 하지만 [9/30 DevDay에서 Pro 200 사용량을 절반으로 줄이고 Pro 500을 새로 내면서](ai-news-2026-09-30.md) 판이 뒤집혔다는 설명이다.

교차 확인한 2차 보도들에 따르면 측정 방법은 이렇다. 토큰 종류별로 100만 토큰을 쓸 때마다 각 서비스의 사용량 게이지가 얼마나 움직이는지 재고, 그 결과로 추정한 월 한도를 각 회사의 API 정가로 환산했다. 에이전트형 작업 기준 수치는 다음과 같다.

| 월 요금 | Claude (Opus 5.5) | ChatGPT (GPT-6.1 Sol) |
|---|---|---|
| 20달러 | Pro 약 1,178달러 | Plus 약 211달러 |
| 100달러 | Max 5x 약 5,725달러 | Pro 100 약 1,055달러 |
| 200달러 | Max 20x 약 11,726달러 | Pro 200 약 2,084달러 |

해석할 때 짚을 점이 몇 가지 있다.

- **5배는 가치 비율이지 생산성 비율이 아니다.** 한도를 끝까지 다 쓴다고 가정한 이론상 상한이다. 일을 5배 더 끝낸다거나 답의 품질이 5배라는 뜻이 아니다. 같은 일을 하는 데 드는 토큰 수도 모델마다 다르다.
- **차이는 작업과 모델 등급에 따라 달라진다.** 중간 등급 모델에서는 약 5.4~5.6배였고, 최상위 모델 등급에서는 차이가 줄었다.
- **보조금 성격이 강하다.** 세미애널리시스는 구독이 앤트로픽 매출의 약 10%에 그치지만 추론 컴퓨트의 40% 이상을 쓴다고 추정했다. 그래서 언제든 한도가 조정될 수 있다는 분석이 따라붙는다. 오픈AI도 Pro 200 기존 가입자의 이전 한도를 10월 29일까지만 유지한다.

> 🔧 **적용 포인트** — Claude Code로 포트폴리오를 만드는 개인 개발자라면, 같은 작업을 API 종량제로 돌리는 것보다 Max 구독이 훨씬 싸다는 근거로 볼 수 있다. 다만 이 비율은 공급자가 예고 없이 바꿀 수 있다. 구독 한도에 기대는 자동화(스케줄 작업·장기 에이전트)는 한도가 줄어도 멈추지 않도록, API 키로 넘어가는 경로나 사용량 모니터링을 따로 마련해두는 것이 좋다.
