## 구글 최상위 모델이 일반 개발자에게 열렸고, Claude API 호출은 이제 기존 관측 도구로 추적된다

2주 전 사이버 방어 파트너에게만 열렸던 Gemini 4 Argon이 유료 API 사용자 전체로 풀렸다. 가격은 처음 두 달 반값이고, API 동작도 몇 군데 바뀌었다. 같은 날 앤트로픽은 Messages API와 Managed Agents 호출을 OpenTelemetry 표준 형식의 트레이스로 내보내는 기능을 베타로 내놨다.

### Gemini 4 Argon 정식 출시 — 유료 API 입력 2달러·출력 10달러는 11월 말까지 한정, 12월부터 두 배, 명시적 캐시 API는 사라졌다

[10/1 Gemini 4 Argon 공개](ai-news-2026-10-01.md) 때는 "일반 개발자는 아직 못 쓴다"가 결론이었다. 그 후속으로, testingcatalog의 10월 14일 데일리 브리프는 구글이 Argon을 **유료 Gemini API와 Gemini 플랫폼에 전 세계 정식 출시**했다고 전했다. Gemini 앱과 검색은 Pro·Ultra 구독자에게, Antigravity는 Ultra 구독자에게 열렸다. Arena 종합 순위에서는 5위로 데뷔했다. 같은 브리프에는 Gemini 데스크톱 앱의 커스텀 MCP 지원 확대 소식도 들어 있다.

교차 확인한 개발자 매체 정리(10월 13일 GA 기준)는 다음과 같다.

- **모델 ID**: `gemini-4-argon`이다. preview 꼬리표 없이 바로 GA로 나왔고, Vertex AI(global·us·eu)와 OpenRouter(`google/gemini-4-argon`)에서도 쓸 수 있다.
- **가격**: 표준 요금은 입력 100만 토큰당 2달러, 출력 10달러다. 단 **11월 30일까지만 적용되는 출시 기념가**이고, 12월 1일부터 4달러·20달러로 오른다. Batch·Flex는 그 절반이다. 출력 가격에는 thinking 토큰이 포함되고, **무료 티어는 없다**(무료 키로 호출하면 할당량 0이 돌아온다).
- **한도**: 입력은 약 100만 토큰이다. 동기 요청 한 번의 출력은 65,536토큰이다. 10/1 기사에서 화제가 된 '출력 100만 토큰'은 Interactions API에서 `background: true`로 돌리는 long decode 방식으로만 쓸 수 있다.
- **바뀐 API 동작**: 명시적 컨텍스트 캐시(`cachedContents`)가 없어지고 암묵적 캐시만 남았다. 기본 thinking 레벨이 `high`에서 `medium`으로 내려갔다. 200K 초과 구간 할증 요금이 없어져 전 구간이 같은 단가다. `temperature`·`top_p`·`top_k`는 받기는 하지만 무시된다. Vertex에서는 `thinkingBudget`·`frequency_penalty` 등이 HTTP 400을 낸다.
- **벤치마크(구글 모델 카드)**: DeepSWE v1.1 77.9%, Vals Index 68.9%로 앞선다. 반면 Terminal-bench 4.0(57.4%)은 Opus 5.5(66.4%)에, FrontierSWE v2(55.0%)는 GPT-6 Astra(65.5%)에 뒤진다. Artificial Analysis 지수는 53점이다.

Gemini CLI, GitHub Copilot, Cursor 지원은 아직 발표되지 않았다. AI Studio 웹 UI도 Ultra 전용이라, 당장은 결제 수단을 등록한 API 키로 직접 부르는 게 가장 빠른 사용 경로다.

> 🔧 **적용 포인트** — 도슨트처럼 LLM 호출 코드를 갖고 있다면, 11월 30일 전까지는 Argon을 표준가의 절반으로 같은 질문 세트에 비교해볼 수 있다. 다만 기존 Gemini 코드를 그대로 옮기면 두 군데서 걸린다. `temperature`로 맞춰둔 말투 조절은 무시되고, `cachedContents`로 시스템 프롬프트를 캐시하던 코드는 동작하지 않는다. 캐시 이득을 보려면 고정 프롬프트(큐레이션 코퍼스 등)를 요청 맨 앞에 두는 식으로 구조를 바꿔야 한다.

### Claude API OpenTelemetry 내보내기 베타 — Messages API·Managed Agents 세션을 Grafana·Datadog·Langfuse 같은 기존 관측 도구에서 추적한다

testingcatalog는 Claude Managed Agents, Messages API, Claude SDK가 OpenTelemetry 트레이스를 지원하기 시작했다고 전했다. 기본으로 요청 시간·상태·토큰 수·모델·도구 이름이 담기고, Grafana·Splunk 같은 도구로 AI 호출을 관측하는 길이 열렸다는 평가다. 앤트로픽 플랫폼 릴리스 노트에도 10월 14일자로 같은 내용이 올라왔다.

공식 문서로 확인한 핵심은 다음과 같다.

- **두 가지 수집 경로**: 하나는 **SDK 트레이싱**이다. 코드에서 tracer provider를 등록하면 되고 별도 권한이 필요 없다. Python·TypeScript·C#·Go·Java·PHP·Ruby SDK가 지원한다. 다른 하나는 **API 트레이싱**이다. Claude Console에서 OTLP 목적지를 추가하면 되고 Admin 권한이 필요하다. 이쪽은 SDK를 쓰지 않는 클라이언트의 요청까지 잡는다. 둘을 같이 켜면 한 요청의 클라이언트 span과 서버 span이 하나의 트레이스로 이어진다.
- **보이는 것**: 요청 하나 안의 모델 실행 단위, 웹 검색 같은 서버 도구, tool runner가 돌린 내 도구(`anthropic.custom_tool_use`), Managed Agents의 턴(`anthropic.session.turn`)까지 span으로 나뉜다. 속성 이름은 OTel GenAI 시맨틱 컨벤션(`gen_ai.*`)을 따르기 때문에, 이를 지원하는 플랫폼은 별도 설정 없이 알아본다.
- **콘텐츠 모드**: 기본값은 `metadata_only`다. ID·시간·상태·토큰 수만 담기고 프롬프트와 응답은 빠진다. `content`로 바꾸면 시스템 프롬프트와 입출력 메시지가 span에 들어간다. 기본 상한은 span당 0.75MB이고, 넘치면 앞쪽 메시지부터 잘리며 `anthropic.content.truncated=true`가 붙는다.
- **토큰 집계 주의**: 같은 사용량이 여러 단계 span에 반복해서 찍힌다. 그래서 요청 하나는 한 소스(SDK면 CLIENT, API면 SERVER span)만 합산해야 한다. 전달 방식이 best effort라 span이 빠질 수도 있으니, 정확한 과금 추적은 Usage API로 하라고 문서에 적혀 있다.

Arize·Braintrust·Datadog·Grafana Cloud·Honeycomb·Langfuse·LangSmith·PostHog·Sentry 등이 연동 가이드를 함께 냈다. 비용 문서에 별도 요금은 나와 있지 않다.

> 🔧 **적용 포인트** — 도슨트 RAG 답변이 느리거나 엉뚱할 때, 지금은 로그를 직접 찍어 원인을 추적해야 한다. Claude SDK로 호출하고 있다면 tracer provider만 등록해, 무료 티어가 있는 Langfuse나 PostHog로 보내보자. 요청별 지연·토큰 수·도구 호출 순서를 바로 볼 수 있다. 공개 사이트 방문자의 질문이 그대로 외부 도구에 쌓이지 않게, 기본값인 `metadata_only`부터 시작하는 것이 안전하다.
