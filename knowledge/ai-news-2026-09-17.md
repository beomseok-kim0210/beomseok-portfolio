## 클로드가 챗과 협업 도구를 하나로 합치고, 에이전트가 로그인된 브라우저와 회사 운영까지 넘겨받은 날

### 앤트로픽, Claude Chat과 Cowork를 하나로 통합 — Docs·Slides·Design도 대화 안으로

Threads(choi.openai, testingcatalog, boris_cherny)에 따르면 앤트로픽이 짧은 질문에 답하는 Claude Chat과 장기 작업을 대신 처리하는 Claude Cowork를 하나의 Claude로 통합했다. 웹서치로 확인한 앤트로픽 공식 블로그(claude.com/blog/cowork-is-now-claude)·TechCrunch·Unite.AI·Engadget 보도에 따르면, 통합된 화면에서는 짧은 질문부터 리서치·보고서·스프레드시트·프레젠테이션 작성 같은 장기 작업까지 같은 대화 안에서 처리되며 어떤 도구를 쓸지는 클로드가 알아서 판단한다. 노트북을 닫아도 작업은 백그라운드에서 계속되고, 불명확한 부분이 있으면 클로드가 먼저 물어보되 최종 결정은 사용자가 갖는다. 같은 발표에서 새로 나온 Claude Docs·Claude Slides는 오늘 처음 공개됐고, 기존에 별도 화면이었던 Claude Design도 대화 안에서 바로 접근할 수 있게 됐다. 앤트로픽은 "Cowork를 큰 작업 전용 공간으로, Design을 시각 작업 전용 공간으로 따로 만들었지만, 사용자들이 실제로 불편해한 지점은 '이 작업을 어디서 시작해야 하는지 결정하는 것' 자체였고, 한쪽에서 시작한 작업이 다른 쪽으로 이어지지 않았다"고 통합 배경을 밝혔다. 롤아웃은 Pro·Max 플랜부터 순차 적용되며 Team·Free가 뒤따르고, 기업 관리자에게는 최소 30일 전 사전 고지가 제공된다. 보리스 체르니는 "몇 주간 매일 이 경험을 써봤는데 더 간단하고 빠르고 강력하게 느껴진다"고 소개했다.

> 🔧 **적용 포인트** — 이 `weekly-ai-news-threads` 같은 예약 작업이나 도슨트 파이프라인 정리 작업처럼 "노트북을 닫아도 계속 진행되는" 장기 작업 패턴은 이미 Claude Code의 백그라운드 세션으로 익숙하지만, Claude Docs·Slides가 대화 안에 통합되면 포트폴리오 프로젝트의 기획 문서나 회고 노트를 별도 도구로 옮기지 않고 바로 초안→문서화까지 이어갈 수 있다. 아직 Pro·Max 순차 롤아웃 단계이므로, 계정에 반영되면 지금 knowledge/ 폴더에 마크다운으로 쌓고 있는 메모 중 일부를 Claude Docs로 옮겨보는 정도로 가볍게 시도해볼 만하다.

### 텐센트, 로그인된 내 브라우저를 그대로 쓰는 에이전트 도구 "BrowserSkill" 오픈소스 공개

Threads(choi.openai)에 따르면 텐센트가 AI 에이전트가 새 브라우저를 띄우는 대신 이미 로그인돼 있는 사용자의 실제 브라우저 탭을 그대로 빌려 쓸 수 있는 도구 "BrowserSkill"을 오픈소스로 공개했다. 웹서치로 확인한 GitHub 저장소(Tencent/BrowserSkill)에 따르면 기존 브라우저 에이전트는 로그인·인증을 별도 계정으로 다시 거쳐야 하는 경우가 많았지만, BrowserSkill은 `bsk` CLI와 브라우저 확장을 통해 현재 로그인 상태를 그대로 활용하고, 작업은 사용자 화면과 분리된 별도의 "에이전트 창"에서 진행돼 원래 쓰던 브라우저 작업을 방해하지 않는다. 셸 명령을 실행할 수 있는 에이전트라면 Cursor, Claude Code, Codex, DeepSeek Harness 등 특정 모델·프레임워크에 종속되지 않고 사용할 수 있고, 모든 작업은 로컬에서 실행된다. 에이전트가 탭을 빌리기 전 사용자 승인을 요구하도록 설계됐으며 MIT 라이선스로 공개돼 있다.

> 🔧 **적용 포인트** — 이번 회차 작업 중 실제로 겪은 문제이기도 한데, 이 세션에 연결된 Claude in Chrome 브라우저가 없어 Instagram 두 계정은 로그인 벽에 막혀 게시물을 3개까지만 확인할 수 있었다. BrowserSkill처럼 "이미 로그인된 실제 브라우저를 셸 명령형 에이전트에 빌려주는" 구조가 이 `weekly-ai-news-threads` 작업에도 정확히 필요한 패턴이다. 다만 서드파티 오픈소스 도구를 로그인 세션에 연결하는 것이므로, 실제로 도입하기 전에는 텐센트 배포 바이너리와 권한 승인 흐름을 먼저 검토하는 편이 안전하다.

### 퀴버AI, 대화로 고치는 편집 가능 SVG 생성 모델 "Arrow 2"·"Arrow 2 Telos" 공개

Threads(choi.openai)에 따르면 벡터 그래픽 생성 스타트업 QuiverAI가 텍스트만 입력해도 바로 수정 가능한 SVG를 만드는 모델 Arrow 2와 상위 버전 Arrow 2 Telos를 공개했다. Arrow 2는 더 빠르고 정교한 SVG 생성에 초점을 맞췄고, Telos는 복잡한 스타일·구도 작업에 특화됐다. 새 앱에서는 생성 결과를 대화로 수정하거나 캔버스에서 직접 요소를 조정할 수 있으며, 결과물은 모두 편집 가능한 SVG 형태로 저장된다. 웹서치로 확인한 QuiverAI 공식 블로그와 Vercel AI SDK 저장소(vercel/ai)의 관련 PR·이슈에 따르면, API도 함께 공개됐고 `generateImage` 인터페이스를 통해 SVG 생성뿐 아니라 래스터 이미지의 벡터화, 기존 SVG 편집(`/v1/svgs/edits`), 애니메이션 추가(`/svgs/animations`)까지 지원하며 Vercel AI SDK에 벌써 프로바이더로 통합이 진행 중이다.

> 🔧 **적용 포인트** — 이 포트폴리오처럼 Three.js·GSAP 기반 인터랙션 위에 아이콘·일러스트 같은 벡터 에셋을 자주 새로 만들거나 수정해야 하는 프로젝트라면, Arrow 2의 "생성 → 대화로 수정 → 편집 가능한 SVG로 저장" 흐름이 디자인 툴을 오가지 않고 코드베이스 안에서 에셋을 반복 조정하는 용도로 바로 시도해볼 만하다. 특히 Vercel AI SDK 프로바이더로 통합되고 있다면, 이미 Next.js 스택을 쓰는 만큼 별도 API 클라이언트를 새로 짜지 않고도 실험해볼 수 있다.

### Andon Labs, 사람 개입 없이 회사를 통째로 운영하는 에이전트 플랫폼 "Pion" 공개

Threads(choi.openai)에 따르면 AI 에이전트 스타트업 Andon Labs가 사람의 개입 없이 회사 전체를 운영하는 에이전트 플랫폼 "Pion"을 공개했다. 이메일·전화·브라우저·은행·결제까지 연결해 고객 응대부터 직원 관리, 재고 구매, 가격 결정, 마케팅까지 에이전트가 이어서 처리한다. 웹서치로 확인한 Andon Labs 공식 블로그("Why we built Pion")와 관련 보도에 따르면, 이 아키텍처는 이미 자판기뿐 아니라 샌프란시스코의 매장 Andon Market, 카페, 라디오 방송국을 1년 넘게 운영하며 검증돼왔다. 매장에서는 하위 에이전트 "Luna"가 Slack으로 직원에게 지시하고 재고를 주문하며, 라디오 방송에서는 선곡·청취자 응대·결제·데이터 분석까지 맡는다. 사용자는 전체를 관리하는 상위 에이전트 "Andonos"에게 "매출을 늘려라" 같은 큰 방향만 전달하면 되고, 여러 전문화된 하위 에이전트가 협업해 세부 업무를 나눠 처리하는 멀티 에이전트 구조다. Andon Labs는 "AI 시스템이 언제부터 현실에서 자원을 자율적으로 획득할 수 있게 되는지"를 거의 2년째 연구해온 질문의 연장선이라 밝혔고, 현재는 리서치 프리뷰 단계로 외부 운영자의 테스트를 받고 있다.
