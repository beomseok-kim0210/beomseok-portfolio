## 로봇의 영상 기반 인컨텍스트 러닝과 에이전트의 로그인 장벽 해제

### Skild AI, 로봇 파운데이션 모델 S1 공개 — 영상 시연 한 번으로 미학습 작업 성공률 66%(언어 지시는 9%)

Threads에 따르면 로보틱스 스타트업 Skild AI가 새 파운데이션 모델 S1을 공개했다. 언어 지시 대신 사람이 작업하는 영상 한 편을 "프롬프트"로 주면, 추가 파인튜닝 없이 같은 작업을 처음 보는 환경·로봇 몸체에서도 수행한다. 한 시연에서는 밤 9시 22분에 촬영한 화분 옮겨심기 영상을 주자 5분 뒤인 9시 27분부터 로봇이 같은 작업을 그대로 수행했다. 벤치마크에서는 처음 보는 작업에 대해 영상 프롬프트 방식이 66% 성공률을 기록해 언어 프롬프트 방식의 9%를 크게 앞섰고, 영상 시연 한 번이 사후 학습 데모 380개와 맞먹는 효과를 냈다는 결과도 함께 공개됐다.

웹서치로 교차 확인한 결과, Skild AI 공식 블로그("Introducing S1: In-Context Learning for Robotics")에 따르면 S1은 짧은 작업부터 10분짜리 장시간·다단계 작업까지 영상 시연 한 번으로 학습하며, 사전학습 단계에서 다양한 작업의 의도를 영상으로부터 추론하도록 훈련해 하나의 가중치 세트로 미학습 작업까지 수행하게 만들었다. 커피 내리기·팬케이크 뒤집기 같은 사전학습 데이터에 전혀 없던 작업도 영상 한 편만으로 수행한 사례가 보고됐으며(팬케이크 뒤집기는 사전학습 데이터를 전수 조사했지만 유사 사례가 없었다고 함), NVIDIA와 협업한 "옴니바디" 로봇 브레인 사례도 별도로 소개돼 있다. 언어 지시 기반 로봇 파운데이션 모델이 주류였던 흐름에서, 시범 영상 자체를 스펙으로 쓰는 방식이 실측 벤치마크로 우위를 보인 사례라는 점에서 주목할 만하다.

### 오픈AI, ChatGPT Work에 로그인 필요한 사이트 접근 기능 추가 — 에이전트가 세션 유지하며 SaaS·사내 포털까지 처리

Threads에 따르면 오픈AI가 ChatGPT Work 에이전트에 로그인이 필요한 웹사이트 접근 기능을 웹·모바일 동시에 추가했다. 기존에는 에이전트가 공개 웹으로만 작업 범위가 제한돼 사내 대시보드, SaaS 툴, 유료 포털 등은 다루지 못했다. 이제는 사용자가 클라우드 브라우저를 잠깐 넘겨받아 직접 로그인하면, 이후 에이전트가 그 세션 쿠키를 이어받아 작업을 계속하고 한 번 로그인한 뒤에는 다음 실행부터 재로그인 없이 이어간다. 유틸리티 요금 처리, 정부 민원, 보험 조회, 인보이스 처리처럼 지금까지 사람이 직접 해야 했던 로그인 후 업무를 에이전트에 넘길 수 있게 된 셈이다.

웹서치로 교차 확인한 결과, 오픈AI 발표에 따르면 에이전트는 로그인 과정에서 비밀번호를 직접 입력하거나 저장하지 않으며 패스워드 매니저를 호출하지도 않는다. 사용자가 브라우저를 넘겨받아 입력하는 내용은 모델에 노출되지 않는다. 로그인 테이크오버 단계는 Pro·Plus·Business·Enterprise·Edu 플랜의 메시지 사용량에 포함되지 않는다. 다만 오픈AI 스스로도 다층 안전장치를 함께 제공한다고 밝히면서, 불필요한 앱 연결 해제나 민감한 계정 로그인 자제, 작업 후 로그아웃 같은 사용자 주의를 함께 권고하고 있어 편의성과 보안 리스크가 맞물려 있는 기능이다.
