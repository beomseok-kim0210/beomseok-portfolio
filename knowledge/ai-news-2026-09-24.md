## Opus 5.5 출시 다음 날, 앤트로픽은 Claude Code를 "로컬 밖"으로 꺼내고 오픈AI는 "속도"에 값을 매기려 한다

### Claude Code 클라우드 세션 정식 출시 — 노트북을 닫아도 계속 일하는 원격 세션, Pro 100달러·Max 250달러 크레딧 10월 7일까지

Threads(btibor91의 39주차 요약)에 따르면 Claude Code 클라우드 세션이 연구 프리뷰를 끝내고 정식 출시(GA)됐다. 클라우드 세션은 앤트로픽이 관리하는 가상 머신에서 Claude Code를 돌리는 방식이라, 작업을 걸어두고 노트북을 닫아도 계속 진행된다. [9/18 노트](ai-news-2026-09-18.md)에서 다룬 "Projects"(한 대화에서 병렬 스레드를 지휘하는 기능)도 이 클라우드 세션 위에서 동작하므로, 이번 GA는 그 기반이 정식 제품이 됐다는 의미이기도 하다.

웹서치로 확인한 ClaudeDevs 공식 발표와 관련 보도에 따르면 기존 Pro 구독자에게는 100달러, Max 구독자에게는 250달러의 1회성 크레딧이 주어진다. 미국 서부 시간 10월 7일까지 공식 링크 또는 CLI에서 `/claim-credit`을 실행해 받아야 하고, GitHub 계정 연결이 필수이며 클라우드 세션에만 쓸 수 있다. 받은 크레딧은 11월 초(태평양시 11월 4일 전후)에 만료된다. 크레딧은 요금제의 기본 사용량 한도와 별개로 위에 얹히는 구조이고, 크레딧을 다 쓴 뒤에는 클라우드 세션도 로컬 Claude Code와 같은 사용량 한도에서 차감될 뿐 추가 과금은 없다고 안내됐다. 시작은 claude.ai·데스크톱·모바일 앱에서 GitHub 저장소를 골라 세션을 여는 방식이며, CLI에서도 원격 세션으로 띄울 수 있다.

> 🔧 **적용 포인트** — Max 요금제라면 10월 7일 전에 `/claim-credit`으로 250달러를 꼭 받아둘 것(GitHub 연결 필요). 포트폴리오 V3 그레이박스, 크라임씬 설계 문서 정리처럼 "완료 조건이 명확하고 몇 시간 걸리는" 작업을 클라우드 세션에 걸어두면 C 드라이브(240GB SSD) 여유 공간이나 로컬 PC 점유 없이 돌릴 수 있다. 다만 사람의 테스트 게이트가 걸린 작업(크라임씬 Human 게이트, 브라우저 테스트 금지 정책)은 클라우드 세션에서도 똑같이 멈춤 조건으로 명시해 둬야 한다.

### 앤트로픽 Claude Marketplace 공개 — 커넥터·플러그인 2,000개 이상, MCP·Agent Skills로 누구나 등록 가능

같은 날 앤트로픽은 Claude Marketplace를 열었다. btibor91의 요약과 웹서치로 확인한 BleepingComputer·gHacks 보도에 따르면 마켓플레이스는 세 구역으로 나뉜다. ① 커넥터·플러그인(출시 시점 2,000개 이상, Atlassian·Google·Microsoft·Notion·Salesforce 등), ② Claude 기반 에이전트·제품(CrowdStrike·Cursor·Harvey·Hebbia·Legora·Lovable·Snowflake 등), ③ 서비스 파트너(Accenture·BCG·Deloitte 등 컨설팅·SI)다. 핵심은 대형 파트너만의 큐레이션이 아니라 외부 개발자에게도 열려 있다는 점으로, MCP(Model Context Protocol) 서버나 Agent Skills로 만든 커넥터·플러그인을 앤트로픽 문서의 제출 절차로 등록할 수 있다. 카탈로그는 Claude 웹사이트에서 누구나 둘러볼 수 있다.

개발자 입장에서는 그동안 GitHub 저장소·개인 블로그·커뮤니티에 흩어져 있던 MCP 서버와 스킬이 한 카탈로그로 모이면서, 배포 채널이 생긴 동시에 "공식 마켓에 올라간 것"과 "아닌 것"의 신뢰도 구분이 생긴다는 의미가 있다.

> 🔧 **적용 포인트** — 포트폴리오 `knowledge/mcp.md`에서 다룬 MCP 개념의 실제 유통 경로가 생긴 셈이다. 도슨트 RAG나 크라임씬 심문 로직처럼 이미 만든 기능 중 일부를 작은 MCP 서버나 Agent Skill로 떼어 마켓에 제출해 보면, 포트폴리오에 "실제 배포된 Claude 플러그인"이라는 증거를 하나 더할 수 있다. 반대로 Claude Code에 서드파티 플러그인을 붙일 땐 마켓 등록 여부를 최소한의 신뢰 기준으로 삼는 게 좋다.

### 오픈AI 월 500달러 ChatGPT Pro Max 준비 포착 — 차이는 "가장 빠른 Work·Codex", 세레브라스 추론 유력

Threads(testingcatalog, btibor91)에 따르면 ChatGPT 웹 코드에서 월 500달러짜리 새 요금제 "Pro Max"가 발견됐다(부가세 포함 화면에선 600달러로 표시). 기존 Pro(100·200달러)의 2.5배 가격인데, 요금제 설명에서 Pro와 달라진 문구는 "가장 빠른 Work와 Codex" 하나뿐이다. testingcatalog는 이 속도가 세레브라스(Cerebras) 인프라에서 나올 가능성이 높다고 봤고, 사용량 한도가 더 높을 여지도 남겼다. 웹서치로 확인한 BleepingComputer·Decrypt 보도에 따르면 설명엔 프런티어 모델 접근, 최대 메모리, 100GB 파일 저장공간, 신기능 우선 체험도 포함돼 있으며, 200달러 Pro의 신규 가입·업그레이드는 9월 10일부터 일시 중단된 상태다. 오픈AI와 세레브라스 모두 공식 확인은 하지 않았고, 새 요금제가 보통 발표되는 DevDay는 9월 29일이다.

결국 차별점이 "모델 품질"이 아니라 "에이전트 작업 속도"라는 점이 눈에 띈다. 코딩 에이전트 경쟁의 축이 점점 몇 시간짜리 자율 작업을 얼마나 빨리 끝내느냐로 옮겨가고 있다는 신호로, 이틀 뒤 나온 [9/26 Ultrafast API 확대 소식](ai-news-2026-09-26.md)과도 맞물린다.
