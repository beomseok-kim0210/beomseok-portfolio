### 앤트로픽, Claude Managed Agents에 이펙트 레벨·웹훅 확장·세션 초기 이벤트 추가

앤트로픽이 서버에서 에이전트를 직접 호스팅해주는 Claude Managed Agents에 여러 기능을 추가했다. 가장 눈에 띄는 건 에이전트별로 `effort`(사고 강도) 레벨을 모델 설정에 직접 지정할 수 있게 된 점 — 응답 속도와 비용을 태스크 성격에 맞춰 조절할 수 있다. 세션 생성 시 `initial_events`로 최대 50개의 `user.message`/`user.define_outcome` 이벤트를 미리 채워 넣을 수 있게 되어, 별도의 이벤트 전송 요청 없이 세션 생성과 동시에 에이전트 루프를 바로 시작할 수 있다. 웹훅은 환경(environment)과 메모리 스토어(memory store) 생명주기까지 커버 범위가 넓어져 총 7종의 이벤트 타입(environment.* 4종, memory_store.* 3종)을 폴링 없이 받아볼 수 있다. Threads 게시물에 따르면 세션당 최대 500개 Skills 지원과 하위 에이전트(sub-agent) 작업을 실시간으로 들여다보는 모니터링 기능도 함께 언급됐다. 공식 릴리스 노트 기준 이 변경들은 7월 22일자로 반영됐다.

> 🔧 **적용 포인트** — [docent-project](docent-project.md) 메모의 GNM 파이프라인/도슨트 백엔드를 향후 Claude Managed Agents로 서버 호스팅 전환할 계획이 있다면, `effort` 레벨을 낮춰 간단한 질의응답 턴의 비용·지연시간을 줄이고 복잡한 3D 씬 조작 요청에만 높은 effort를 쓰는 식으로 분기할 수 있다. 지금 당장 Managed Agents로 옮기지 않더라도, Claude API를 직접 호출하는 현재 구조에서도 요청 종류별로 `effort` 파라미터를 다르게 주는 것만으로 비슷한 비용 절감 효과를 볼 수 있다.

### 앤트로픽, 코드 취약점을 스스로 검증까지 하는 'Claude Security' 플러그인 베타 공개

앤트로픽이 코드베이스의 보안 취약점을 찾아 수정안까지 제안하는 'Claude Security'를 공개했다. 단일 파일 패턴 매칭에 의존하는 기존 정적 분석 도구와 달리 여러 파일에 걸친 데이터 흐름을 추적해 복합적인 취약점을 탐지하며, 찾아낸 결과를 그대로 내놓지 않고 "Claude가 자기 결과에 스스로 반박해보는" 적대적 검증(adversarial verification) 과정을 한 번 더 거쳐 오탐(false positive)을 줄인다고 설명한다. Claude Code용 플러그인은 모든 사용자에게 베타로 열려 있어, 커밋 전 변경분만 스캔하거나 터미널에서 전체 저장소를 검사할 수 있다. 제안된 수정안은 항상 사람이 검토·승인해야 적용되며, Slack·Jira 연동 웹훅과 CSV 내보내기로 기존 워크플로에 붙일 수 있다. 앤트로픽 내부 롤아웃 기준 이 플러그인 도입 후 PR의 보안 관련 코멘트가 30~40% 줄었다는 수치도 함께 나왔다.

> 🔧 **적용 포인트** — 이 저장소도 Claude Code로 작업하고 있으니 `/plugins` 마켓플레이스에서 Claude Security 플러그인을 설치해, `/docent`의 Claude API 키 처리나 GNM 파이프라인 스크립트 같은 민감한 부분을 커밋 전에 스캔해보는 걸 고려할 만하다. 특히 API 키 하드코딩이나 안전하지 않은 역직렬화 같은 패턴은 포트폴리오처럼 혼자 빠르게 작업하는 프로젝트에서 놓치기 쉬운 지점이다.

### 커서, 작업 난이도별로 모델을 자동으로 고르는 'Cursor Router' 출시 — 비용 최대 60% 절감

커서(Cursor)가 요청마다 최적의 모델을 자동으로 골라주는 'Cursor Router'를 출시했다. 60만 건 이상의 실제 요청으로 학습한 분류기가 질의의 복잡도·컨텍스트·도메인을 분석해, 간단한 작업은 저비용 모델로, 복잡한 추론이 필요한 작업은 프런티어급 모델로 보낸다. 수백만 건 규모의 온라인 A/B 테스트에서는 항상 최고 성능 모델(Opus 4.8)만 쓸 때 대비 60% 비용 절감을 확인했고, 실제 기업 다수를 대상으로 한 얼리 액세스에서는 30~50% 절감이 관측됐다. 사용자는 Intelligence·Balance·Cost 세 가지 최적화 모드 중 고를 수 있는데, Intelligence 모드는 Fable 수준 만족도를 약 60% 낮은 비용에, Balance 모드는 Opus 4.8보다 높은 만족도를 약 36% 낮은 비용에 제공한다고 밝혔다. 커밋 1건당 비용 비교로는 Intelligence 모드 $6.76, Balance 모드 $4.63으로, Fable 단독 사용($12.69)이나 Opus 단독 사용($7.34)보다 낮았다. Teams 플랜에는 기본으로 켜져 있고, 관리자는 팀별로 라우팅을 통제하거나 기본 모드를 지정할 수 있다.

> 🔧 **적용 포인트** — 이 프로젝트는 Cursor가 아니라 Claude Code/Claude API를 직접 쓰는 구조라 Router 자체를 붙일 수는 없지만, 아이디어는 그대로 가져올 만하다. `/docent`에서 사용자가 짧은 인사말이나 단순 질문을 던질 때는 저비용 모델(Haiku)로, 3D 씬 조작이나 복잡한 설명이 필요한 요청에는 Sonnet/Opus로 분기하는 간단한 라우팅 로직을 API 호출 앞단에 직접 구현해볼 수 있다.
