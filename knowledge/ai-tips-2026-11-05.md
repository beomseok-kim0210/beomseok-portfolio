## 코딩 에이전트 옆에 '생성 도구 상자'를 하나 붙이는 법 — 파이프로 잇는 멀티모달 CLI

### Vercel Labs ai-cli — 터미널 한 줄로 텍스트·이미지·영상·음성을 만들고 파이프로 잇는 CLI, MCP 서버 모드로 Claude Code·Codex가 생성 도구로 바로 쓴다

Vercel Labs가 공개한 `ai-cli`는 Vercel AI SDK와 AI Gateway 위에 만든 생성용 CLI다. 모델 수백 개를 하나의 키로 부를 수 있고, 명령이 작고 조합 가능하게 나뉘어 있어 셸 파이프와 코딩 에이전트 양쪽에서 쓰기 좋다.

- **설치·인증**: `npm install -g ai-cli`(Node.js 22 이상). `ai login`이 키 발급 페이지를 열고 붙여 넣은 키를 확인해 `~/.config/ai-cli/auth.json`에 저장한다. 환경 변수 `AI_GATEWAY_API_KEY`가 있으면 그쪽이 우선이다.
- **명령 구성**: `ai text`, `ai image`, `ai video`, `ai audio speak`, `ai audio transcribe`, 그리고 정해진 형태로 판정만 돌려주는 `ai decide`(예: `ai decide --boolean "refund=Refund requested?" < ticket.txt`). `ai models`로 쓸 수 있는 모델을 본다.
- **파이프 조합**: 표준 입력을 받기 때문에 `ai image "a dragon" | ai video "animate this"`처럼 이어 붙이거나, `git diff | ai text "explain these changes"`, `ai text --image screenshot.png "what is broken in this UI?"`처럼 기존 셸 흐름에 끼워 넣을 수 있다. 참조 이미지는 `-i`/`--images`로 여러 장 넘긴다.
- **스크립트에 쓰기 좋은 출력 규칙**: `-m`에 모델을 쉼표로 여러 개 넣으면 같은 프롬프트를 모델별로 뽑아 비교할 수 있고, `--json`을 켜면 stdout에는 메타데이터만 나오고 결과물은 항상 파일로 저장된다. 이미지·영상을 n장 요청했는데 덜 나오면 0이 아닌 종료 코드로 '불완전 결과'를 알려 주고, 받은 것까지는 저장한다.
- **에이전트 연결**: `ai mcp --profile all`로 stdio MCP 서버를 띄우면 Claude Code·Codex·opencode 같은 에이전트가 `ai` 명령을 타입이 있는 도구로 호출한다. 모델별 비용·데이터 보관 정책은 AI Gateway 쪽에서 관리한다.

choi.openai 스레드 댓글에는 "Claude Code에서 연결해 둔 Codex에 시키면 되는데 이걸 쓰는 이점이 뭐냐"는 질문이 달렸다. 차이는 범위다. Codex 연결은 코드 작업 위임이고, ai-cli는 Flux·영상·음성 같은 **다른 회사의 생성 모델**을 같은 인터페이스와 같은 키로 부르는 도구라 겹치지 않는다.

> 🔧 **적용 포인트** — 포트폴리오 작업 중 필요한 배경 이미지·OG 이미지·짧은 루프 영상을 Claude Code 세션 안에서 `ai mcp`로 바로 만들고 `-o public/...`로 저장하면, 에셋 제작을 별도 웹 UI로 오가지 않아도 된다.
> `ai text --image`로 dev 서버 스크린샷을 넘겨 "깨진 레이아웃"을 물어보는 가벼운 시각 점검에도 쓸 수 있다. 다만 생성 호출은 유료이니 `-m`으로 모델을 명시하고, 생성물은 기존 이미지 용량 예산 안으로 압축해 넣는다.
