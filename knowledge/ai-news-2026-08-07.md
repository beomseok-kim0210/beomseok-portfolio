## 무료 티어로 내려온 프론티어 모델, 그리고 정부발 오픈데이터 MCP 서버

### 오픈AI, 무료 사용자에게 GPT-5.6 Luna 무제한 개방 — Sol은 사실 오류 68% 줄인 리튠 버전으로 유료 기본 모델

오픈AI가 무료 사용자에게 GPT-5.6 Luna를 무제한으로 개방했다. Threads에 따르면 Plus·Pro 사용자에게는 즉시 응답과 추론 모드를 하나로 통합한 Sol이 기본 모델로 제공되며, 금융·의료·법률 분야 답변의 사실 오류가 68% 줄었다고 한다. 웹서치로 확인한 Unite.AI·Neowin·Developers Digest 보도에 따르면 이번 발표는 8월 6일 이뤄졌고, 무료·Go 등급의 기존 기본 모델이었던 GPT-5.5 Instant를 Luna로 교체하면서 텍스트 대화에 한해 무제한을 적용한다(파일 업로드·이미지 등 다른 기능 한도는 유지). 무제한 텍스트 채팅과 Think 버튼은 8월 10일 주에 순차 적용된다. OpenAI 자체 평가로는 새 Sol이 GPT-5.5 Instant 대비 사실 오류 68% 감소, Luna는 62% 감소를 보였다.

[8/2 노트](ai-news-2026-08-02.md)에서 다룬 것처럼 가장 저렴한 등급인 Luna의 API 가격은 이미 80% 인하된 상태였는데, 이번에는 API 가격이 아니라 ChatGPT 무료 사용자 자체의 사용량 제한을 없앤 것이 핵심이다. Threads는 이를 딥시크가 최근 가격을 올리고 앤트로픽이 무료 메시지 한도를 줄인 것과 대비해 "정반대 방향"이라고 짚었다 — 무료 티어 경쟁이 API 단가 경쟁을 넘어 사용량 자체의 경쟁으로 번지고 있다는 뜻이다. Luna 추론형은 1년 전 최상위 모델이었던 GPT-5 High와 비슷한 수준이고 Luna 기본형은 2년 전 GPT-4o에 해당한다는 Threads의 설명대로, 불과 1~2년 전 최고 수준의 성능이 이제 무료·무제한으로 풀린 셈이다. 다만 이 혜택은 코딩 에이전트 Codex에는 적용되지 않는다.

### AI 답변이 손글씨처럼 흘러나오는 스트리밍 데모 — 너무 정갈한 출력은 오히려 신뢰를 깎는다

Threads에 AI 답변을 손글씨처럼 흘려 쓰는 데모 두 건이 올라왔다. 하나는 애니메이션 SVG로 손으로 쓰는 듯한 출력을 만들었고, 다른 하나는 필기체 폰트에 밑줄·낙서·손그림 차트까지 섞었다. 둘 다 스트리밍 출력과 결합해 누군가 옆에서 실시간으로 받아 적어주는 느낌을 낸다. 기술 자체는 단순하다 — SVG 패스를 애니메이션으로 그리고, 필기체 폰트를 입히고, 스트리밍 속도를 조절하는 정도다. 웹서치로 확인해 보니 실제로 이런 방식을 구현한 오픈소스 라이브러리도 이미 존재한다. 2026년 5월 공개된 "Tegaki"는 React·Svelte·Vue·SolidJS·Astro·Web Components를 지원하는 폰트 기반 손글씨 애니메이션 라이브러리이며, SVGator·GSAP 커뮤니티 포럼에도 SVG 패스와 마스크로 손글씨 효과를 만드는 방법이 정리돼 있다.

Threads가 짚은 핵심은 기술이 아니라 왜 반응이 좋은가다. AI 출력이 너무 정갈하면 오히려 신뢰가 떨어진다 — 실수 없이 깔끔한 답변은 사람이 쓴 게 아니라 기계가 찍어낸 것처럼 보이기 때문이다. 중간에 망설이고 고치고 덧붙이는 흔적이 있어야 진짜 고민한 답변처럼 읽힌다는 것이다. 더 똑똑한 답변이 아니라 더 "사람 냄새 나는" 출력이 AI와 사람 사이의 마지막 간격을 메우는 지점이라는 게 이 데모가 던지는 시사점이다.

> 🔧 **적용 포인트** — 이 포트폴리오의 `/docent` 라이브 챗은 Claude 응답을 NDJSON으로 스트리밍해 3D 헤드 모프타겟을 구동하는 구조([docent-project](docent-project.md))라, 텍스트 버블 쪽에 GSAP로 SVG 밑줄/손글씨 느낌의 스트로크 애니메이션을 얹는 실험을 해볼 수 있다. 이미 스트리밍 파이프라인이 있으니 추가 인프라 없이 텍스트 렌더링 단계에만 손대면 된다 — 다만 Tegaki 같은 별도 라이브러리를 새로 얹기보다는, 현재 폰트에 맞춘 최소한의 CSS 마스크/GSAP 트윈으로 먼저 시도해보는 쪽이 스택에 더 잘 맞는다.

### 국가통계포털(KOSIS), MCP 서버로 국가통계 개방 — '모두의 AI 실험실'은 바이브코딩 인프라까지 무료 지원

Instagram(@ai_freaks.kr)에 따르면 국가통계포털(KOSIS)이 국가통계를 MCP(Model Context Protocol)로 제공하기 시작했다 — 서버 주소만 등록하면 Claude나 ChatGPT에 국가 통계를 대화하듯 물어볼 수 있다. 웹서치로 확인한 KOSIS 공식 공지에 따르면 이는 "AI 기반 이용자 맞춤형 KOSIS 통계표 생성 시범서비스"로, 1,360여 종의 국가승인통계와 26만여 통계표를 AI 기능에 접목해 자연어 질의로 맞춤 통계표를 만들 수 있게 한다. GitHub·LobeHub·Glama에는 이미 이 API를 감싼 커뮤니티 MCP 서버(`korean-stat-mcp`, `korea-stats-mcp` 등)가 여러 개 올라와 있어, Claude Desktop·Claude Code·Cursor·Windsurf 같은 MCP 지원 도구에서 곧바로 통계표 검색·메타데이터 조회·데이터 가져오기가 가능하다.

같은 게시물이 함께 소개한 '모두의 AI 실험실'은 국민 참여형 AI 서비스 개발 플랫폼이다. 웹서치로 교차 확인한 ZDNet Korea·대한민국 정책브리핑 기사에 따르면 이 플랫폼은 아이디어 제안부터 개발 인프라 제공, 성과 공유, 사업화·창업 연계까지 개발 전주기를 원스톱 지원하며, 이용자에게 생성형 AI 모델 구독용 토큰과 민간 클라우드 자원을 제공해 커서·클로드 코드·코파일럿·챗GPT·제미나이 같은 바이브코딩 도구를 비용 부담 없이 쓸 수 있게 한다. 선착순 3만 명 대상이라 신청 시점이 중요하다.

> 🔧 **적용 포인트** — 포트폴리오에 한국 관련 데이터 시각화(예: 지역별 통계, 트렌드 차트)를 추가할 계획이 있다면, 자체 크롤러 대신 이미 공개된 KOSIS MCP 서버(`korean-stat-mcp`, `korea-stats-mcp`)를 Claude Code에 연결해 원하는 통계를 바로 질의해보고, 그 결과를 React Three Fiber나 차트 컴포넌트용 정적 JSON으로 한 번만 추출해두는 방식이 API 키 발급·인증 절차를 새로 만드는 것보다 훨씬 빠르다.
