## 구글은 코딩 에이전트 하나를 접고, 오픈 모델 두 개가 실제로 내려받을 수 있게 됐다

오늘은 다섯 가지를 골랐다. 구글이 Jules를 접고 Antigravity로 몰아준다. Mistral과 NVIDIA는 각각 코딩용 초대형 모델과 음성 인식 모델의 가중치를 풀었다. 리눅스 커널에는 심각도 평가가 엇갈리는 TCP 취약점이 나왔고, 앤트로픽은 모델이 자기 대화를 스스로 점검하게 하는 값싼 감시 방식을 공개했다. 뒤의 둘은 숫자가 출처마다 달라서, 무엇이 확인된 것이고 무엇이 아닌지를 나눠 적었다.

### 구글, 코딩 에이전트 Jules 종료 — 11월 11일부터 읽기 전용·12월 31일 완전 종료, 백그라운드 실행은 Antigravity로 옮긴다

testingcatalog가 전했고, Crypto Briefing 보도와 Jules 변경 기록으로 교차 확인했다. 10월 29일 발표다.

- **일정**: 11월 11일까지는 진행 중인 세션을 마칠 수 있다. 그 뒤로는 읽기 전용이 되어 볼 수는 있지만 에이전트가 일을 하지 않는다. 12월 31일에 완전히 종료된다.
- **데이터**: Jules 변경 기록에 따르면 계정 설정, 예약 작업, 연결된 저장소, 메모리, 세션 기록을 로컬 폴더로 내보낼 수 있다.
- **어디로 가나**: 구글은 "Jules에서 배운 것을 Antigravity로 가져와, 원격 백그라운드 실행과 에이전트 중심 개발 환경을 함께 주겠다"고 했다. 다만 모든 기능이 그대로 옮겨진다고 약속하지는 않았다. Jules 무료 등급의 하루 15개 작업(동시 3개) 같은 한도가 Antigravity에서 어떻게 될지도 발표되지 않았다.
- **배경**: Jules는 GitHub 저장소를 연결하면 구글 클라우드 VM에서 버그 수정이나 기능 추가를 돌리는 비동기 에이전트였다. 2024년 말 Labs 실험으로 시작해 2025년 8월 정식 출시됐다. Antigravity는 2025년 11월에 나와 2026년 I/O에서 2.0이 됐고, 지금은 여러 에이전트 조율과 예약 작업을 지원한다. 같은 날 Antigravity에는 Jira·Confluence·Firebase·Notion·Stripe·Linear·Figma·Vercel·Datadog·Postman 등을 붙이는 플러그인 마켓플레이스도 열렸다(testingcatalog).
- **해석**: testingcatalog는 Jules v2가 "AI 슈퍼앱이 등장하고 구글이 Codex와 맞서야 하던 시점"에 기획된 게 불운했다고 봤다. 구글 안에서 코딩 에이전트 제품이 하나로 정리되는 흐름이다. 6월에 Gemini CLI·Code Assist 개인용이 정리된 데 이어 두 번째다.

### Mistral Large 4(Le Chonk) 정식 가중치 공개 — 1조 파라미터 MoE, FrontierCode 2.0 오픈웨이트 1위는 자체 발표이고 독립 측정은 더 낮다

choi.openai와 testingcatalog가 전했다. Mistral 공식 블로그와 The Decoder·heise 보도, Artificial Analysis 게시물로 교차 확인했다. 10월 29일 공개다.

- **모델**: 이달 초 API 프리뷰로 나왔던 Large 4의 개선판 가중치다. 전체 약 1조(1.05T) 파라미터의 MoE로, 토큰당 활성 파라미터는 Hugging Face 저장소 이름 기준 약 52B다(일부 보도는 49B). 이미지도 읽는 네이티브 멀티모달이고, 추론 강도를 Low·Medium·High(기본값) 세 단계로 고른다.
- **코딩 성적**: Mistral 발표로는 Cognition의 비공개 벤치마크 FrontierCode 2.0에서 19.7%로 오픈웨이트 1위다. 하지만 Artificial Analysis의 독립 측정은 15%로, DeepSeek V4.1 Flash(29%)·GLM-5.3(22%)보다 낮았다. choi.openai가 쓴 "토큰 47% 절감"은 FrontierCode가 아니라 Artificial Analysis Coding Agent Index 이야기다. 이 지수에서 48%로 GLM-5.3과 사실상 동률이면서 작업당 토큰을 47% 덜 썼다. Terminal-Bench 4.0은 41%로 프리뷰보다 13점 올랐다.
- **보안**: Artificial Analysis Cyber Index 51%, 악성 사이버 요청 거절률 평균 96.6%, B3 에이전트 보안 벤치마크 공격 저항 97.1%를 내세웠다. 취약점 탐지·수정에 특화했다는 설명도 붙었다.
- **라이선스와 배포**: "Mistral Ecosystem Open-Weight License"라는 수정 MIT 라이선스다. 상업적 사용·파인튜닝은 되지만, 이 모델을 API 서비스로 되파는 경우엔 별도 상업 라이선스가 필요하다. vLLM·SGLang으로 직접 띄울 수 있고, Mistral API·OpenRouter·NVIDIA NIM·Microsoft Foundry에서도 쓸 수 있다. API 가격은 100만 토큰당 입력 0.70달러(캐시 0.07달러)·출력 2.10달러다.
- **위치**: Artificial Analysis는 "중국 밖에서 만든 오픈웨이트 모델 중 근소한 1위"라고 평했다. 종합으로는 여전히 중국 오픈 모델에 뒤진다는 게 The Decoder의 정리다.

> 🔧 **적용 포인트** — 1조 파라미터라 직접 띄울 일은 없지만, API 가격(입력 0.70·출력 2.10달러)은 도슨트 RAG의 답변 모델 후보로 비교해볼 만하다. 고를 때는 회사 발표치(19.7%)가 아니라 독립 측정치(15%)를 기준으로 삼고, 한국어 답변 품질은 직접 몇 개 질문으로 돌려본 뒤 판단한다.

### 리눅스 커널 IPv4 TCP use-after-free CVE-2026-98432 — Ubuntu는 CVSS 9.8, 다른 DB는 5.9로 갈리고 22.04·24.04 패치는 아직 진행 중

choi.openai가 전했다. Ubuntu 보안 공지와 Wiz·Feedly(Tenable) 취약점 DB로 교차 확인했다.

- **결함**: TCP 연결 요청에 붙는 IP 옵션(`inet_opt`, `ireq_opt`)을 RCU 유예 기간을 기다리지 않고 바로 해제한다. 그래서 한 CPU가 SYN-ACK를 만드는 동안 다른 CPU가 재전송된 SYN을 처리하면, 이미 해제된 메모리를 `ip_options_build()`에서 읽을 수 있다. 요청 소켓 마이그레이션(`net.ipv4.tcp_migrate_req=1`이나 reuseport 마이그레이션 BPF 프로그램)에서도 같은 일이 생긴다. 수정은 `kfree()`를 `kfree_rcu()`로 바꾸는 것이다. IPv6는 첫 번째 문제에 해당하지 않는다.
- **심각도가 엇갈린다**: Ubuntu 공지는 CVSS 9.8(치명적), 우선순위 High다. 반면 Feedly에 실린 점수는 5.9(보통)로, 공격 복잡도를 높게 봤다. 경쟁 상태(race condition)를 맞춰야 터지는 버그라서 실제 악용 난이도는 9.8이라는 숫자가 주는 인상보다 높을 수 있다. Wiz 기준으로 10월 15일 공개 당시 공개 PoC나 실제 악용은 확인되지 않았다.
- **새 소식이 아니다**: NVD 첫 공개는 10월 15일이다. 화제가 된 것은 Ubuntu 공지가 10월 29일 갱신되면서다.
- **패치 상태(10월 29일 Ubuntu 기준)**: 26.10·26.04 LTS·24.04 LTS·22.04 LTS 기본 커널은 모두 "작업 중"이다. 20.04·18.04·16.04는 취약으로 표시돼 있다. AWS·Azure·GCP·Oracle용 커널 변형도 상당수가 취약 또는 작업 중이다.
- **독자 반응**: "서버를 쓰고 있으면 꺼야 하냐"는 질문이 달렸다. 끌 일은 아니다. 배포판 보안 공지를 구독해 두고, 수정 커널이 나오면 업데이트하고 재부팅하면 된다.

### NVIDIA Nemotron 3.5 Transcribe — 한국어 포함 40개 언어 받아쓰기·화자 구분·용어 힌트를 한 모델에, 1시간짜리 오프라인 처리용 오픈 모델

Instagram ai_freaks.kr가 전했다. Hugging Face 모델 카드와 MarkTechPost·The Decoder 보도로 교차 확인했다. 10월 28일 공개다.

- **무엇을 하나**: 받아쓰기(ASR), 영어와의 음성 번역, "누가 말했는지" 붙이는 화자 구분 받아쓰기를 한 모델이 한다. 따로 놀던 ASR 모델과 화자 분리 모델을 이어 붙이지 않아도 된다. 지원 언어는 받아쓰기 40개, 번역 31개, 화자 구분 13개다. 한국어는 받아쓰기·번역·화자 구분·한영 섞어 말하기(코드 스위칭)를 모두 지원하는 "Leading" 등급이다.
- **용어 힌트**: 사람 이름이나 도메인 용어를 프롬프트로 넣으면 그 단어를 더 잘 받아 적는다. ContextASR-Bench에서 단어 오류율(WER)이 3.33%에서 1.71%로 떨어졌다.
- **성적**: Open ASR 영어 9개 데이터셋 평균 WER 4.71%, 다국어 7개 언어 4.62%, 여러 화자 cpWER 15.80%다. NVIDIA는 오픈웨이트 모델 중 최고라고 했다.
- **구조와 요구 사양**: Mamba-2와 트랜스포머를 섞은 MoE로, 전체 34B·활성 약 4.3B다. 배포 기준은 H100 80GB 1장이고, vLLM 0.32.0·Transformers·GGML·SGLang-Omni로 돌릴 수 있다. 라이선스는 OpenMDW-1.1로 상업적 사용이 된다.
- **제약**: 모델 카드가 분명히 "오프라인 모델"이라고 적었다. 최대 1시간 녹음을 한 번에 처리하지만, 실시간 스트리밍 서비스는 아니다. 실시간이 필요하면 6월에 나온 600M짜리 Nemotron 3.5 ASR(스트리밍용)이 따로 있다. 9월의 Nemotron 3 Diarization(화자 분리 전용)과도 다른 모델이다.

> 🔧 **적용 포인트** — 도슨트 음성 대화처럼 말하는 즉시 받아 적어야 하는 곳에는 맞지 않는다(오프라인 전용). 쓸 자리는 녹음 파일 쪽이다. 면접·발표 연습 녹음을 한국어로 받아 적어 화자별로 나누고, 프로젝트 이름(행가래, ARMI 등)을 용어 힌트로 넣어 회고 자료를 만드는 정도라면, H100 대신 build.nvidia.com 호스팅 엔드포인트로 먼저 시험해볼 수 있다.

### 앤트로픽 self-assessment — 응답 직후 Claude가 10토큰 남짓의 JSON으로 스스로 위험을 표시, 탐지는 쓸 만하지만 차단기로는 약하다

testingcatalog가 소개했다. 앤트로픽 Safeguards 블로그 원문으로 확인했다. 원문은 10월 16일에 올라왔고, 어제 다시 화제가 됐다.

- **방식**: Claude가 답한 직후 시스템이 짧은 지시를 덧붙여 "이 대화가 안전한지" 스스로 평가하게 한다. 답은 정해진 JSON 스키마로 나온다. 문제가 없으면 `{"flagged": false}` 한 줄이다. 문제가 있으면 이유·분류·세부 정책·거절 여부·1~10 우선순위가 붙는다. `flagged`의 확률값을 연속 점수로 써서 문턱값을 조절한다. 결과는 사용자에게 보이지 않고 사후 검토에 쓰인다.
- **싼 이유**: 대화가 이미 KV 캐시에 있으니 새로 처리하는 건 짧은 지시뿐이고, 생성은 평균 10토큰 정도다. 앤트로픽은 전체 추론 비용의 2% 미만이라고 추산했다. 별도의 분류용 모델에 프롬프트로 판정을 맡기는 방식(prompted classifier)보다 훨씬 싸다. 이 비용은 고객에게 청구되지 않는다.
- **탐지 성적**: Claude Fable 5 실제 트래픽에서 오탐률 1% 기준으로, 더 강한 prompted classifier가 잡은 유해 대화의 78%, 고위험 건의 94%를 잡았다.
- **차단 성적은 약하다**: 공격형 사이버 과제 24개로 레드팀 시험을 했다. 안전장치 없이 공격 성공률 79%, self-assessment로 막으면 54%, prompted classifier로 막으면 25%였다. 공격 한 번 성공에 드는 생성 토큰은 16.3만 → 69.1만 → 210만으로 늘었다. testingcatalog가 인용한 "공격당 토큰 약 4배"는 이 중간값이다. 사후 감시로는 24건 중 21건을 한 번 이상 표시했다.
- **앤트로픽이 밝힌 한계**: 실제 서비스에서는 표시만 하고 막지 않는다. 작정한 공격자는 피할 수 있다. 학습 기준이 된 분류기의 사각지대를 그대로 물려받는다. Claude 자신의 행동을 감시하는 용도로는 아직 믿을 수 없다. 개발자가 API로 켜는 기능이 아니라 앤트로픽 내부 안전장치다.

> 🔧 **적용 포인트** — 기능은 못 쓰지만 패턴은 가져올 수 있다. 도슨트 챗봇에서 답변을 만든 직후, 같은 대화에 이어 "이 답변이 코퍼스 밖 내용을 지어냈는가"를 `{"flagged": bool, "reason": ...}`로 짧게 묻는다. 프롬프트 캐시가 맞으면 추가 비용이 작다. 결과는 사용자에게 보이지 않게 로그로만 쌓아 사후 점검에 쓰고, 실시간 차단 장치로 믿지는 않는다. 앤트로픽 결과대로 차단용으로는 약하기 때문이다.
