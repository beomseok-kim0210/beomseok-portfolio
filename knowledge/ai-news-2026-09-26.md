## DevDay 사흘 전, "더 빠르게"와 "꺼지지 않는 에이전트"가 동시에 새어 나왔다

### 오픈AI, 초당 750토큰 Ultrafast API 확대 준비 포착 — Responses API에 Standard·Fast·Ultrafast 속도 선택기

Threads(testingcatalog)에 따르면 오픈AI가 일부 고객에게만 열어뒀던 Ultrafast 모드를 DevDay(9월 29일) 전후로 더 많은 사용자에게 확대할 준비를 하고 있다. [8/14 노트](ai-news-2026-08-14.md)에서 다룬 GPT-5.6 Sol Ultrafast 프리뷰의 후속이다. 새로 포착된 건 Responses API 플레이그라운드의 속도 선택기로, Standard·Fast·Ultrafast 세 단계 중 고를 수 있게 준비되고 있다. 워크로드별 가치에 따라 지연 시간을 골라 돈을 내는 구조가 될 가능성이 크다.

웹서치로 확인한 오픈AI 공식 프리뷰 글과 세레브라스 블로그에 따르면 Ultrafast는 세레브라스 웨이퍼 스케일 칩에서 돌아가며 최대 초당 750 출력 토큰, 표준 대비 최대 14배 빠르다. 증류·양자화한 변형이 아니라 표준과 같은 GPT-5.6 Sol을 그대로 돌린다는 점이 강조된다. 오픈AI는 세레브라스와 750MW 규모 파트너십을 맺고 2028년까지 단계적으로 용량을 늘린다. 현재 확인된 지원 모델은 GPT-5.6 Sol이며, [9/23에 나온 GPT-6 Sol](ai-news-2026-09-23.md)·Astra까지 처음부터 지원될지는 확인되지 않았다. 가격도 아직 공개되지 않았다.

> 🔧 **적용 포인트** — 음성 인터페이스에선 "생성 속도"가 곧 "첫 음성까지의 시간"이다. 도슨트 음성 응답처럼 LLM 응답 → TTS로 이어지는 구조라면, 초당 750토큰이면 답변 전체가 TTS 첫 문장보다 먼저 끝나므로 병목이 네트워크와 TTS 쪽으로 넘어간다. DevDay에서 가격이 나오면 "도슨트 첫 발화 지연"을 기준으로 현재 모델과 비교해 볼 만하다.

### 오픈AI DevDay에서 상시 작동 에이전트 "o" 공개설 — 채팅을 닫아도 일하고 자체 이메일까지

testingcatalog는 ChatGPT 내부 설정에서 "o"라는 표시 이름과 "-o" 이메일 접미사가 발견됐다며, 오픈AI가 DevDay에서 상시 작동(always-on) 소비자용 에이전트를 공개할 것으로 봤다. 100달러 Pro 요금제 업그레이드 화면에 "o, 당신의 상시 비서"라는 문구가 잠깐 노출되기도 했다. 웹서치로 확인한 Wccftech·kingy.ai 등 보도를 종합하면, "o"는 채팅 세션 밖에서도 계속 일하는 에이전트로 자체 이메일 신원을 가질 가능성이 있으며, ChatGPT Workspace의 커스텀 에이전트 기반 "Aeon" 위에 소비자용으로 얹은 형태로 추정된다. 다만 DevDay 공식 페이지엔 "o"나 에이전트·Codex 언급이 없어 발표 여부는 아직 가설 단계다. 메타 Muse, 마이크로소프트 Autopilot(아래 항목), 앤트로픽 클라우드 세션까지 "사용자가 없어도 계속 일하는 에이전트"가 한 주 사이 업계 공통 방향으로 굳어지는 모습이다.

### 마이크로소프트 새 Copilot 공개 — Home·Code·Autopilot 3축, GitHub Copilot 기술로 사내 앱 생성

마이크로소프트가 Copilot을 세 축으로 재편했다. 공식 블로그와 testingcatalog에 따르면 ① **Home**은 Chat과 Cowork를 합친 시작 화면으로 Word·Excel·PowerPoint를 Copilot 안에서 바로 만들고 수정하며 Office 앱과 동기화한다. ② **Code**는 GitHub Copilot과 같은 기반 기술로 자연어 설명에서 대시보드·위젯·트래커·자동화 앱을 만들어, 회사 테넌트 안 샌드박스에 호스팅한다. 거버넌스는 프리뷰로 나온 Copilot Managed Runtime이 맡는다. ③ **Autopilot**은 이름·역할·목표를 부여받은 상시 에이전트로, 독립된 메모리·신원·작업공간을 갖고 Teams·Outlook·문서에서 아무도 쓰지 않을 때도 후속 작업을 이어간다. Home과 Code는 몇 주 안에 Frontier 프로그램 사용자에게, Autopilot은 9월 말 비공개 프리뷰로 확대된다. 개발자 관점에선 "비개발자용 앱 빌더"가 GitHub Copilot 엔진 위에서 사내 배포까지 한 번에 되는 구조라는 점이 핵심이다.
