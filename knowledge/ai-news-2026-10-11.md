## 속도는 돈으로 사고, API 문턱은 낮아지고, 취약점 스캔은 무료가 됐다

btibor91의 41주차 정리에서 앞서 다루지 않은 세 가지를 골랐다. 오픈AI는 같은 모델을 더 빨리 돌리는 대신 비싸게 받는 요금 단계를 열었고, API 사용 티어를 단순하게 바꿨다. 앤트로픽은 오픈소스 프로젝트에 자사 최상위 모델로 돌린 취약점 스캔을 무료로 주기 시작했다.

### GPT-6.1 Sol Ultrafast — service_tier 하나로 Codex 최대 8배·API 최대 6배 빠르게, 대신 표준가의 6배

btibor91은 "GPT-6.1 Sol의 Ultrafast 모드가 API·Codex·ChatGPT Work에서 Sol Standard보다 최대 8배 빠르다"고 정리했다. 보도들은 출시일을 10월 8일로 잡는다.

- **속도**: Codex에서 최대 8배, API에서 최대 6배 빠른 생성이며 출력 속도가 초당 최대 300토큰까지 나온다는 보도가 있다. 8배는 오픈AI가 밝힌 **최대치**이지 모든 요청이 그만큼 빨라진다는 뜻은 아니다.
- **쓰는 법**: 모델은 그대로 `gpt-6.1-sol`이고 요청에 `service_tier: "ultrafast"`를 넣는다. 문서 요약에 따르면 연결을 매번 새로 맺으면 네트워크 지연이 이득을 깎아 먹기 때문에 WebSocket 연결을 권장한다. Standard·Fast와 별도의 rate limit이 적용된다는 보도도 있다.
- **가격**: 여러 출처가 입력 100만 토큰당 12달러, 출력 60달러로 전한다. 표준 Sol(2달러/10달러)의 정확히 6배다. 다만 오픈AI 공식 가격표를 직접 확인하진 못했고, ChatGPT·Codex에서 누가 쓸 수 있는지는 보도마다 엇갈린다.

[10/6 노트](ai-news-2026-10-06.md)의 "28일 연속 개선" 1일차가 구독 기본 속도를 30에서 50 TPS로 올린 것이었다면, 이번엔 API에서 돈을 더 내면 속도를 사는 선택지가 생긴 셈이다.

### 오픈AI 유료 API 티어 5단계→3단계(Build·Launch·Grow) — 최상위 진입 문턱이 1,000달러에서 500달러로

같은 정리에 "유료 API 티어가 다섯 개에서 세 개로 줄었다"는 항목이 있다. 변경일은 10월 6일이다.

- **새 구조**: 무료 티어는 그대로 두고 유료를 Build·Launch·Grow 세 단계로 합쳤다. 누적 결제액 기준은 Build 5달러, Launch 100달러, Grow 500달러이고, 월 사용 한도는 각각 500달러, 5,000달러, 20만 달러다. 기존 유료 조직은 자동으로 새 티어로 옮겨진다.
- **핵심 변화**: 최상위 티어 진입 조건이 기존 Tier 5의 1,000달러에서 500달러로 내려갔다. 월 한도는 지출 상한이지 포함 크레딧이 아니다.
- **rate limit**: 한 출처는 Astra·Sol·Terra의 분당 토큰이 Build 100만, Launch 400만, Grow 4,000만이라고 전하지만, 오픈AI 공식 표로 확인하진 못했다. 실제 값은 조직 설정의 Limits 페이지에서 보는 게 정확하다.

### 앤트로픽 Cyber Mission — 오픈소스 무료 취약점 스캐너 OSS Scanner와 11개사 기반시설 방어 프로그램

앤트로픽은 10월 8일(현지) **Anthropic Cyber Mission**을 발표했다. 두 갈래다.

- **OSS Scanner**: 구글 OSS-Fuzz를 본뜬 신청형 무료 서비스다. 등록한 오픈소스 프로젝트를 Claude Mythos 등 앤트로픽 최상위 모델로 주기적으로 스캔한다. 리포트마다 재현 코드(PoC)가 붙고, 가능하면 버그가 들어온 커밋을 찾은 기록(bisection)과 수정 패치 후보도 붙는다. 핵심 메인테이너가 앤트로픽 GitHub 저장소에 PR을 올려 신청하고, 대상은 OSS-Fuzz처럼 "인프라·사용자 보안에 미치는 영향이 큰지"로 건별 판단한다.
- **정확도와 한계**: 초기 버전의 치명·높음 등급 발견 97건을 전문 침투 테스터가 검토해 85건을 공개 승인했고, 나머지 12건도 1건을 빼면 이미 알려진 이슈와 겹친 실제 버그였다. wolfSSL은 초기 시험 리포트 74건 중 2건을 빼고 모두 유효했고 5건이 CVE가 됐다고 밝혔다. 다만 리포트는 사람 검토 없이 메인테이너에게 가므로 심각도 판정이 틀릴 수 있다. 원본 리포트를 감당할 인력이 없는 프로젝트는 기존처럼 사람이 확인한 리포트를 받는다.
- **Critical Infrastructure Defense Program**: 전력망·수도·교통 같은 운영기술(OT)을 지키는 보안 업체에 Claude 모델, 현장 엔지니어, 위협 연구를 지원한다. 창립 파트너는 Accenture, Booz Allen Hamilton, CrowdStrike, Deloitte, Dragos, Hitachi, Insane Cyber, Nozomi Networks, Palo Alto Networks, PwC, Rockwell Automation 11곳이다. 상업 조건은 공개되지 않았다.
