### Claude Code Mods 정식 출시 — TypeScript 함수로 프롬프트·도구 호출·권한·UI를 가로채는 확장, 플러그인에 담아 배포

[9/15 노트에서 "Function Hooks"라는 이름으로 예고됐던](ai-news-2026-09-15.md) Mods가 10월 1일(현지) Claude Code CLI와 데스크톱 앱에 정식으로 들어왔다. 앤트로픽 공식 블로그의 설명은 "Claude Code의 동작을 바꾸는 작은 TypeScript 함수"다. testingcatalog가 전한 공지 문구대로, 내부적으로는 훅이고 플러그인 안에 담겨 배포되며, 세션 안에서 돌면서 모든 이벤트를 실시간으로 본다.

기존 셸 기반 Hook과 가장 크게 다른 점은 **이벤트 전·후에 반응하는 데서 그치지 않고 이벤트 자체를 대체할 수 있다**는 것이다. 공식 문서가 꼽은 용도는 다음과 같다.

- 모델에 가기 전에 프롬프트 다시 쓰기
- 도구 호출 막기·고쳐 쓰기·재시도
- 권한 요청 승인·거부
- Claude가 읽기 전에 도구 출력에서 비밀값 지우기
- 도구 결과 화면을 바꾸거나 새 UI 요소 그리기

여러 Mod는 로드된 순서대로 겹쳐 실행된다. 설치는 기존 플러그인 경로 그대로 Claude 디렉터리나 CLI의 `/plugin`으로 하고, 공유도 플러그인으로 묶어 디렉터리에 제출하면 된다. 주의할 점은 **Mod가 샌드박스 안에서 돌지 않는다**는 것이다. Claude Code와 같은 권한으로 내 컴퓨터에 접근하므로 믿을 수 있는 출처의 Mod만 설치해야 한다. Team·Enterprise 요금제에서는 `sec-default`라는 내장 Mod가 가장 먼저 로드돼, 다른 Mod가 권한 규칙을 덮어쓰는 것 같은 위험한 동작을 막는다.

출시 직후 커뮤니티에는 마우스를 올릴 때만 민감 정보를 보여주는 Mod, Mermaid 다이어그램을 터미널 안에서 바로 렌더링하는 Mod, diff 창을 옆에 고정하는 Mod 등이 올라왔다. testingcatalog는 "이제 클라이언트 소프트웨어 대부분을 약간의 노력과 토큰으로 개조할 수 있다"며 이를 개인화된 UI로 가는 첫걸음으로 봤다. 이 글 댓글에서는 testingcatalog가 인용한 문구의 출처가 Addy Osmani의 "Getting started with Claude Code mods" 글이라는 지적이 나왔다. 이 글이 올라온 곳은 같은 날 앤트로픽이 연 개발자용 사이트 **claude.dev**다. Claude Code·API 사용법, Skills, 컨텍스트 엔지니어링, 에이전트 워크플로처럼 Claude 개발팀이 실제로 일하는 방식을 정리하는 곳으로, [9/24 팁 노트](ai-tips-2026-09-24.md)에서 다룬 "claude.ai를 2주 만에 3배 빠르게 만든 방법"도 여기로 모였다.

> 🔧 **적용 포인트** — 이 포트폴리오에서 바로 만들어볼 만한 Mod는 두 가지다. 첫째, 도구 출력에서 `.env`의 API 키나 RunPod 엔드포인트 같은 값을 Claude가 읽기 전에 지우는 비밀값 마스킹 Mod. 둘째, `git push`나 `knowledge/` 밖의 파일 수정처럼 예약 작업(이 AI 뉴스 작업 등)이 건드리면 안 되는 도구 호출을 막는 가드 Mod다. 둘 다 Claude Code에게 "이런 Mod를 만들어 줘"라고 시켜 프로젝트 플러그인으로 두면 된다. 샌드박스가 없으니 남이 만든 Mod는 코드를 읽어 본 뒤에만 설치하자.

### 구글 Stitch CLI 공개 — 코딩 에이전트가 터미널에서 화면·디자인 시스템을 만들고, 로컬 개발 화면을 Stitch로 되돌려 보낸다

구글 랩스의 AI UI 디자인 도구 Stitch가 `@google/stitch` CLI를 내놓았다. 로컬 코딩 에이전트를 Stitch에 연결해 터미널에서 화면과 디자인 시스템을 만들 수 있고, 반대로 **로컬 개발 서버에 떠 있는 화면을 스냅숏으로 Stitch에 보내** 그 위에서 디자인 작업을 이어갈 수도 있다. choi.openai는 사람이 명령어를 직접 치지 않아도 Antigravity 같은 에이전트에게 Stitch를 쓰라고 시키면 된다는 점을 짚었다.

Stitch는 그동안 MCP 서버, SDK, 에이전트 스킬(Stitch Skills), 디자인 시스템을 담는 `DESIGN.md`를 차례로 붙여 왔다. MCP는 Claude Code·Cursor·Gemini CLI·Codex·OpenCode 등에서 쓸 수 있다. 여기에 CLI가 더해지면서 "디자인 생성 → 코드 → 실제 화면을 다시 디자인 도구로"라는 왕복 경로가 코딩 에이전트의 작업 흐름 안에 완성된 셈이다. 원문 댓글에서는 "디자인이 에이전트 작업 안으로 들어오면 색·글꼴·간격 규칙을 파일 하나로 먼저 정해 두는 게 더 중요해진다. 안 그러면 화면을 만들 때마다 톤이 조금씩 달라진다"는 지적이 나왔다.

> 🔧 **적용 포인트** — V3 디자인 랩처럼 그레이박스부터 시안을 여러 번 돌리는 작업에서, 로컬 dev 서버 화면을 Stitch로 보내 대안 레이아웃 몇 개를 받아 보고 고르는 흐름을 시험해볼 만하다. 다만 Stitch가 내놓는 결과는 HTML/CSS 정적 화면이라 R3F 씬·GSAP·Lenis 모션은 담기지 않는다. 히어로 3D 영역은 빼고 텍스트·카드·내비게이션 같은 정적 섹션에만 쓰는 게 현실적이다. `DESIGN.md`에 지금 쓰는 색·타이포 토큰을 먼저 적어 두면 결과물이 기존 톤에서 덜 벗어난다.

### Cloudflare `cf` — 3,000개 넘는 API 작업을 다루는 에이전트용 CLI, 자연어로 명령어를 찾는다

Stitch CLI와 같은 흐름에 있는 소식이다. Cloudflare가 생일 주간(Birthday Week)에 새 CLI `cf`를 베타로 공개했다. 기존 Wrangler가 약 280개 명령을 지원했다면, `cf`는 **Cloudflare API 전체(3,000개 이상의 작업)**를 명령줄로 다룬다. 도메인 구매까지 터미널에서 할 수 있다. Cloudflare는 지난주 Wrangler 사용량의 48%가 에이전트에서 나왔다며, 처음부터 에이전트가 쓰기 좋게 설계했다고 밝혔다.

- **출력은 기본이 JSON**이다. 사람보다 에이전트가 파싱하기 쉬운 형식을 기본값으로 삼았다.
- **`cf cli search "내 큐에 막혀 있는 메시지 확인"`**처럼 자연어로 검색하면 관련 명령어 목록을 돌려준다. 에이전트가 명령어 이름을 몰라도 스스로 찾아 쓸 수 있다.
- 설정 파일은 Wrangler의 TOML/JSONC 대신 타입 검사가 되는 **`cloudflare.config.ts`**를 쓴다.
- `cf migrate`로 기존 Workers 프로젝트를 옮길 수 있다. Wrangler는 베타 종료 후 18개월 동안 계속 지원한다.
- API 문서·SDK를 만드는 스키마에서 CLI 명령까지 자동으로 생성하는 내부 도구 **Forge**도 오픈소스로 풀었다.

원문 댓글에서는 `cf`가 Cloud Foundry CLI(`cf push`로 유명)와 이름이 겹친다는 지적이 나왔다. 두 도구를 함께 쓰는 환경이라면 PATH 충돌을 확인해야 한다.

> 🔧 **적용 포인트** — 이 포트폴리오는 Vercel에 배포돼 있어 당장 쓸 일은 없다. 다만 "에이전트가 쓰기 좋은 CLI"의 조건(기본 JSON 출력, 자연어 명령 검색, 타입이 있는 설정 파일)은 도슨트나 크라임씬에 운영 스크립트를 붙일 때 그대로 참고할 만하다. Claude Code에게 맡길 스크립트라면 사람용 표 대신 `--json` 출력부터 만들어 두자.

### Comfy API 정식 출시 — ComfyUI 워크플로 JSON을 그대로 고정 빌드해 자동 확장 API로 배포

ComfyUI가 9월 30일 유료 플랜(Standard 이상) 사용자 전체에게 **Comfy API**를 열었다. 워크플로 JSON을 넣으면 그 안에서 쓴 커스텀 노드, 모델, LoRA, Python 의존성, ComfyUI 버전까지 확인해 하나의 **Build**로 묶는다. 이 Build에서 바꿀 수 없는 릴리스를 만들고, 릴리스를 고유 URL을 가진 관리형 엔드포인트로 배포한다. 테스트한 환경이 곧 배포되는 환경이라, 노드 버전이 어긋나 운영에서만 깨지는 ComfyUI의 고질적인 문제를 줄이려는 설계다. 수정할 때는 Build를 고쳐 새 릴리스를 만들면 되고, 서비스 중인 릴리스는 건드리지 않는다.

GPU는 초 단위 과금이며, 시간당 RTX PRO 6000(96GB) 4.54달러, H100(80GB) 6.23달러, H200(141GB) 7.71달러, B200(180GB) 11.23달러다. 네트워크 스토리지는 GB당 월 0.20달러다. 빌드·배포·사용량·API 키는 platform.comfy.org 한 콘솔에서 관리한다.

> 🔧 **적용 포인트** — 도슨트처럼 RunPod 같은 GPU 엔드포인트를 직접 관리하는 구조에서, "환경 전체를 바꿀 수 없는 릴리스로 고정하고 URL 단위로 배포·롤백한다"는 방식은 그대로 가져올 만하다. 모델 가중치·의존성 버전을 담은 이미지 태그를 릴리스 단위로 남겨 두면, 음성·입모양 모델을 바꿨다가 되돌릴 때 훨씬 안전하다.

### Tavus Griffin — 1분 영상통화 상대의 48%가 사람으로 착각한 실시간 대화 모델, 아직 연구 프리뷰

AI 영상 아바타 회사 Tavus가 자칭 최초의 "Human Interaction Model(HIM)"인 Griffin을 공개했다. 참가자 54명이 Griffin과 1분간 영상통화를 했는데, 이 중 26명(48%)이 상대가 실제 사람이라고 답했다. Tavus는 기존 시스템이 3% 미만에 그쳤다고 밝혔다.

핵심은 **듣기·판단·말하기를 순서대로 하지 않고 동시에 돌린다**는 점이다. 기존 음성·영상 에이전트는 사용자가 말을 멈추기를 기다렸다가 답하는 구조였다. 반면 Griffin은 1초에도 여러 번 대화 상황을 다시 판단한다. 그래서 상대가 말하는 도중에 고개를 끄덕이거나 "음" 하고 맞장구를 치고, 끼어들면 멈추고, 잠깐 쉬는 것과 말을 끝낸 것을 구분하며, 카메라에 보여준 물건을 대화에 바로 반영한다. 구조는 오디오·비디오를 인식해 반응을 정하는 엔진과, 음성과 720p 영상을 스트리밍으로 만드는 생성 엔진의 두 부분이다. 음성은 10ms 단위 패킷으로 만들고, 영상은 320ms 단위로 생성한다. 오디오에서 영상까지의 지연은 H100 기준 평균 0.43초이고, 영상 품질 지표에서는 1위, 입모양 동기화(LSE-C 7.27)에서는 2위였다고 한다.

배포는 하지 않았다. 경량판 Griffin-Lite도 일부 신뢰 테스터에게만 연구 프리뷰로 열렸다. Tavus는 사람으로 오인될 수 있다는 성질 자체가 위험하다며, AI임을 알리는 기능과 안전 절차를 먼저 갖추겠다고 밝혔다. 가격은 공개되지 않았다.

> 🔧 **적용 포인트** — 도슨트 아바타가 가야 할 방향을 잘 보여주는 사례다. 당장 가져올 수 있는 아이디어는 두 가지다. 첫째, 사용자가 말하는 동안 아바타가 가만히 있지 않도록 STT 부분 인식 결과가 들어올 때마다 작은 끄덕임이나 눈 깜박임 같은 "듣는 중" 반응을 넣는 것. 둘째, 사용자가 말을 시작하면 TTS 재생과 입모양을 즉시 멈추는 끼어들기(barge-in) 처리다. 입모양 품질만큼이나 이 "턴 주고받기"가 사람처럼 느껴지는 정도를 좌우한다는 게 Griffin 실험의 메시지다.

### 'Sign in with ChatGPT' 구독 연동 세부 — 서드파티 도구가 사용자의 Plus·Pro 한도로 추론, 앱별 주간 상한 설정

[DevDay 노트](ai-news-2026-09-30.md)에서 한 줄로 다룬 Sign in with ChatGPT(SIWC) 구독 연동의 구체적인 내용이 나왔다. 7월에 베타로 나온 SIWC는 원래 계정 로그인만 연결했다. 이번 확장으로 Plus·Pro 사용자가 스위치를 켜면 참여 앱이 AI 요청을 **사용자 본인의 ChatGPT 요금제 한도로 처리**한다. 그 앱에 구독을 따로 결제하거나 OpenAI API 키를 넣을 필요가 없다는 뜻이다.

swhan0329_가 정리한 공식 문서 기준 조건은 이렇다. 계정 로그인과 구독 사용 허용은 별도로 선택한다. 사용량은 ChatGPT Work·Codex 한도에서 차감되며, 연결한다고 사용량이 늘지는 않는다. 앱마다 주간 상한을 전체 주간 한도의 비율로 정할 수 있고, 상한에 닿으면 앱 쪽 과금으로 넘어가지 않고 그냥 멈춘다. 앱 자체 이용료는 별도로 붙을 수 있다. 이 연결만으로 앱이 ChatGPT 대화나 메모리를 볼 수는 없다. 출시 파트너는 16곳으로, Amp Code·Devin·Kilo Code·Notion·Vercel·Warp 등 상용 도구와 OpenClaw·OpenCode·Pi·T3 같은 오픈소스 프로젝트가 포함됐다. 기능 담당자 Vignesh는 오픈소스 도구들이 그동안 추론 비용을 사용자에게 넘기려고 우회적인 연결 방식을 써 왔고, 상용 도구도 크레딧·정액제·BYOK 사이에서 가격을 계속 조정해야 했다며, OpenAI가 지능을 전기처럼 공급하고 개발자는 도구를 만드는 데 집중하게 하겠다고 설명했다.

개발자 입장에서는 "BYOK 입력창" 대신 "ChatGPT로 로그인" 버튼 하나로 추론 비용을 사용자 구독에 넘길 수 있는 경로가 생긴 것이다. 다만 참여 앱 승인 방식이고, 사용자 쪽은 조건에 맞는 Plus·Pro로 한정된다.

### FLUX 3 Image·Ideogram 4.5 — 이미지 모델 경쟁이 '생성'에서 '여러 번 고쳐도 무너지지 않는 편집'으로

하루 차이로 나온 두 이미지 모델이 같은 문제를 겨냥했다. 같은 이미지를 여러 번 고치면 색이 바래고, 픽셀이 밀리고, 고치지 않은 부분까지 조금씩 변하는 문제다.

- **FLUX 3 Image (Black Forest Labs, 10월 1일)**: 7월에 공개한 멀티모달 FLUX 3 계열의 이미지 버전이다. 정밀 편집에서 지정한 영역 밖의 픽셀은 비트 단위로 똑같이 유지된다고 밝혔다. 개발자에게 눈에 띄는 기능은 **좌표 기반 배치**다. 0~1000 정규화 격자 위에 `{"id", "bbox": [y_min, x_min, y_max, x_max], "desc"}` 형태로 요소마다 위치와 설명을 지정할 수 있다. 참고 이미지는 최대 10장(`ref_image_0`~`ref_image_9`)까지 조합하고, 출력은 약 5,456×3,072 수준인 최대 16.8MP의 네이티브 4K다. 플레이그라운드와 API는 바로 열렸고 10월 8일까지 API 50% 할인이다. 기업용 가중치는 이미 라이선스로 제공되고, 오픈 웨이트(FLUX 3 Dev)는 "몇 주 안에" 나온다.
- **Ideogram 4.5 (9월 30일)**: 여러 번 이어서 편집하는 데 초점을 맞춘 편집 모델이다. 10회 이상 이어서 편집해도 인물과 손대지 않은 부분이 유지되고, 고해상도 이미지의 일부만 잘라 편집한 뒤 해상도를 줄이지 않고 원본에 다시 붙일 수 있다. API는 입력 크기 그대로 돌려주는 정밀 편집과 생성+편집 두 엔드포인트이고, 네이티브 2K 기준 장당 0.8~22센트다. fal·Krea·Runway·ComfyUI 등 파트너에도 들어갔다. 오픈 웨이트는 예고만 됐고 아직 공개되지 않았다.
