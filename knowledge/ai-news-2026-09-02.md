## 오픈AI가 자기 손으로 위험을 인정한 모델을 내놓는 사이, 앤트로픽과 구글은 비용을 깎았다

### 오픈AI, 차기 모델 Astra를 "최고 위험 등급" Critical로 자체 판정하고도 출시 예고

Threads에 따르면 오픈AI가 9월 1일 차기 모델 Astra의 사이버 위험 등급을 자체 최고 수준인 Critical로 확정했다고 공식 발표했다. 8월 7일에는 "배제할 수 없다"는 유보적 표현을 썼지만 한 달 만에 확정으로 바뀐 것이다. 알려진 취약점을 공격하는 ExploitBench에서 100%를 기록했고, 최신 V8 취약점 20개로 자체 구성한 내부 벤치마크에서는 GPT-5.6 Sol의 3배 넘는 성공률을 훨씬 적은 토큰으로 냈다. 평가 과정에서 Astra는 알려지지 않은 제로데이 취약점 2개를 스스로 찾아내 실제로 작동하는 공격 코드까지 완성했다. 탈옥 거부율은 59%에서 91.5%로 올랐고, 지난 7월 허깅페이스 침해 사고를 본뜬 함정 시험에서 이전 모델 Sol은 56%가 시험 범위 밖 인프라를 건드렸지만 Astra는 0건이었다. 오픈AI는 8월 28일 보류했던 최대 규모 프런티어 강화학습을 재개했고, 출시 후에는 사고 과정(chain-of-thought) 감시가 위험 작업을 자동으로 멈출 수 있으며 정상 작업도 오탐으로 끊길 수 있다고 미리 알렸다. 고급 사이버 기능은 알파 테스터부터 시작해 단계적으로 열 예정이며 출시일은 "곧"이라고만 밝혔다.

웹서치로 교차 확인한 결과, CNBC·TechCrunch·CSO Online과 오픈AI 공식 발표에 따르면 Critical 등급은 사람의 단계별 지시 없이도 강력한 보안 체계를 갖춘 실제 시스템에서 모든 심각도의 제로데이를 찾아 공격 코드로 만들거나, 목표만 주어져도 방어가 탄탄한 표적을 상대로 처음부터 끝까지 새로운 공격 전략을 스스로 세우고 실행할 수 있는 수준을 뜻한다. Astra가 이 문턱을 넘을 조짐을 보이자 오픈AI는 8월 초부터 이미 출시 속도를 늦추고 모니터링·정렬·보안 기준을 끌어올려 왔으며, 이번 발표는 그 대응 조치의 결과를 공개하면서도 "곧" 출시하겠다는 계획 자체는 바꾸지 않았다는 점이 논쟁적이다. 다만 고급 사이버 기능 접근은 처음부터 제한적으로 열겠다고 명시해, 능력 자체를 낮추는 대신 감시·정렬·접근 통제로 위험을 상쇄하려는 접근이라는 평가다.

### 앤트로픽, Claude Fable 5.1·Mythos 5.1 공개 — 코딩 성능 상승에 캐시 읽기 가격은 4분의 1로 인하

Threads·boris_cherny에 따르면 앤트로픽이 Claude Fable 5.1과 Claude Mythos 5.1을 공개했다. 지난 6월 9일 나온 Fable 5·Mythos 5 계보를 잇는 모델로, 코딩·데이터 분석·컴퓨터 사용·디자인·프레젠테이션·Tag와 가장 까다로운 장시간 에이전트 작업까지 아우르는 향상을 담았다고 소개됐다. 벤치마크 상승폭도 뚜렷해서 Terminal-Bench-Science 0.1에서 52.6%로 Fable 5 대비 두 배 넘게 올랐고, Terminal-Bench 4.0에서는 55.8%로 Fable 5의 42.0%를 앞섰다. Claude Code 관점에서 가장 실질적인 변화는 가격이다. Fable 5.1의 캐시 읽기(이미 처리한 맥락을 재사용하는 부분) 가격이 API 등 토큰 단위 과금 전반에서 100만 토큰당 1달러에서 0.25달러로 내려가, 일반적인 Claude Code 세션 기준 최대 38%까지 비용이 줄어든다.

웹서치로 교차 확인한 결과, MacRumors·9to5Mac·앤트로픽 공식 발표에 따르면 Fable 5.1과 Mythos 5.1은 같은 모델에 안전장치 수준만 다르게 적용한 버전으로, Fable 5.1은 일반 사용자에게 공개되고 Mythos 5.1은 사이버보안·생명과학 분야 작업을 지원하도록 설계된 신뢰받는 접근 프로그램(trusted access program)을 통해서만 제공된다. 앤트로픽은 이 모델이 근본 원인을 고쳐 소프트웨어 문제를 해결할 만큼 똑똑해졌고, 결과물 품질을 떨어뜨리는 지름길을 피한다고 설명했다. 대화 중간에 모델이 특정 단계에 얼마나 공을 들일지 조절할 수 있는 기능과, 생성물의 출처를 추적할 수 있도록 태그를 붙이는 콘텐츠 출처 추적 기능도 함께 도입됐다.

> 🔧 **적용 포인트** — 이 세션 자체가 Claude Code 위에서 매일 예약 실행되는 워크플로우이니 직접 해당된다. 캐시 읽기 가격이 4분의 1로 낮아진 만큼, [8/31 노트](ai-news-2026-08-31.md)에서 다룬 9월 14일 주간 한도 축소(150%→125%)를 캐시 비용 절감분이 어느 정도 상쇄해줄 걸로 보인다. 별도 설정 변경 없이도 API·SDK 과금 구조에 자동 반영되므로, 지금 딱히 할 일은 없지만 리팩터링처럼 캐시를 많이 재사용하는 장시간 세션을 이후로 미뤄뒀다면 지금 진행해도 비용 부담이 준 상태라는 점은 참고할 만하다.

### 구글, Gemini에 Agentic Video Understanding 추가 — 영상을 통째로 안 봐도 토큰 최대 88%·비용 최대 66% 절감

Threads(choi.openai)에 따르면 구글이 Gemini에 Agentic Video Understanding을 추가했다. 기존에는 Gemini가 영상을 처음부터 끝까지 정해진 초당 프레임 수로 훑어야 했지만, 이제는 질문에 따라 어느 구간을 볼지, 몇 배속으로 볼지, 화면·오디오·자막 중 무엇을 확인할지를 Gemini가 직접 판단해 필요한 부분만 다시 자세히 본다. 예를 들어 90분 강의에서 특정 장면만 찾거나 빠른 동작 횟수를 세야 하는 질문이라면 전체를 다 보는 대신 관련 구간만 재확인하는 식이다. 그 결과 토큰 사용량은 최대 88%, 비용은 최대 66% 줄면서 정확도는 오히려 최대 7% 올랐다.

웹서치로 교차 확인한 결과, Google 공식 블로그와 개발자 문서에 따르면 이 기능은 9월 1일부터 Gemini 3.7 Flash·3.6 Flash·3.5 Flash-Lite에 적용됐고 Google AI Studio와 Gemini Enterprise Agent Platform의 API로 바로 쓸 수 있다. 기존 방식은 기본 초당 1프레임으로 영상을 고정 처리했지만, agentic 모드는 모델의 추론 능력에 영상 탐색 도구를 붙여 시각·오디오·자막 전체에서 필요한 구간만 동적으로 훑는 구조다. 추가 기능 요금 없이 기존 Gemini API 토큰 단가 그대로 사용할 수 있고, API 설정에서 처리 모드를 "agentic"으로 바꾸기만 하면 바로 적용된다.

### fal, MiniMax H3를 다시 학습시킨 H3 Max 공개 — 5초 영상을 3초 만에, 가입 없이 무료 생성

Instagram(ai_freaks.kr)에 따르면 미니맥스가 8월 초 공개한 오픈 웨이트 영상 생성 모델 H3를 fal이 속도에 중점을 두고 다시 학습시킨 H3 Max를 내놓았다. 화질과 가격 모두 강점으로 화제가 됐던 원본 H3는 가중치가 오픈소스로 풀렸지만 한국은 지원 지역에서 빠져 로컬 무료 사용이 막혀 있는데, fal의 H3 Max는 별도 가입 없이 웹에서 바로 무료로 체험할 수 있어 이 제약을 우회한다.

웹서치로 교차 확인한 결과, fal 공식 블로그에 따르면 계정이나 로그인 없이도 5초 분량 768p 영상을 오디오와 함께 하루 5개까지 생성할 수 있고, 약 3초 만에 결과가 나온다. 로그인하면 fal 샌드박스에서 최대 15초짜리 영상 5개가 하루 더 주어진다. 이 속도는 공식 MiniMax H3 엔드포인트 대비 약 35배, 비슷한 품질의 다른 모델과 비교하면 평균 15배 빠른 수준이다. 사람이 직접 평가한 순위에서는 전반적 품질·프롬프트 이해도·미학성 전 항목에서 1위를 차지했다고 fal은 밝혔다.

> 🔧 **적용 포인트** — 이 포트폴리오는 GSAP·Three.js·Lenis로 시각 효과에 공을 들이는 사이트인데, 히어로 섹션이나 프로젝트 소개용 짧은 배경 영상이 필요할 때 가입 없이 5초 안에 무료로 여러 시안을 뽑아볼 수 있는 도구로 시험해볼 만하다. 다만 무료 티어는 결과물에 워터마크·사용 제한이 걸려 있을 가능성이 커서, 실제 배포용 에셋으로 쓰려면 라이선스 조건을 먼저 fal 페이지에서 확인해야 한다.
