### Claude Fable 5, 구독 포함 기한 7월 12일로 닷새 연장

지난 07-05 노트에서 다룬 대로 Claude Fable 5는 원래 7월 7일부터 구독 한도에서 빠지고 선불 크레딧(입력 $10/백만 토큰, 출력 $50/백만 토큰) 과금으로 전환될 예정이었다. 그런데 Anthropic이 이를 닷새 미뤄, Pro·Max·Team·일부 Enterprise 플랜 사용자는 7월 12일까지 주간 한도의 최대 50%까지 Fable 5(Mythos-class 모델)를 구독 안에서 계속 쓸 수 있게 됐다. Claude Code 리드 엔지니어는 용량이 회복되는 대로 Fable 5를 표준 구독 구성요소로 되돌리는 게 목표라고 밝혀, 이번 연장도 "일시 이탈은 임시 조치"라던 기존 설명과 같은 맥락임을 재확인했다.

> 🔧 **적용 포인트** — 포트폴리오에 넣을 만한 인터랙티브 3D 데모나 프로토타입을 Fable 5로 실험해볼 계획이 있다면, 크레딧 과금으로 완전히 전환되기 전인 7월 12일 이전에 시도해두는 편이 비용 면에서 유리하다.

### Cursor Composer 3 — SpaceX의 슈퍼컴퓨터에서 처음부터 학습한 1.5T 모델, 이번 주 출시

SpaceX가 6월 코딩 도구 Cursor(모회사 Anysphere)를 600억 달러에 인수하며 예고했던 첫 자체 개발 모델이 이르면 이번 주 수요일 공개된다. **Composer 3**는 1.5조 파라미터 규모로, Kimi 기반이던 이전 Composer와 달리 xAI의 Colossus 슈퍼컴퓨터 클러스터에서 처음부터(from scratch) 학습됐고 연산량도 전작 대비 10~20배다. 주요 벤치마크에서 Opus 4.8·GPT-5.5급을 노린다고 밝혔지만, 절반 크기인 753B 오픈웨이트 GLM-5.2가 이미 Terminal-Bench에서 Opus 4.8과 4점 차까지 따라붙은 상태라 기준선이 이미 높다. 에디터 안에서 실시간으로 돌려야 하는 모델 특성상, 벤치마크 점수보다 실제 추론 비용과 개발자들의 전환 여부가 성패를 가를 것이라는 전망이다.

### Meta, Superintelligence Labs의 두 번째 모델 Muse Image·Muse Video 공개

Meta Superintelligence Labs(Alexandr Wang 총괄)가 4월 언어모델 Muse Spark에 이은 두 번째 모델로 이미지 생성 모델 **Muse Image**를 공개하고 영상 모델 **Muse Video**를 프리뷰로 선보였다. Muse Image는 LMArena에서 GPT Image 2에 이어 2위로 데뷔했고(Muse Video는 3위), 프롬프트를 바로 이미지로 매핑하는 대신 웹 검색으로 사실을 확인하고 도표·QR코드처럼 정확도가 중요한 부분은 코드를 실행해 생성한 뒤 결과를 스스로 점검해 고치는 에이전트형 구조다. Meta는 이 자기수정 행동을 따로 설계하지 않았고, 강화학습 과정에서 다시 그린 이미지가 더 높은 보상을 받자 모델이 스스로 익힌 것이라고 밝혔다. 언어모델의 테스트 타임 컴퓨트(더 오래 생각할수록 품질이 오르는) 공식이 이미지 생성에도 적용된다는 의미로 해석된다. 별도 API 없이 Meta AI 앱·인스타그램 스토리(미국)·왓츠앱(일부 국가)에 바로 적용됐고 광고 도구 탑재도 예정돼 있다.

> 🔧 **적용 포인트** — 이 저장소에서 작업 중인 "2026 트렌드 디자인 프롬프트" 라이브러리(`src/data/designPrompts.ts`)는 지금 ChatGPT/Nano Banana 계열을 염두에 두고 있는데, Muse Image처럼 스스로 결과를 점검·재생성하는 에이전트형 이미지 모델이 늘고 있으므로 같은 프롬프트를 여러 모델에 돌려 결과를 비교하는 용도로 후보군에 넣어볼 만하다. 특히 도표·아이콘처럼 "정확도"가 중요한 스타일 프롬프트가 있다면 Muse Image의 코드 실행 기반 생성 방식이 더 잘 맞을 수 있다.

### DeepSeek, 엔비디아·화웨이 모두에서 벗어나려는 자체 추론칩 개발 착수

DeepSeek이 학습용이 아닌 **추론(inference) 전용 자체 칩** 개발에 나섰다. 현재 DeepSeek 추론은 화웨이 어센드(Ascend) 칩에서 돌아가는데, 알리바바·텐센트 등도 같은 칩에 몰리면서 화웨이 물량조차 올해 수요를 다 감당하지 못하는 상황이 배경이다. 추론 연산은 반복적이고 낮은 정밀도로도 동작 가능해 SMIC의 구형 공정으로도 전용 ASIC 설계가 가능하지만, 최첨단 공정·고급 인터커넥트·CUDA 생태계가 필요한 학습용 칩은 훨씬 어렵다(화웨이조차 엔비디아 대비 약 2년 뒤처진 것으로 평가). 다만 SMIC 생산 능력 자체가 장비 수출통제로 빠듯해(캄브리콘 최상위 칩 수율 약 20% 수준) 자체 칩 설계~양산까지 통상 3년이 걸리는 반면 칩 부족은 당장 이번 분기 문제라, 단기 해법이라기보다 추론 공급망을 국산으로 닫으려는 장기 포석으로 해석된다. DeepSeek은 이 프로젝트를 약 1년째 조용히 진행해 왔으며, 최근 처음으로 외부 자본(밸류에이션 520~590억 달러 규모 70억 달러 펀딩) 유치도 함께 추진 중이다.
