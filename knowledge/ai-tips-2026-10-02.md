## 모션그래픽도 이제 "코드로 짜 달라"고 시키는 작업이 됐다

### Opus 5.5 코드 모션그래픽 프롬프트 475개 저장소 — 애프터이펙트 없이 HTML·Canvas·GSAP·Three.js로 만든 바이럴 영상, 프롬프트째 가져다 쓰기

요즘 X에는 Claude Opus 5.5로 만든 모션그래픽 영상이 쏟아지고 있다. ai.trend.kr에 따르면 애프터이펙트 같은 영상 툴은 전혀 쓰지 않았고, 모델에게 애니메이션을 코드로 짜게 한 뒤 브라우저에서 재생되는 화면을 녹화한 영상들이다. 가장 반응이 좋았던 15초 영상은 조회수 207만 회를 넘겼다. 이력서용 쇼릴처럼 속도 곡선, 도형 변신, 3D 기법을 차례로 보여주다가 "모든 프레임을 코드로 썼다"는 문구로 끝나는 영상이다. 같은 프롬프트로 다른 사람이 만든 변형도 59만·51만 회를 찍었다. 버튼 하나가 로딩 바·음악 플레이어·그래프로 계속 바뀌는 인터랙션 영상도 프롬프트까지 함께 공개됐다.

이런 영상의 프롬프트를 모아 둔 곳이 GitHub 저장소 **yihui-dev/awesome-opus5-5-videos**(MIT)다. 9월 말 기준 475개가 모였고, 9월 29일에만 86개가 추가됐다. 구성은 다음과 같다.

- **분류**: 모션그래픽, 설명형 영상(explainer), 3D 장면, 게임·인터랙티브. 엄선한 100개는 README에 원작자 게시물 링크와 함께 정리돼 있다.
- **파일 구조**: `prompts/{작성자}-{ID}.md` 파일 하나에 프롬프트 하나를 담고, 전체 목록은 `data/videos.json`으로 묶었다.
- **쓰인 기술**: Canvas·HTML5, SVG + **GSAP**, **Three.js**, GLSL 셰이더·WebGL, CSS 애니메이션, Web Audio API, 물리 엔진.
- **사용법**: 파일의 Prompt 블록을 복사해 Claude Code나 앱에 붙이고, **HTML 파일 하나로 렌더링해 달라**고 요청한 뒤 필요하면 화면을 녹화한다. 일부 파일은 원작자가 프롬프트 전체가 아니라 설명만 공개했다는 표시가 붙어 있으니 걸러서 보면 된다.

핵심은 영상을 "렌더링 툴로 만드는 결과물"이 아니라 "코드로 짜는 결과물"로 다룬다는 점이다. 코드라서 수정·재사용·버전 관리가 되고, 같은 프롬프트로 여러 변형을 뽑아 고를 수도 있다. 프롬프트가 기술 이름(예: GSAP 타임라인, Three.js 장면, GLSL 셰이더)과 연출 순서를 구체적으로 지정할수록 결과가 안정적이라는 점은 공개된 예시들에서 공통으로 보인다.

> 🔧 **적용 포인트** — 이 저장소에서 쓰인 기술 스택(GSAP, Three.js, GLSL)이 이 포트폴리오와 거의 같다. 두 가지 방법으로 바로 써먹을 수 있다. 첫째, 포트폴리오 소개용 15초 쇼릴을 만들 때 마음에 드는 모션그래픽 프롬프트를 가져와 "HTML 파일 하나로" 뽑은 뒤, 프로젝트 이름·색상 토큰만 바꿔 화면 녹화하면 된다. 둘째, 3D 장면·셰이더 프롬프트를 히어로 섹션이나 프로젝트 카드 전환 연출의 **프로토타입 생성기**로 쓰는 방법이다. 단일 HTML로 먼저 빠르게 뽑아 보고, 마음에 드는 것만 R3F 컴포넌트와 GSAP 타임라인으로 옮기는 2단계로 가면 본 코드베이스를 어지럽히지 않는다.
