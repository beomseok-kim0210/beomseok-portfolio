## 클로드 코드가 대화 하나를 병렬 에이전트 팀으로 바꾸고, 알리바바는 옴니모달 모델을 헐값에 푼 하루

### 앤트로픽, "Claude Code Projects" 정식 출시 — 대화 하나가 병렬 에이전트 스레드로 갈라진다

Threads(testingcatalog, boris_cherny, choi.openai)에 따르면 앤트로픽이 Claude Code의 새 Projects 경험을 정식 발표하고 일부 Pro·Max 사용자를 대상으로 대기자 명단 기반 베타를 시작했다. 사용자가 대화창에서 "무엇을 해야 하는지"만 설명하면 클로드가 요청 범위를 스스로 나눠 필요한 만큼의 스레드를 만들고, 각 스레드는 별도의 클라우드 세션으로 병렬 실행되면서 프로젝트 단위의 공유 메모리와 파일·아티팩트 라이브러리를 함께 참조한다. 보리스 체르니는 "요즘 코드 대부분을 이 방식으로 짠다"며 직접 써온 소감을 전했고, 공식 발표는 "노트북을 닫아도 스레드는 계속 작동한다"고 밝혔다. 웹서치로 확인한 VentureBeat·MarkTechPost 보도에 따르면, 실제 활용 예로는 "체크아웃 API의 p75 지연 시간을 줄여라"는 목표를 주면 클로드가 각 엔드포인트를 프로파일링하고 최적화를 테스트한 뒤 풀 리퀘스트까지 병렬 스레드로 여는 시나리오, 또는 API·웹·모바일 리포지토리를 연결해 "지원 종료된 v1 엔드포인트를 없애라"고 하면 리포지토리별로 스레드를 만들어 호출부를 마이그레이션하고 테스트·PR까지 진행하는 시나리오가 소개됐다. 전체 결과 조립·검토도 클로드가 맡으며, 진행 상황을 보여주는 새 개요 패널이 함께 제공된다. 현재는 Claude Code 클라우드 세션을 쓰는 일부 Pro·Max 사용자부터 열리고, 이후 1주 안에 더 넓은 Pro·Max 사용자로 확대될 예정이다.

> 🔧 **적용 포인트** — 이 포트폴리오도 Claude Code로 개발되고 있는 만큼, Projects가 계정에 열리면 "도슨트 RAG 파이프라인 리팩터링"이나 "Three.js 씬 여러 개 동시 튜닝" 같은 서로 독립적인 작업을 한 번에 병렬 스레드로 맡기고 노트북을 덮어도 계속 진행시키는 방식을 시도해볼 만하다. 다만 대기자 명단 베타 단계이므로, 우선 계정에 기능이 뜨는지 확인하는 것부터 시작하면 된다.

### 알리바바, 텍스트·이미지·음성·영상 옴니모달 "Qwen3.8-Omni-Flash" 공개 — 제미나이 3.8 Flash보다 5~8배 저렴

Threads(choi.openai)에 따르면 알리바바 Qwen팀이 텍스트·이미지·음성·영상을 한 번에 입력받아 최대 100만 토큰 컨텍스트로 처리하는 옴니모달 모델 Qwen3.8-Omni-Flash를 공개했다. choi.openai가 함께 소개한 지난 3월 발표 내용을 보면, 전작 Qwen3.5-Omni가 화면을 보며 음성으로 코딩을 지시받는 수준이었다면, 이번 모델은 영상에서 필요한 장면을 찾고 도구를 호출한 뒤 만든 결과물을 다시 검토하는 긴 에이전틱 작업까지 활용 범위를 넓혔다. 공식 발표에는 회의 후속 작업 자동화, 영상 편집·번역, 학습 자료 제작 같은 실제 데모가 포함됐고 API로 제공된다. 가격은 싱가포르 국제 리전 기준 텍스트 100만 토큰당 입력 0.15달러·출력 0.47달러로, 같은 시기 나온 Gemini 3.8 Flash의 출시 프로모션 단가(0.75달러·3.75달러) 대비 각각 5분의 1, 약 8분의 1 수준이다. 시간당 입력 비용도 음성만 처리할 때 0.01달러 미만, 음성이 포함된 영상은 0.20달러로 전작 Omni-Plus 대비 각각 98%·93% 이상 줄었다고 회사는 밝혔다. 성능은 과제 성격에 따라 갈렸다. 회사가 공개한 29개 평가 평균은 전작 대비 25% 넘게 개선됐고, 이미지·음성·영상이 섞인 도구 사용 과제를 Claude Code에서 실행하는 WildClawBench-MM에서는 Qwen이 71.0점으로 Gemini 3.8 Flash(58.9점)를 앞섰지만, 별도 에이전트 환경 없이 웹 검색만 평가하는 OmniGAIA(74.0 대 78.6)와 Claude Code에서 영상 작업을 평가하는 AgenticVBench(36.8 대 45.0)에서는 Gemini가 앞섰다. 웹서치로 확인한 알리바바 클라우드 공식 블로그·더뉴스택 보도에 따르면 이 모델은 지난 8월 공개된 차세대 Qwen4 아키텍처 프리뷰 "Qwen3.8-Flash-Next"(1,250억 파라미터 중 토큰당 60억만 활성화하는 MoE, 입력 0.15달러·출력 0.47달러로 동일한 가격 체계)의 옴니모달 확장판으로, 6억 파라미터 활성화만으로 3배 큰 자사 상위 모델을 대부분의 벤치마크에서 앞섰던 구조를 텍스트·이미지·음성·영상 입력까지 그대로 확장한 결과다.

> 🔧 **적용 포인트** — 메모리에 남아있는 도슨트 프로젝트의 음성 RAG 파이프라인처럼 음성·영상 입력을 다루는 기능이 있다면, Qwen3.8-Omni-Flash의 시간당 음성 처리 비용(0.01달러 미만)은 현재 쓰고 있을 TTS/STT·LLM 조합 대비 비용 구조를 비교해볼 만한 대안이다. 다만 API가 중국 리전 중심으로 제공되고 국내 접근성·지연시간·데이터 정책이 검증되지 않았으니, 실제 전환보다는 비용 벤치마크 참고용으로만 우선 봐두는 편이 안전하다.
