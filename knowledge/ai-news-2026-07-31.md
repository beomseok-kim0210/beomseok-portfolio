## 오픈 웨이트 vs 프론티어 가격 인하 — 딥시크 V4-Flash MIT 공개와 오픈AI의 응수

### 딥시크, V4-Flash-0731 가중치를 MIT 라이선스로 전면 공개 — Opus급 코딩 에이전트가 사실상 무료로

딥시크가 7월 31일 V4-Flash의 정식판 가중치 "V4-Flash-0731"을 기술 보고서와 함께 공개했다. 4월에 낸 프리뷰를 공식 대체하는 버전으로, MIT 라이선스를 적용해 상업적 이용·수정·재배포까지 사실상 제한 없이 허용한다. 구조와 크기(총 284B, 토큰당 13B만 활성화)는 4월 프리뷰와 동일하고 바뀐 것은 학습 후반 공정뿐인데도, 코딩 에이전트 평가 DeepSWE가 7.3점에서 54.4점으로, 터미널 작업 평가가 61.8점에서 82.7점으로 뛰어 활성 파라미터 49B를 쓰는 자사 상위 모델 V4-Pro(프리뷰)를 전 항목에서 앞질렀다. 독립 평가기관 Artificial Analysis 집계 지능 지수는 50점으로 구글 Gemini 3.6 Flash와 동급이지만, 출력 단가는 100만 토큰당 0.28달러로 구글(7.50달러)의 27분의 1 수준이다. 체크포인트에는 투기적 디코딩 모듈 "DSpark"가 기본 포함돼, 딥시크 서빙 환경 기준 사용자당 생성 속도가 60~85% 빨라졌다.

공개 몇 시간 만에 Unsloth가 4비트 무손실 GGUF 양자화판을 내놨다(램 168GB로 무손실 4비트, 110GB로 3비트 구동 가능) — 딥시크가 학습 단계부터 양자화를 반영하는 QAT로 훈련해 전문가 파라미터의 96%가 원래부터 FP4였기 때문에, 원본과 토큰 일치율 100%를 유지한 채 그대로 옮겨 담을 수 있었다고 밝혔다. 공개 하루 만에 나온 외부 검증(써드파티 보안 평가)에서도 실제 취약점 32개 중 24개를 찾아내 GPT-5.6 Sol과는 1개, Claude Opus 5와는 2개 차이까지 따라붙었다. 다만 이미지 입력은 아직 지원하지 않고 물리 추론·초장문 문맥에서는 일부 오픈 모델에 뒤진다는 평가도 함께 나왔다 — 후반 학습 자원을 실행형 에이전트 성능에 집중적으로 투입한 결과로 풀이된다. 웹서치로 확인한 MarkTechPost·officechai·digitalapplied 보도도 이 벤치마크 수치와 MIT 라이선스 사실을 동일하게 확인해준다. 배경에는 딥시크가 내몽골 울란차부에 1GW급 데이터센터를 준비 중이라는 블룸버그 보도가 있다 — 모델은 무료로 풀되 그 모델을 만들어내는 학습 인프라(수십만 개 규모 샌드박스 클러스터, 자체 GPU 커널)에 계속 투자해 "경쟁력은 모델이 아니라 학습 공장에 있다"는 창업자 량원펑의 5월 유출 발언과 같은 기조로 해석된다.

> 🔧 **적용 포인트** — [docent-project](docent-project.md)의 남은 작업 중 하나가 "Anthropic API 키 구매 시 Vercel env 추가"인데, 지금처럼 오픈 웨이트 모델 가격이 초저가로 내려간 상황에서는 라이브 챗 모드(`DOCENT_MODEL` env로 교체 가능)의 대안 후보로 DeepSeek V4-Flash API(현재 공개 베타, 출력 100만 토큰당 0.28달러)도 검토해볼 만하다. MIT 라이선스라 약관 부담도 적고, Claude 예산이 부담스러울 때 저비용 세컨더리 라이브 모드로 붙이는 선택지가 될 수 있다.

### 오픈AI, GPT-5.6 전 라인업 API 가격 인하 — Luna 80%↓, Terra 20%↓

오픈AI가 7월 30일, 출시 3주 만에 GPT-5.6 전 라인업의 API 가격을 낮췄다. 가장 저렴한 모델 Luna는 100만 토큰당 입력 0.20달러·출력 1.20달러(캐시 입력 0.02달러)로 80% 인하됐고, 중간급 Terra는 입력 2달러·출력 12달러로 20% 인하됐다. 최상위 Sol 가격은 그대로지만 최대 2.5배 빠른 "Fast Mode"(가격 2배)가 새로 추가됐다. Threads 스레드에 따르면 이 인하는 오픈AI가 Sol을 자기 서빙 최적화(프로덕션 GPU 커널 개선, 추측 디코딩 효율화)에 투입해 절감한 운영비를 그대로 API 가격에 반영한 결과다. 웹서치로 확인한 CNBC·VentureBeat 보도에 따르면 이번 인하는 GPT-5.6 패밀리가 7월 9일 출시된 지 3주 만에 나온 것으로, 프론티어 랩의 가격 결정력이 글로벌 경쟁(특히 중국발 오픈 웨이트 모델) 앞에서 빠르게 약해지고 있다는 신호로 해석됐다.

같은 날 이 소식을 다룬 ai_freaks.kr(Instagram)은 "1년 전 최고급 모델이 하던 일을 예전 값의 6% 수준으로 처리"한다는 프레이밍으로 소개하며, 구독제로만 쓰는 사용자도 사용량 계산에 인하가 반영돼 이득이라는 점을 짚었다. Threads 스레드는 이 가격 인하를 같은 날 공개된 딥시크 V4-Flash(출력 0.28달러)와 나란히 놓고, "기본값이 되는 모델의 가격 경쟁이 심화되며 토큰 가격은 앞으로도 내려갈 가능성이 크다"고 정리했다 — 실제로 Luna의 새 가격(1.20달러)도 딥시크보다는 4배 넘게 비싸다.

> 🔧 **적용 포인트** — 프론티어 API 가격이 몇 주 단위로 크게 움직이는 만큼, [docent-project](docent-project.md)에서 아직 미정인 프로덕션 라이브 모드 비용 계획을 세울 때 `claude-haiku-4-5` 단일 후보로 고정하기보다, GPT-5.6 Luna·DeepSeek V4-Flash처럼 급락한 저가 모델들과 주기적으로 비용/응답 품질을 비교해보는 편이 좋다. 특히 도슨트처럼 짧은 Q&A 위주 응답에는 최상위 모델이 굳이 필요 없을 수 있어, 저가 모델 스왑이 실질적인 운영비 절감으로 이어질 여지가 크다.
