## 비싼 모델은 지휘에, 싼 모델은 대량 처리에 — 사람이 직접 할 일은 계정과 비용이 걸린 세 가지뿐이었다

### 카파시의 HackerTube 2시간 제작기 — 대량 텍스트는 Workflow로 Sonnet에 맡기고, 서버 IP와 '배포·보안·최적화' 같은 큰 목표만 주며, 사람은 API 키·서버·도메인만 직접 만든다

choi.openai가 소개했고, 카파시의 블로그 원문으로 확인했다. 개인 제작기라 언론 교차 확인은 생략했다.

**무엇을 만들었나**: [hackertube.org](https://hackertube.org)는 Hacker News 댓글에서 사람들이 추천한 유튜브 영상만 모아 보여 주는 사이트다. 2007~2026년에 추천된 영상 6,454개를 150개 주제로 나눴다. 썸네일은 업로더가 올린 자극적인 이미지 대신 영상 중간 장면을 쓴다. 로그인 없이 브라우저 세션 안에서 개인화 추천('ForYou')을 하고, 키보드 단축키와 데이터 내보내기를 지원한다. 유튜브 추천에 질린 어느 금요일 밤에 약 2시간 만에 만들었다고 한다.

**어떻게 만들었나**
1. **도구 구성**: Mac용 Claude Code 데스크톱 앱. 기본 모델은 Opus 5.5(effort Medium), 대량 처리는 Sonnet이 맡았다.
2. **데이터 파이프라인**: Hugging Face 데이터셋에서 HN 댓글 전체(약 4,300만 개)를 받는다 → 걸러낸 뒤 Claude Code의 Workflow로 Sonnet을 돌린다 → 스팸을 빼고 유튜브 영상을 추천하는 댓글 약 4만 개로 줄인다 → 영상 메타데이터를 붙인다.
3. **배포**: 데이터를 유튜브 같은 UI로 감싸고 VPS에 올렸다. 업데이트·배포·보안 강화·최적화는 Claude가 했다.
4. **사람이 직접 한 일**: Google Cloud에서 YouTube Data API 키 만들기, VPS 띄우기, 도메인 사기. 계정·결제가 걸린 일만 남긴 셈이다.

**원문에서 건질 운영 방식**
- 카파시는 이제 코드를 직접 쓰거나 터미널 명령을 치거나 파일을 고치지 않고, 평범한 말로 지시만 한다고 했다.
- 에이전트에게는 서버 IP 같은 **구체적인 입력**과 "업데이트하고, 배포하고, 보안을 강화하고, 최적화해" 같은 **큰 목표**를 함께 준다.
- 대량 텍스트 처리는 Workflow로 묶어 **싼 모델**에 맡긴다. 4,300만 개를 Opus로 돌리지 않은 것이 비용 면에서 핵심이다.
- 에이전트가 작업하는 사이에 사람도 다른 부분을 진행한다. 카파시는 이게 팀으로 일하는 느낌이라고 했다.
- 데이터를 에이전트가 쓰기 좋은 형태로 내보내 두면, 다른 사람이 자기 버전을 다시 만들 수 있다.

choi.openai는 여기서 "AI가 콘텐츠를 무한히 만드는 시대에는 정보보다 신뢰와 큐레이션이 중요해진다"는 해석을 붙였다. 이 사이트 자체도 새 콘텐츠를 만들지 않고, 20년치 사람의 추천을 다시 엮은 결과물이다.

> 🔧 **적용 포인트** — 포트폴리오의 knowledge/ 노트가 쌓이면서 태그 정리나 요약 재작성 같은 일괄 작업이 필요해질 수 있다. 이런 작업은 Claude Code Workflow로 묶어 Sonnet이나 Haiku에 맡기고, 메인 세션(Opus)은 결과 검토와 UI 반영에만 쓰면 비용이 크게 준다. 배포를 맡길 때도 카파시처럼 '무엇을(대상·입력)'과 '어디까지(목표)'를 한 번에 주되, Vercel 토큰·도메인처럼 계정이 걸린 설정은 직접 처리하는 경계를 지킨다.
