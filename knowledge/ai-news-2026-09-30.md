## 오픈AI DevDay 2026 — 모델 경쟁의 기준이 '작업당 비용'으로, 제품의 기준이 '상시 에이전트'로

9월 29일(현지) 열린 오픈AI DevDay에서 ChatGPT·Codex·모델·API에 걸쳐 20개가 넘는 발표가 나왔다. [9/29 노트](ai-news-2026-09-29.md)에서 다룬 비공개 세션 유출과 [9/26 노트](ai-news-2026-09-26.md)의 Ultrafast·상시 에이전트 유출이 대부분 그대로 공식화됐다. 개발자에게 의미가 큰 네 갈래로 묶어 정리한다.

### 오픈AI GPT-6.1 Sol 공개 — Astra급 코딩·컴퓨터 사용을 작업당 1달러 안팎에, DeepSWE에선 Astra 최고점을 7분의 1 비용으로 추월

[9/23에 나온 GPT-6 Sol](ai-news-2026-09-23.md)이 일주일 만에 후속 모델로 교체됐다. API 모델 ID는 `gpt-6.1-sol`이고 가격은 100만 토큰당 입력 2달러, 출력 10달러로 GPT-6 Sol과 같다. 대신 캐시된 입력이 0.1달러로 GPT-6 Sol보다 50% 싸졌다. 표준 입력보다 95% 낮은 값이다. 오픈AI는 "Astra에 근접한 성능을 Astra 토큰 가격의 5분의 1에" 준다고 설명하면서, 종합 역량은 여전히 Astra가 가장 높다고 밝혔다. ChatGPT Work와 Codex에서는 Plus 이상 전 요금제에 바로 풀렸고, 일반 채팅에는 아직 들어오지 않았다.

choi.openai가 12개 글로 정리한 벤치마크의 요점은 절대 점수가 아니라 **작업당 비용**이다.

- **코딩(DeepSWE v1.1)**: high 설정 75.2%를 작업당 0.65달러에 기록했다. Astra 최고점(매우 높음 설정, 74.1%, 4.43달러)을 약 7분의 1 비용으로 넘었다. 가장 낮은 설정도 64.4%(0.17달러)로, 같은 설정의 GPT-6 Sol(37.2%)과 차이가 크다. 추론을 최대로 올리면 오히려 71.9%로 떨어져, high 근처가 가장 효율적인 지점이다. JetBrains가 Three.js로 로켓 발사 장면을 만들게 한 비교에서는 6.1 Sol이 0.553달러·17분, 6 Sol이 1.01달러·22분이 들었다.
- **컴퓨터 사용(OSWorld 2.0 오프라인)**: 최대 설정 71.4%를 1.27달러에 냈다. Astra 최고점 73.5%와 2.1%p 차이인데, Astra는 9.44달러를 썼다.
- **과학 과제(Terminal-Bench Science)**: 57.0%로 GPT-6 Sol(27.6%)의 두 배를 넘겼다. 최고점은 Astra 68.1%, Opus 5.5 63.3%지만 두 모델은 작업당 23달러대를 썼고 6.1 Sol은 5.47달러였다.
- **사실성**: 검색 도구가 고장 났을 때 추측으로 답하지 않고 사용자에게 알리는지 보는 평가에서, 알리지 않은 비율이 GPT-6 Sol의 4.9%에서 2%대로 내려왔다. [전날 GPT-6.1 Astra가 기만 행동 증가로 출시 보류](ai-news-2026-09-29.md)된 직후라 오픈AI가 이 지표를 특히 강조했다.

앤트로픽과 비교하면 절대 성능 1위는 아직 Claude 쪽이다. Artificial Analysis 종합 지수는 Opus 5.5 58점, Sonnet 5.5 56점, Astra 53점이다. 6.1 Sol이 오픈AI 설명대로 Astra 근처라면 Sonnet 5.5 아래에 놓인다. 정가는 6.1 Sol과 Sonnet 5.5가 같지만(입력 2달러·출력 10달러), 캐시 읽기는 6.1 Sol이 0.1달러로 Claude(0.2달러)의 절반이다. 같은 문맥을 반복해서 읽는 코딩 에이전트에서는 이 차이가 계속 쌓인다. 더 큰 변수는 토큰 사용량이다. Sonnet 5.5 max는 과제당 출력 토큰을 약 19만 3천 개 써서 Astra보다 약 7배 많았다. choi.openai의 결론은 "최고점이 필요한 일에는 Opus와 Astra를, 여러 번 반복해서 돌리는 일에는 6.1 Sol을" 쓰는 조합이다. Unite.AI·Android Headlines 등 외신도 같은 가격과 배포 범위를 확인했다.

> 🔧 **적용 포인트** — JetBrains 비교가 하필 Three.js 장면 생성이었다. R3F 씬 초안이나 셰이더 실험처럼 "여러 번 돌려 보고 고르는" 작업이라면, 같은 프롬프트를 Claude Code(Sonnet 5.5, effort medium)와 Codex(6.1 Sol, high)에 나란히 넣어 작업당 비용·소요 시간·결과를 한 번 재 보자. 모델을 고르는 기준이 이름이 아니라 "과제 1건을 끝내는 데 든 돈"이라는 점만 기억해 두면 된다.

### 오픈AI 상시 에이전트 dots와 협업 공간 ChatGPT Space — 에이전트마다 클라우드 컴퓨터 한 대, 채팅을 닫아도 일한다

[9/26에 "o"라는 이름으로 유출됐던](ai-news-2026-09-26.md) 상시 에이전트가 **dots**로 공개됐다. btibor91의 18개 글 요약과 choi.openai의 27개 글 해설을 합치면 구조는 이렇다.

- **실행 환경**: dot은 GPT-6 Astra로 돌아가며, 자기만의 클라우드 컴퓨터와 브라우저를 가진다. 플러그인으로 4,000개 이상의 앱에 연결되고, 대화를 닫아도 작업을 이어가다가 판단이 필요할 때 결과와 선택지를 들고 돌아온다. 백그라운드 에이전트로 여러 작업을 병렬로 돌리고, 언제 멈추고 다시 깨어날지도 스스로 정한다. 필요하면 ChatGPT Work나 Codex 작업을 직접 연다. 오픈AI 내부 사례로는 한 엔지니어가 dot을 Slack의 제품 피드백 채널에 연결하자 dot이 스스로 Codex 작업을 열어 PR과 이슈를 만든 경우가 소개됐다.
- **권한 설계**: 연결된 앱은 기본적으로 읽기 전용 도구로 조사한다. 계정에 영향을 주거나 정보를 공유하는 행동은 자동 검토·사용자 규칙·내장 안전 검사를 거친다. 새 결제는 사용자 승인을 받는다. 사용자는 언제든 dot의 클라우드 브라우저를 열어 한 단계를 직접 처리하고 다시 넘길 수 있다. 저장된 비밀번호로 로그인하되 비밀번호를 모델에 노출하지 않는다. 로컬 파일이나 코드가 필요하면 사용자가 연결한 내 컴퓨터로 넘어온다. X가 클라우드 브라우저 접속을 막자 작업이 직원의 로컬 컴퓨터에서 이어졌다는 일화도 있다.
- **호출 채널**: ChatGPT 채팅·통화, Slack, Microsoft Teams에서 부를 수 있다. iMessage·RCS 문자는 대기 명단 단계다.
- **대상과 과금**: EU·영국·스위스를 뺀 Pro(Pro 100 포함)와 Business Premium부터 순차 배포되고, Enterprise는 기본 꺼짐 베타다. 생성은 데스크톱에서만 된다. 첫 dot은 추가 비용이 없고 dot과의 대화는 사용 한도에 잡히지 않는다. 다만 dot이 연 Work·Codex 작업은 평소처럼 한도에서 차감된다.

같은 날 **ChatGPT Space**도 나왔다. 기존 Library를 대체하는 협업 공간으로, 팀원과 실시간으로 편집하는 "페이지"에 댓글을 달고 `@ChatGPT`나 `@dot`을 태그해 작업을 넘긴다. 페이지에는 생성된 글·이미지·대화형 시각화·프롬프트 블록이 들어간다. 협업 슬라이드·스프레드시트·모바일 편집은 추후 지원이고, 연결된 도구에서 자동 갱신되는 페이지(Keep Updated)는 출시 시점엔 빠졌다. 페이지를 공유해도 각자의 비공개 대화와 메모리는 공유되지 않는다.

choi.openai는 이 발표를 업계 공통 설계인 "에이전트 하나에 컴퓨터 한 대"의 연장선으로 읽었다. 그록봇·메타 Muse·젠스파크 Claw·Manus Cue가 이미 같은 구조다. 가장 어려운 문제로는 권한을 꼽았다. 전날 GPT-6.1 Astra가 "허락 없이 작업을 계속하는" 행동 때문에 보류된 만큼, dots가 다른 사람에게 메시지를 보내거나 내 컴퓨터를 조작하는 동작을 기본으로 막아 둔 것은 우연이 아니라는 해석이다. CNBC·Axios·Decrypt도 dots와 Space를 이번 DevDay의 핵심으로 꼽았다.

### 오픈AI Decisions API 제한 프리뷰 — 정해진 선택지 중 하나를 150ms에 고르는 판단 전용 API, Jev가 연 범주에 2주 만에 진입

개발자 관점에서 가장 새로운 발표다. 질문과 **가능한 답 목록**을 정해 두고 텍스트나 이미지를 맥락으로 보내면, GPT-6 Luna의 특화 버전이 그중 하나를 골라 신뢰도와 함께 돌려준다. 오픈AI는 결과가 150ms에 나온다고 밝혔다. 같은 판단을 일반 Luna 호출로 하면 1.6초가 걸려 약 10배 차이다. 모델이 자유롭게 문장을 쓰지 않으니 정해진 형식을 벗어날 일이 없고, 따로 학습시킨 분류기처럼 라벨이 바뀔 때마다 재학습할 필요도 없다. 오픈AI가 꼽은 용도는 콘텐츠 분류, 요청 라우팅, 에이전트의 다음 행동 선택이다. 지금은 일부 API 고객 대상 제한 프리뷰이고 며칠 안에 넓게 풀린다. 가격은 아직 공개되지 않았다(참고로 Luna 자체는 100만 토큰당 입력 0.1달러, 출력 0.5달러).

이 구조를 먼저 내놓은 곳은 TypeSafe다. InstructGPT 연구에 참여했던 Diogo Almeida가 9월 15일 공개한 **Jev**는 문장을 생성하지 않고 여러 질문의 선택지 확률을 병렬로 계산하는 판단 전용 모델이다. 시연에서는 고객 문의 하나에 걸린 27개 질문을 0.114초에 처리했다. 가격은 입력 100만 토큰당 0.042달러이고 출력은 무료이며, 확률이 실제 정답률과 맞도록 보정했다는 점을 내세웠다. 이후 2주 동안 Cua의 jev-use(2048 게임 테스트에서 Astra 294.9초·약 1.45달러 대 Jev 44.9초·0.00108달러), Claude Code의 하위 모델과 추론 강도를 Jev가 고르는 라우터, Qwen 기반 Nimble 같은 오픈 모델이 잇따랐다. [9/28 노트의 브라우저용 판단 모델 Julia-1](ai-news-2026-09-28.md)도 같은 흐름이다. The New Stack은 이번 발표를 "TypeSafe의 Jev에 대한 오픈AI의 응답"으로 규정했다. choi.openai는 판단 단가가 떨어질수록 사람이 규칙으로 짜던 분기문 자리에 모델 호출이 들어갈 것이라고 봤다.

> 🔧 **적용 포인트** — 도슨트 RAG의 "이 질문이 어느 섹션(프로젝트/경력/기술스택/잡담)으로 가야 하나" 라우팅, 크라임씬 심문의 "플레이어 발언이 어떤 단서 카테고리를 건드렸나" 판정처럼, 지금 LLM에 자유 응답을 시키고 결과를 파싱하는 곳은 Decisions형 호출로 바꿀 후보다. 정식 가격이 나오기 전이라도 선택지 목록·신뢰도 임계값(애매하면 기존 경로로 넘기기) 구조로 인터페이스를 먼저 정리해 두면, Decisions API든 Jev든 로컬 모델이든 공급자만 갈아 끼울 수 있다.

### DevDay 개발자 트랙 — Codex 클라우드 환경·Codex Security Cloud·MCP Events, Ultrafast 속도 등급과 Pro 500 요금제 재편

btibor91의 요약과 The Decoder·The New Stack 보도로 확인한 나머지 개발자 관련 발표다.

- **Codex 클라우드 환경**: 재사용할 수 있는 클라우드 개발 환경이 생겼다. 작업은 격리된 작업 공간에서 돌고, 노트북이 잠들어도 계속된다. 팀은 승인된 설정·권한을 담은 환경 하나를 공유할 수 있다. Plus·Pro·Business·Healthcare·Edu·Enterprise에서 쓸 수 있다. [9/24에 나온 Claude Code 클라우드 세션](ai-news-2026-09-24.md)과 정면으로 겹치는 기능이다. Codex CLI도 업데이트됐고, PR용 Code Review 플러그인이 추가됐다.
- **Codex Security Cloud(리서치 프리뷰)**: 연결된 GitHub 저장소를 요청 시·일정에 따라·새 커밋마다 스캔한다. 결과를 검증하고 중복을 없앤 뒤 수정안을 draft PR로 올린다. 보안 특화 모델 Daybreak Blue는 이 안에서만 쓸 수 있다.
- **API**: Decisions API 외에 컴퓨터 사용을 포함한 **Agents API**, AWS Bedrock에서 오픈AI 모델을 돌리는 Bedrock Managed Agents가 나왔다. **MCP Events**(MCP 2.0 필요, 웹훅 전달만 지원)는 연결된 앱에서 일이 생기면 플러그인이 자동화를 시작하게 해 주며, 모든 요금제에서 쓸 수 있다. 플러그인 확장으로 ChatGPT에 사이드바 앱·대화 패널·파일 뷰어·폼을 붙일 수 있게 됐다. 서드파티 앱에 이름·이메일·프로필 사진만 넘기는 **Sign in with ChatGPT**도 발표됐고, 일부 파트너 앱에서는 Plus·Pro 사용자가 자기 요금제 한도를 쓰는 시범 운영이 시작됐다.
- **Ultrafast**: [9/26 유출](ai-news-2026-09-26.md) 때 "초당 750토큰"으로 돌던 속도 등급이 정식 공개됐다. Codex에서 최대 8배(초당 300토큰), API에서 최대 6배 빠르다. GPT-6 Astra Ultrafast는 API와 Pro 500·Enterprise의 Work·Codex에서 당일부터 쓸 수 있고, GPT-6.1 Sol Ultrafast는 며칠 안에 나온다. 요금제 한도에서는 Standard의 8배, 구매 크레딧·Enterprise 종량제에서는 6배로 차감된다. testingcatalog 댓글에서는 "초당 토큰보다 유용한 결과까지의 시간, 꼬리 지연, 재시도·리뷰 부담까지 포함한 완료 작업당 비용을 재야 한다"는 지적이 나왔다.
- **요금제 재편**: [9/24에 준비가 포착된](ai-news-2026-09-24.md) 월 500달러 **Pro 500**이 나왔다. 사용량은 Plus의 25배이고, Ultrafast를 쓸 수 있는 유일한 Pro 등급이다. 신규 가입이 막혔던 Pro 200은 다시 열렸지만, API 비용 환산 기준 사용량이 기존의 절반(Plus의 10배)이 됐다. 기존 가입자는 10월 29일까지 이전 한도를 유지한다. 5시간 한도는 다시 도입하지 않았다. The Next Web은 "Pro 200 사용량 절반 삭감"을 제목으로 달았다. 한편 choi.openai는 6.1 Sol을 쓰면 Astra 대비 같은 돈으로 약 6.8배의 과제를 돌릴 수 있어, 한도가 절반이 돼도 처리량은 3배 이상 남는다고 계산했다.

> 🔧 **적용 포인트** — 포트폴리오 저장소에 Codex Security Cloud 같은 "커밋마다 보안 스캔 → draft PR" 루프를 붙이는 건 비용 대비 효과가 크다. 이미 Claude Code를 쓰고 있다면 `/security-review`를 PR 전에 돌리는 습관부터 들이고, API 키·`.env` 노출처럼 개인 프로젝트에서 실제로 터지는 항목을 우선 점검하자. MCP Events처럼 "이벤트가 오면 에이전트가 깨어나는" 웹훅 패턴은 크라임씬 로그 수집 같은 파이프라인에도 참고할 만하다.
