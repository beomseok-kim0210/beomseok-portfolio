## 공개 AI 해킹 도구로 은행이 뚫렸고, 같은 주 Claude는 영상과 API 크레딧을 풀었다

국내 은행 여러 곳을 털어간 공격자가 쓴 건 누구나 받을 수 있는 오픈소스 침투 도구와 오픈웨이트 모델이었다. 증거는 공격자가 자기 서버에 남긴 Claude Code 작업 기록에서 나왔다. 같은 주 앤트로픽은 코드로 짜는 모션그래픽 도구와 구독자용 월간 API 크레딧을 내놨다.

### 국내 은행 연쇄 침해에 쓰인 AI 해킹 스택 — 크라우드스트라이크, 공개 도구 ARTEX·DeepSeek V4.1-Flash·Claude Code 흔적을 노출된 서버에서 찾았다

choi.openai가 크라우드스트라이크의 10월 7일(현지) 보고서를 정리했다. 9월 말부터 10월 초까지 국내 금융사 여러 곳이 한 공격자에게 연달아 뚫렸고, 그 공격자는 자기 서버조차 제대로 관리하지 못한 미숙한 해커였다는 게 요지다.

- **피해**: 신한은행 약 2만 5천 명, KB국민은행 119명, 하나은행 89명의 고객 정보가 빠져나갔고 예가람저축은행·BNK부산은행도 피해를 봤다. 보고서에 따르면 한 은행은 대출 중개인이 쓰는 대출 진행 조회 서비스가, 다른 은행은 직원용 모바일 업무 지원 시스템이 뚫렸다. 피해 기관 수는 보도마다 7곳에서 9곳으로 엇갈린다.
- **AI 스택**: 중국에서 만든 오픈소스 AI 침투 도구 **ARTEX**가 중심이다. ARTEX 자체는 모델이 아니라 작업 도구이고, 주력 백엔드는 누구나 받을 수 있는 **DeepSeek V4.1-Flash**, 보조로 GLM-5.3과 Grok 4.6이 붙었다. **Claude Code**는 여러 모델을 갈아 끼우는 작업 환경으로도 쓰였다.
- **증거가 나온 경로**: 공격자가 열어둔 홍콩 서버 폴더에 ARTEX 설정 파일, Claude Code 세션 기록, Claude 메모리 파일이 그대로 있었다. 코리아중앙데일리에 따르면 한 세션에서는 공격자가 나이·학력을 넣어 보안 연구원 이력서를 써 달라고 했고, 훔친 한국 데이터를 파는 텔레그램 거래처를 묻기도 했다. 크라우드스트라이크는 중국어 사용자이자 금전 목적의 공격자로 "중간 신뢰도"로 판단했고, 특정 조직·국가와 연결하지는 않았다.
- **이후**: ARTEX 개발자는 10월 8일 저장소를 비공개로 돌리고 배포를 멈췄다. 학습·연구용으로 만들었고 공격과는 무관하다는 입장이다. 앤트로픽은 보도 시점까지 입장을 내지 않았다.

이틀 뒤 choi.openai는 Axios의 10월 9일 보도를 이어 정리했다. 앤트로픽·오픈AI 등이 "대형 AI 사고 다음 날"을 비공개로 시뮬레이션하고 있고, 가장 유력하게 상정하는 사고가 금융·인터넷·전력·수도를 멈추는 사이버 공격이라는 내용이다. 이번 국내 사례가 그 시나리오의 작은 실물이라는 해석이다.

> 🔧 **적용 포인트** — 이번 수사의 결정적 증거는 해커가 남긴 Claude Code 세션·메모리 파일이었다. 반대로 말하면 이 파일들에는 작업 맥락과 개인 정보가 고스란히 남는다는 뜻이다. 포트폴리오 저장소의 `.gitignore`는 지금 `.claude/skills/`만 막고 있고 `.claude/settings.local.json`과 미추적 `.agents/` 폴더는 명시적으로 빠져 있지 않다. 공개 저장소이니 두 경로를 `.gitignore`에 추가해 두는 게 안전하다.

### Claude Motion 베타 — /motion 한 줄로 코드 기반 모션그래픽을 만들고 MP4로 내보낸다, Docs·Slides·Design은 정식 전환

ai.trend.kr가 "이번 주 클로드 선물 보따리"로 묶어 소개한 것 중 개발자에게 가장 눈에 띄는 건 **Claude Motion**이다. 앤트로픽은 10월 8일(현지) Claude Dashboards와 함께 새 아티팩트 템플릿으로 공개했다.

- **쓰는 법**: 채팅창에 `/motion`을 치고 원하는 장면을 설명한다. 설명 영상, 차트 애니메이션, 화면 따라하기 같은 짧은 영상을 겨냥한다.
- **방식**: 영상 생성 모델이 아니다. Claude가 글자·차트·도형·이미지를 움직이는 **코드**를 쓰고, 그 결과를 렌더링한다. 그래서 단어·숫자·타이밍을 직접 고치거나 Claude에게 수정을 요청할 수 있고, 지어낸 영상이나 AI 인물이 섞이지 않는다. 결과는 MP4로 내려받는다. 어떤 언어·라이브러리로 짜는지는 공개되지 않았다.
- **이용 범위**: Team·Enterprise 요금제 베타다. Team은 기본으로 켜져 있고, Enterprise는 관리자가 조직 설정 > Artifacts에서 켜야 한다. 일부 보도가 전 요금제라고 썼지만 다수 출처와 요금 안내는 Team·Enterprise로 일치한다.
- **같이 나온 것**: Claude Dashboards는 Redshift·BigQuery·Snowflake 같은 데이터 소스에 붙어 쿼리를 직접 쓰고 실시간 대시보드를 만든다(유료 요금제 베타). 9월부터 베타였던 Claude Docs·Slides·Design은 Free를 포함한 모든 요금제에서 정식으로 전환됐다.

> 🔧 **적용 포인트** — 프로젝트 케이스 스터디의 "구조 설명 영상"(예: 도슨트 RAG 흐름, ARMI 상태 전이)을 GSAP 타임라인으로 직접 짜기 전에, Motion으로 초안 영상을 뽑아 타이밍·장면 구성을 먼저 검증하는 용도로 쓸 만하다. 다만 Team 이상 요금제 전용이라 개인 Max·Pro 사용자는 아직 못 쓴다. 같은 "코드로 짜는 모션" 발상은 Claude Code에 Remotion이나 GSAP 타임라인을 맡기는 식으로 지금 스택에서도 그대로 재현할 수 있다.

### Claude Max·Team에 매달 API 크레딧 — Max 5x 100달러·20x 200달러·Team 최대 500달러, 남으면 이월 없이 사라진다

같은 게시물이 짚은 두 번째 소식은 구독자용 월간 API 크레딧이다. 앤트로픽은 10월 7일 Haiku 5.5와 함께 발표했다.

- **금액**: Max 5x는 매달 100달러, Max 20x는 200달러다. Team은 Standard 좌석당 20달러, Premium 좌석당 100달러가 합쳐진 공용 잔액으로 월 500달러가 상한이다. Free·Pro·Enterprise는 대상이 아니다.
- **받는 법**: 해당 요금제를 7일 이상 쓴 뒤 claude.ai 웹에서 Claude Console 조직 하나를 연결해 신청한다. Team은 Primary Owner·Owner가 신청해야 하고, 연결된 Console 사용자는 Owner·Admin·Billing 권한이 있어야 한다. 순차 배포라 아직 안 보이는 계정도 있다.
- **제약**: 남은 크레딧은 결제 주기 끝에 사라지고 이월되지 않는다. API·에이전트 사용에만 쓰이고, 대화형 Claude Code 사용량이나 Claude 앱 사용 한도를 늘려 주지는 않는다.

> 🔧 **적용 포인트** — Max 요금제를 쓰고 있다면 `/docent`처럼 Anthropic API를 직접 부르는 기능의 운영비를 이 크레딧으로 충당할 수 있다. 신청하지 않으면 그 달 몫이 그대로 사라지니 Console 조직 연결부터 해 두자. 도슨트의 Anthropic 폴백 모델(`src/lib/docent/llmProvider.ts`, 현재 `claude-haiku-4-5`)을 Haiku 5.5로 바꾸면 같은 크레딧으로 훨씬 많은 요청을 처리할 수 있다.
