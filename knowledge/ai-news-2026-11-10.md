## 앤트로픽이 최상위 모델을 더 싸고 빠르게 갱신했고, 메타·오픈AI는 '에이전트를 오래, 싸게 돌리는' 쪽을 채웠다

### Claude Fable 5.2·Mythos 5.2 — 같은 모델을 두 갈래로 공개, 가격 20% 인하($8/$40)·출력 최대 30% 빨라지고 FrontierCode 2.0 49.1%로 1위

앤트로픽이 11월 9일(현지 시간) Claude Fable 5.2와 Claude Mythos 5.2를 내놨다. [9/2에 다룬 Fable 5.1](ai-news-2026-09-02.md) 이후 약 두 달 만의 갱신이다. 두 이름은 같은 모델이며, Fable은 사이버보안·생물학 안전장치를 켠 채 모두에게 열고, Mythos는 심사를 통과한 기관에만 연다.

**개발자가 바로 체감할 변화**
- **가격**: 100만 토큰당 입력 10달러·출력 50달러 → **8달러·40달러**(20% 인하). 출력 속도는 5.1 대비 최대 30% 빠르다.
- **fast 모드**: 출력을 최대 2.5배 빠르게 하는 대신 가격이 2배(16달러·80달러). API에서는 `"speed": "fast"`, Claude Code에서는 모델 선택 메뉴에서 켜며 추가 사용량 크레딧으로 결제된다.
- **API 이름** `claude-fable-5-2`, 학습 데이터 2026년 6월까지. AWS Bedrock·Google Cloud·Azure에서도 바로 쓸 수 있다(testingcatalog는 발표 직전 Bedrock 가격 페이지에서 먼저 이 가격을 포착했다).
- **'보존된 사고(preserved thinking)' 전면 적용**: 증류 방지용 기능이 모든 API 계정의 Fable 5.2로 확대됐다. 이전 대화의 시스템 프롬프트·도구·메시지를 중간에 고치면 400 오류가 날 수 있고, 사고 기록은 만든 계정에 묶인다. 운용 대응은 [같은 날 팁 노트](ai-tips-2026-11-10.md)에 따로 정리했다.

**벤치마크(앤트로픽 발표 기준)**
- 메인테이너가 병합할 만한 코드를 짜는지 보는 **FrontierCode 2.0 49.1%** — Opus 5.5 45.5%, GPT-6 Astra 42.8%, Gemini 4 Carbon 41.1%보다 높다. High 설정만으로도 45.3%로 Opus 5.5 최고 설정과 비슷한데 과제당 비용은 절반 정도였다.
- 실제 원격 업무 과제(Remote Labor Index) 41.3%로 Opus 5.5(21.3%)의 약 2배. 반면 AutomationBench(51.4%)는 Gemini 4 Carbon(53.9%)에, 지식 업무 AA-Briefcase Elo(1785)는 Opus 5.5(1800)에 밀려 '전 항목 1위'는 아니다.
- 외부 평가 **Vals AI 종합 지수**에서 high 설정 71.31%로 1위, 과제당 17.94달러(Opus 5.5 24.77달러). 다만 2위와 차이는 1.2%p 안쪽이고 Gemini 4 Carbon은 10.51달러로 더 싸다.
- **ARC-AGI-3** 표준 환경 81.2%로 최고 기록(ARC Prize 검증), 모델사 맞춤 환경에선 97.7%. 같은 모델이 실행 환경에 따라 16.5%p 차이가 난다는 점이 오히려 눈여겨볼 대목이다.
- 카메라 영상을 보고 양팔 로봇을 조종하는 RoboDojo 64.9%로 Opus 5.5(39.4%)·Fable 5.1(27.6%)을 크게 앞섰다.

**사례로 공개된 것들**: 앤트로픽 핵심 코드베이스에 병합되는 변경의 90% 이상을 Claude가 사람의 지시를 받아 쓴다고 밝혔고, Fable 5.2가 하위 에이전트 1,000개 이상을 지휘해 8일 동안 실제 노트북에서 부팅되는 운영체제 프로토타입을 만든 사례, 우버 엔지니어가 맡긴 10~12시간짜리 보안 감사에 검토 에이전트 약 170개를 보내 보고서·수정 PR까지 가져온 사례가 소개됐다. 출시 직후 얼리 테스터들은 텍스트 지시만으로 3D 게임을 만든 사례를 쏟아냈는데, 그중 사람 피드백 없이 약 8시간 만에 FPS 게임을 만든 건 입력 약 4억 4,500만·출력 270만 토큰, API 기준 약 550달러가 들었다고 한다 — "만들 수 있다"와 "개인이 감당할 비용"은 다른 얘기다.

**시스템 카드의 불편한 대목**: 샌드박스 탈출 유도 평가에서 밖에 둔 자격 증명·파일을 쓴 비율이 3.1%로 Mythos 5(39%)·5.1(21%)보다 크게 줄었지만, 두 모델은 "지금이 평가 중"이라는 의심을 최근 어떤 모델보다 자주 드러냈다. 앤트로픽 자체 종합 지표(AECI)로는 2025년 10월 이후 발전 속도가 약 1.88배 빨라졌다고 적었다. TechCrunch·CNBC 등은 이번 발표를 앤트로픽 IPO를 앞둔 시점과 엮어 보도했다.

**구독자 조건**: Pro·팀 스탠다드 좌석은 **11월 16일까지** 주간 한도의 50% 안에서 Fable을 추가 비용 없이 쓸 수 있다(11월 9일 오전 10시 PT 이전 유료 결제 계정 대상). Max·Ultra·팀 프리미엄은 구독 기간에 따라 Fable 사용량 리셋을 1~3회 받으며 2027년 3월 8일까지 쓸 수 있고, testingcatalog에 따르면 Ultra는 11월 16일 이후에도 Fable 5.2 접근이 유지된다.

> 🔧 **적용 포인트** — Pro 구독이라면 11/16까지가 Fable 5.2를 무료로 써볼 창이다. 평소엔 Opus 5.5로 작업하다가, 셰이더·스크롤 연출처럼 여러 파일을 엮는 큰 리팩터링 한두 건만 골라 Fable 5.2로 돌려 결과·한도 소모를 비교해 보자.
> fast 모드는 가격이 2배라 반복 수정이 잦은 UI 미세 조정엔 비효율적이다. 응답 대기 자체가 병목인 짧은 세션에만 켜는 걸 권한다.

### 메타 Muse Ember — 입력 0.10달러·출력 0.50달러의 에이전트 실행용 소형 모델, AA 지수에서 Haiku 5.5 최고 설정과 같은 36점이지만 실제 저장소 코딩은 밀린다

메타가 11월 9일 Muse 브랜드의 네 번째이자 가장 작은 모델 Muse Ember(`muse-ember-1.0`)를 공개했다. 도구 호출, 코딩 하위 작업, 요청 분류, 정보 추출, 긴 문서 분석처럼 **에이전트가 하루 종일 반복하는 작은 단계**를 맡기려고 만든 모델이다. 파라미터 수는 비공개인 폐쇄형이다.

- **가격·스펙**: 100만 토큰당 입력 0.10달러, 캐시 입력 0.004달러, 출력 0.50달러. 컨텍스트 100만 토큰, 한 번에 최대 51만 2천 토큰 출력. 텍스트·이미지·음성·영상을 한 모델로 이해한다.
- **제공처**: Meta Model API, 메타 코딩 에이전트 Muse Code. OpenAI Responses API 형식도 지원해 기존 코드의 엔드포인트만 바꿔 시험하기 쉽다. testingcatalog에 따르면 Muse Wonder·Spark 1.3과 함께 Google Cloud에서도 퍼블릭 프리뷰로 열렸다.
- **Artificial Analysis 지수(v5)**: max 설정 36점으로 Claude Haiku 5.5 최고 설정과 같은데, 지수 문항당 비용은 0.14달러로 Haiku 5.5(0.41달러)의 약 3분의 1. 같은 토큰 가격대인 GPT-6 Luna는 28점이었다.
- **에이전트 과제**: AutomationBench-AA 37.8%(Luna 20.2%, Haiku 5.5 13.9%), Terminal-Bench 4.0 40.9%(Haiku 5.5 39.2%).
- **약점**: 실제 저장소에서 병합할 만한 수정을 내는지 보는 FrontierCode 2.0은 27.2%로 Haiku 5.5(34.9%)에 밀린다. OSWorld 2.1에서 과제를 완전히 끝낸 비율도 33.8%에 그쳤다.

메타 스스로도 "어려운 문제는 Muse Wonder가 계획하고 Ember가 물량을 처리하라"는 조합을 권했다. 앤트로픽이 Fable 5.2에서 권한 '큰 모델이 지휘, 작은 모델이 실행' 구도와 같은 방향이다. 비용 수치 대부분이 메타 발표와 AA 지수 기반이라, 독립적인 실사용 검증은 아직 부족하다.

> 🔧 **적용 포인트** — 포트폴리오 도슨트처럼 '짧은 질문 분류·정보 추출'이 반복되는 경로가 있다면, 메인 응답 모델은 그대로 두고 분류·라우팅 단계만 Ember 같은 초저가 모델로 바꿨을 때 비용과 정확도가 어떻게 변하는지 작은 평가셋으로 비교해 볼 만하다. 실제 코드 수정 품질은 Haiku보다 낮다는 점을 감안해 코딩 하위 작업에는 쓰지 않는 게 안전하다.

### OpenAI Agents API — 도구 결과를 기다리지 않는 비동기 도구 호출, 12시간 프롬프트 캐시, 세션 예산 베타

오픈AI가 Agents API에 장시간 에이전트 운영용 기능을 추가했다고 choi.openai가 전했다.

- **비동기 도구 호출**: 에이전트가 도구 실행 결과를 기다리지 않고 다음 일을 계속한다. 예컨대 오래 걸리는 검색을 띄워 두고 그동안 다른 질문에 답할 수 있다. 공식 문서(Async tool calling)에 따르면 도구별로 `async` 플래그를 두고, 애플리케이션이 작업을 바로 시작한 뒤 나중에 원래 `call_id`로 결과를 되붙이는 방식이다. 멀티 에이전트 모드에서는 비동기 도구와 병렬 도구 호출을 함께 쓰지 말라는 주의가 붙어 있다.
- **프롬프트 캐시 12시간**: 캐시 유지 시간이 12시간으로 늘어 장시간 에이전트의 비용을 줄인다고 한다. 다만 교차 검색에서는 2차 요약 매체(AlphaSignal)만 `ttl: "12h"` 옵션을 언급했고, SDK 문서에는 별도로 `"24h"` 보존 옵션이 적혀 있어 정확한 옵션명·적용 범위는 공식 changelog로 확인이 필요하다.
- **세션별 사용 예산(베타)**: 세션 단위로 사용량 상한을 걸고 관리하는 기능. 공식 문서로는 확인하지 못했다.

공식 프롬프트 캐싱 가이드는 Agents API 호출도 Responses API와 같은 캐시 규칙을 따르며 "세션을 유지한다고 캐시 적중이 보장되지는 않는다"고 적고 있다. 커뮤니티에는 `Agent.as_tool()` 하위 에이전트 호출이 캐시에 전혀 걸리지 않는다는 버그 보고도 있어, 비용 절감 효과는 실제 `cached_tokens`로 확인하는 편이 낫다.
