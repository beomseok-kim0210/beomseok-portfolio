## Claude Code가 "코드로 개조 가능한" 도구가 되려 하고, AI의 자체 발표는 또 하루 만에 반박당한 날

### 앤트로픽, Claude Code를 "TypeScript로 후킹하는" 플랫폼으로 — Claude Mods 공개 예고

Threads(choi.openai)에 따르면 앤트로픽이 Claude Code에 기존 Hook보다 훨씬 깊게 개입할 수 있는 "Claude Mods"를 준비하고 있다. GitHub 이슈(anthropics/claude-code #91870, 174개 댓글)를 직접 확인한 결과, 이 기능의 정식 명칭은 "Function Hooks"이며 제품명으로는 "Mods"로 부르기로 했다. 9월 3일 앤트로픽 엔지니어가 "TypeScript 함수로 Claude Code 내부를 Express·Koa 미들웨어처럼 후킹하면 어떻겠냐"는 제안을 커뮤니티에 올리며 시작됐고, 9월 9일 업데이트에서 "몇 주 안에 출시하겠다"고 공식화했다. 기존 Hook이 셸 스크립트로 이벤트 전후에 반응하는 방식이었다면, Function Hooks는 `$` 객체를 매개로 한 TypeScript 함수가 Claude Code의 동작 자체(도구 호출, UI 렌더링, 프롬프트 처리, 세션 간 메시지 등)를 감싸 바꿀 수 있다. React 기반 컴포넌트 렌더링에도 개입할 수 있어 "화면의 API 키를 자동으로 가렸다가 마우스를 올릴 때만 보여주는" 것 같은 UI 커스터마이징도 가능하다. 이미 커뮤니티에서는 화면 위에 Doom을 통째로 띄우는 목, 26만 파라미터짜리 초소형 언어모델을 목 안에서 직접 돌려 토큰 소비 없이 이야기를 써주는 목, 작업 중 숨쉬기를 유도하는 목, 후킹으로 잡은 이벤트가 셸 패치보다 훨씬 안정적이라는 실측 보고(30일간 161개 세션에서 Hook 기반 로그는 161/161 도착, 모델에게 직접 기록을 맡긴 로그는 9%만 도착) 등 다양한 실험이 올라오고 있다. 관리자가 조직 차원에서 특정 플러그인의 권한(`$` 객체의 특정 메서드)을 미리 박탈할 수 있어 보안 통제도 함께 설계됐다. 현재 버전(v267~v271)에서 `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1 claude`로 미리 켜서 테스트하고 GitHub 이슈에 피드백을 남길 수 있으며, 웹서치로 확인한 AlphaSignal·claudefa.st·X(ClaudeDevs) 보도도 이 흐름을 동일하게 전한다.

> 🔧 **적용 포인트** — 이 세션이 매일 Claude Code로 작업하는 만큼, `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1 claude`로 먼저 켜보고 `claude plugin validate`로 어떤 `$.noun.verb`가 노출되는지부터 확인해볼 만하다. 예를 들어 이 포트폴리오의 도슨트 런타임 API 키나 RunPod 엔드포인트처럼 화면에 떠 있으면 곤란한 값을 자동으로 가리는 목, 혹은 이 `weekly-ai-news-threads` 같은 예약 작업이 도는 동안 상태를 상단에 표시해주는 목을 시험 삼아 만들어볼 수 있다. 다만 아직 미출시 기능(브레이킹 체인지 가능성)이라는 점은 감안해야 한다.

### 오픈AI, 스마트폰 카메라 스타트업 글래스 이미징 인수 — 하드웨어 기기 채비 가속

Threads(testingcatalog)에 따르면 오픈AI가 스마트폰 카메라 기술 스타트업 글래스 이미징(Glass Imaging)을 인수했다. 웹서치로 확인한 WSJ 단독 보도(via 테크크런치·사일리콘앵글·핌츠)에 따르면 인수 금액은 3억 달러 이상이며, 2019년 설립된 이 회사는 애플에서 '인물 사진 모드(Portrait Mode)'를 개발했던 지브 아타르(Ziv Attar)·톰 비숍(Tom Bishop)이 만들었다. 신경망으로 각 스마트폰 기종의 카메라 특성을 학습해 촬영 즉시 더 나은 이미지를 뽑아내는 기술을 보유하고 있다. 이번 인수는 오픈AI가 2025년 5월 조니 아이브(Jony Ive)의 io Products를 65억 달러(주식)에 인수하고 이후 애플 출신 직원을 대거 영입해온 소비자 하드웨어 진출 흐름의 연장선으로 풀이된다. testingcatalog는 "올해 안에 오픈AI 기기를 보게 될 가능성이 얼마나 될까"라고 되물었고, 양사 모두 인수를 공식 확인하지는 않은 상태다.

### 클로드 Fable 5.1, "370년 묵은 암호를 45분 만에 풀었다" — 다음날 바로 반박 나와

Threads(boris_cherny)에 따르면 앤트로픽 최신 모델 Fable 5.1이 스코틀랜드 작가 토머스 어커트(Thomas Urquhart)가 1653년 저서 『Logopandecteision』 말미에 남긴 채 370년간 풀리지 않던 암호 "Cyphral Distich"를 풀었다. 웹서치로 확인한 Vals AI 공식 블로그에 따르면 Fable 5.1은 사람 개입 없이 44분·17만 6,000토큰 만에, 암호에 등장하는 숫자 32개가 책의 32개 단락(Proquiritation)과 대응하고 각 숫자를 해당 단락의 단어 색인으로 읽어 첫 글자만 모으면 된다는 규칙을 스스로 찾아냈다. 그렇게 복원된 평문은 "오 신이시여 찰스 2세 왕을 지켜주시고 이 땅의 지고한 통치자로 만드소서(O GOD UPHOLD KING CHARLS THE SECOND AND MAKE HIM THE SUPREME RULER OF THIS LAND)"라는 왕당파 기원문이었고, 정확한 글자 수와 운율이 맞아떨어지는 것으로 스스로 교차 검증까지 했다고 소개됐다.

그러나 하루 만에 반박이 나왔다. 웹서치로 확인한 파스콸레 필리테리(Pasquale Pillitteri) 보도에 따르면, 영국국립도서관 소장 1653년 원본을 직접 확인한 연구자들은 "그 책 말미에는 숫자로 된 2행시 자체가 존재하지 않는다"고 지적했다. 원본은 인쇄상 장식·제사(epigraph)·"FINIS"·정오표로 끝날 뿐 숫자가 전혀 없다는 것이다. 이들은 또한 Fable이 제시한 해독 규칙대로면 열 개 자리는 애초에 성립할 수 없다고 - 필요한 글자로 시작하는 단어가 해당 단락에 아예 없다 - 계산으로 반박했고, Fable 5.1이 만들어낸 "그럴듯하게 딱 맞아떨어지는" 해답은 1653년 원본이 아니라 1899년에 나온 후대 판본을 바탕으로 만들어졌을 가능성이 크다고 결론지었다. [9/14 노트](ai-news-2026-09-14.md)에서 다룬 오픈AI 나비에-스토크스 발표(강제 방정식이지 클레이 문제가 실제로 묻는 비강제 사례가 아니라는 지적)에 이어, AI 랩의 "난제를 풀었다"는 자체 발표가 또다시 하루 만에 원문 대조로 반박당한 사례다.
